# 分步课板面、版式与组件规格（v1.3，2026-10-23）

这份规格是 `plans/direction.md` 第六节阶段 1"分步课规格"里的界面部分：令牌、版面、按页面功能排的版式、各组件的样式和状态、能自动查的规则。阶段 2 播放器进库时按它做组件和校验。

原型：`mockups/collision/`（第 4 节碰撞课）已经按本规格改好，是对照的标准答案。它用自己的 `shell.js`、`shell.css`、`lib.js`、`cns-draw.js`；其他几节课仍用 `mockups/momentum/` 的共享外壳，等迁移时再统一。

出处：
- 第 4 节组件盘点实测（1440×900 与 390×844）。
- 高斯 9 张截图的像素测量（由截图估算，只取比例）。
- 前一轮调研已定的推荐档、整板推导 F、不加飞入。
- 本轮版式改动前后用同一套脚本量了 24 步（1440、1280、1024），数字见第七节。

v1.3 改动：S 下限统一为 13px；写明整体缩放的例外；标题字数不计小测题号前缀；`.sym` 不计入字号种类；第七节补上原型对照校验规则仍未达标的项。

## 一、总规矩

1. **字号三档**：标题 T、正文 B、小字 S；另有两个专用档：式子 E、大字 D。一屏最多四种字号。（高斯 T:B:S ≈ 1.35 : 1 : 0.85；改前我们有 13 种固定字号。）
2. **正文一样大**：讲述、问句、题干、选项、卡片正文、表格数值都用 B。层级靠字重和颜色，不靠大小。
3. **能读的字不用 steel**：要让人读的字只用 ink 和 graphite（≥ 4.5:1）。steel 只给线、边框、禁用的底，和"还没讲到的预告字"（5.12）。
4. **一种卡片**：题干卡、定义卡、选项、演算块同一种样式：card 底、hairline 1px 边框、圆角 R2。整屏最多一个结论框。
5. **位置不跳**：标题 y 坐标每步一样；主区按本步最满的一拍预排，从第一句到答完，板上已有的块不移动；动作按钮固定在板底居中。
6. **按页面功能排版**：每一步按它在做什么套一种版式（第三节），整组在主区里水平居中、竖向偏上，两栏互相对齐。
7. **板上只变状态，话写在讲述栏**：对错反馈、提示、点评都由讲述栏说；板上只变选项和空格的状态，不加段落。

## 二、令牌

### 2.1 字号

| 档 | 电脑（≥ 1024） | 1440 时 | 手机（≤ 760） | 字体 | 字重 | 行高 |
|---|---|---|---|---|---|---|
| B 正文 | `clamp(16px, 1.2vw, 19px)` | 17.3 | 16 | Noto Sans SC | 400；强调 600 | 1.65 |
| S 小字 | `max(13px, 0.82×B)` | 14.2 | 13 | Noto Sans SC | 400 / 500 | 1.5 |
| T 标题 | `1.5×B` | 26 | 22 | Noto Serif SC | 600 | 1.3 |
| E 式子 | `1.3×B` | 22.5 | 19 | 符号 Source Serif 4 斜体，数字和运算符同字体正体 | 400 | 1.5 |
| D 大字 | `2.6×B` | 45 | 40 | Noto Serif SC | 600 | 1.2 |

- 行内物理符号 `.sym` 不另设档，用 1.08em 跟随所在文字。
- 画布里的字只用 S 和 B 两档，最小 13px，标注色 graphite。
- 整板推导（没有画面、没有分块的长推导）允许 E 放大到 `min(1.75×B, 能放下的最大值)`，这是唯一的例外。

### 2.2 间距（固定 px，不随 B 缩放）

| 名 | 值 | 用在 |
|---|---|---|
| s1 | 4 | 字和小标记之间 |
| s2 | 8 | 标签到标题；卡片内小标题到正文 |
| s3 | 12 | 选项之间、卡片之间 |
| s4 | 16 | 卡片上下内边距；问句到选项 |
| s5 | 24 | 卡片左右内边距；动作条离板底；例题题干卡到画面 |
| s6 | 40 | 标题到主区；1024–1279 宽时两栏的间隔 |
| s7 | 64 | 两栏的间隔（≥ 1280）；整组内部空白条带的上限 |

板的左右内边距 `clamp(40px, 6.5%板宽, 96px)`（1440 时约 70），上内边距 28。

### 2.3 圆角

只用三种：R1 = 6（标签、小胶囊、表格），R2 = 14（卡片、选项、按钮），R3 = 28（板）。

### 2.4 颜色（以 `app/src/theme.ts` 为准）

- 文字：ink 给标题、正文、选中项；graphite 给次要文字、已读讲述、已排除的选项、表头、旁注、标签。
- 线：hairline 给卡片边框和分隔；steel 给禁用的边框和坐标轴细线。
- 物理量颜色照旧：蓝 = 速度，红 = 力和"不可能"，金 = 能量；状态不用彩色。碰撞面、冰面这类装饰用中性色，靠形状区分。
- 结论框：bezel 底，左边一条 3px ink 竖线。不用黄底，金色已经归能量。
- 夜光只换令牌，不另写规则。

## 三、版面

### 3.1 骨架（电脑 ≥ 1024）

```
┌顶栏 56──────────────────────────────────────────────┐
│讲述栏 clamp(280,24vw,340) │ 板（R3，四周留 16）        │
│                          │  结论链一行（高 32）        │
│  上一句末行（S graphite） │  幕标签（S）                │
│  当前句（B ink）          │  标题（T，y 坐标固定）       │
│  我的回答（S，气泡）      │  ── s6 ──                  │
│                          │  主区：版式整组，见 3.2      │
│                          │  ── s5 ──                  │
│                          │  动作条（板底居中）          │
└──────────────────────────┴────────────────────────────┘
```

主区是标题下 s6 到动作条上 s5 之间的空间。内容比主区高时依次缩小画布、E、间距，最后整体缩放，不出滚动条。

### 3.2 整组定位与对齐

**G1 整组定位**：整组 = 本步最满状态下所有内容块的外接框（沿用预排，0 跳动）。
- 水平：整组居中，偏差 ≤ 4px。
- 竖向：主区高 H、整组高 gh，整组顶 = `clamp(0, 0.42·H − gh/2, H − gh)`。内容满时等于贴顶，内容少时中心落在 0.42 处。（高斯实测在 0.34–0.40；改前我们的纯文字题在 0.29–0.32，上重下轻。）

**G2 两栏对齐**：矮的一栏对齐高的一栏的竖向中心；左栏是画面时，按画面本身（不含播放条）算。最满状态下两栏中心差 ≤ 24px。例外：fill 版式两栏顶对齐。

**G3 栏宽按版式定**（3.3），栏距 s7（< 1280 时 s6）。

**G4 密度**（最满状态）：
- 有画面的版式，内容占板 25–50%；
- 纯文字版式（quiz、fill、result）下限 12%。高斯小结页实测 12.8%，文字页不为凑密度加内容；
- 整组内部最大空白条带 ≤ 64px。

### 3.3 版式

由外壳按内容自动判定，课件不用声明。判定按表中顺序，第一条满足的生效；结果写在 `#work[data-layout]` 上。可选的步属性 `frame` 可以强制指定版式（新属性、可选；不用 `layout`，那是已有属性，意思是"不显示画布"）。

| 版式 | 判定 | 构图 | 栏宽（B = 正文字号） |
|---|---|---|---|
| **result 结果** | 有 `.score` | 单栏居中 | 32B |
| **grid 作业** | 有 `.hw` | 单栏双列网格 | 内容宽 |
| **fill 填空** | 有 `.fill` | 左：整张结论卡，空格挖在卡里；右：当前空的选项。两栏顶对齐 | 右 21B，左 = 其余 |
| **example 例题** | 有 `.stem` 且有画面 | 左：题干卡（宽 = 左栏）、下隔 s5 接画面；右：选项和作答后的演算，右栏中心对齐整个左栏 | 右 21B |
| **quiz 纯文字题** | 有 `.stem`、无画面 | 左：题干卡（含问句）；右：选项。两栏互相竖向居中，整组居中 | 左 28B，右 21B |
| **lab 实验** | 有画面，且有 `.run` 或数据表 `table.dt` | 左：画面；右：控件、数据表、停点 | 右 26B |
| **derive 推导** | 无画面、有分块 `.bks` | 左：推导卡；右：问句、选项、核对表 | 右 21B |
| **def 概念** | 有画面、有 `.def`、无选项 | 左：图；右：定义卡，卡中心对齐图 | 右 24B |
| **pic 图＋停点** | 其余有画面的 | 左：画面；右：问句和选项 | 右 21B |

1440 下 21B ≈ 363px、24B ≈ 415、26B ≈ 450、28B ≈ 485、32B ≈ 554。

- **1024–1279**：同样的版式，放不下时依次缩画面、E、间距，最后整体缩放。令牌里 S 不低于 13；整体缩放是最后手段，缩放后实际字号会低于 13，出现时记入第七节「已知未达标」。
- **手机（≤ 760）**：不分版式，单栏从上往下：标签和标题、题干、画面、问句、选项。动作条贴底（`.act-slot`）。板左右边距 16，B 16、T 22、S 13。

第 4 节各步用到的版式：result #a7s8；grid #a7s9；fill #a6s1；example #a5s1–3、#a7s3–7；quiz #a7s1–2；lab #a1s2–3；derive #a4s1；def #a2s2；其余 pic。

## 四、交互

**G5 动作条按钮**：主按钮只有两种字——"继续"和"提交"。
- 讲述各拍、作答后、小测题间、结果页、作业页，一律"继续"。各步自己写的按钮字（"下一句""看结果""去测数据"等）不再显示；步属性 `button` 保留但忽略，标"已弃用"。
- 停点上有可选的选项、还没提交时是"提交"，没选中时禁用。
- 没有选项的门（如实验要做满三次）是禁用的"继续"。
- 停点时"提示"文字按钮在主按钮右侧。
- 不在按钮上方写"先选一项"，禁用的"提交"已经说明了。

**G6 先选后提交**：
- 停点上点选项只是选中（`.sel`）：2px ink 边框，字母格 bezel 底；不出 ✓ / ✕，讲述栏不出"我选…"。再点另一项换选。
- 按"提交"或回车才判：讲述栏出"我选「…」"，然后照原逻辑走：
  - 判对：`.win`，按钮变"继续"；
  - 判错：`.lose`，清空选中，"提交"再次禁用；
  - 预测题：锁定（"已锁定"标签），按钮变"继续"。
- 对停点里所有 `.opt` 生效，包括 `GRAV.ui.choice` 和各幕自己写的预测题；写课的人不用改写法。

**G7 问句归位**：
- 有题干卡（`.stem`）的步，问句是题干卡的最后一句（`<b class="stem-q">`，600），右栏不再出 `.q-echo`。
- 没有题干卡的步，问句在选项正上方（`.q-echo`）。

## 五、组件卡

每张卡写：放哪、尺寸、状态、写课的人写什么。

### 5.1 顶栏
- 高 56；图标按钮 ≥ 44×44（手机）、≥ 32×32（电脑）。
- 禁用的箭头和图标对比 ≥ 3:1。
- 写课的人不写。

### 5.2 讲述栏
- 当前句：B ink。
- 已读句：只留紧挨着的上一句，显示它的最后一行，S graphite，点一下展开整步记录。
- 我的回答：S graphite，卡片底的气泡里，只留最近一条。
- 反馈和提示：作为当前句说出来。
- 写课的人：每句 ≤ 60 字，超过的拆成两拍。

### 5.3 动作条
- 板底居中，离板底 s5；手机上用贴底的行动位。
- 主按钮：高 48，最小宽 200，R2；ink 底、card 色字、B 600；文字见 G5。
- 禁用：bezel 底、graphite 字。
- 次按钮"提示"：文字按钮，B graphite，主按钮右侧 s3。
- 讲述栏原来的 `.go` 在电脑上隐藏，逻辑不变。
- 写课的人不写。

### 5.4 结论链
- 板最上一行，高 32，单行；放不下时只留最新几项，前面折成"…+n"。
- 胶囊 S：普通项 graphite 字、hairline 边框；最新项 ink 字、1.5px ink 边框。
- 不加飞入和闪动。

### 5.5 幕标签
S graphite，格式"第 2 幕 · 三种碰撞"。不用彩色胶囊。

### 5.6 步标题
- T ink 600。电脑一行写完（≤ 18 字），手机最多两行。
- 小测的标题写题号和情境，问句在题干卡里。

### 5.7 画面（canvas）
- 放在左栏，宽 = 左栏宽。
- 标注 S graphite，读数等宽字体，ink 或物理量色，最小 13px。
- 播放条在画面下 s2，S graphite，按钮高 ≥ 32。
- 小测题如果是两物体碰撞，配一张静态的碰前示意图：只画物体、质量、速度箭头和数值；不动画、不画碰后，不泄露答案。

### 5.8 问句（`.q-echo`）
- 没有题干卡时：右栏，选项正上方，隔 s4。
- B 600 ink，≤ 2 行（≤ 40 字）。答完后保留。

### 5.9 题干卡（`.stem`）
- example 版式在左栏顶部，宽 = 左栏；quiz 版式在左栏，宽 28B。
- 可选小标题"已知"：S 600 graphite。正文 B。
- 最后一句是问句（G7）。

### 5.10 选项（`.opt`）
- 最小高 `2.2×B + 2×s3`（1440 约 62），内边距 s3 / s4，R2，间隔 s3，字 B ink。
- 字母 A / B / C / D：S 500 graphite，在左侧，和正文之间隔一条 hairline 竖线，字母加竖线约 36px。右侧标记位固定 24px，只放 ✓ / ✕。
- 状态：

  | 状态 | 边框 | 文字 | 右侧标记 |
  |---|---|---|---|
  | 默认 | hairline 1px | ink | — |
  | 悬停 | steel 1px | ink | — |
  | 选中未提交（`.sel`） | ink 2px，字母格 bezel 底 | ink | — |
  | 锁定预测（`.on`） | ink 1.5px | ink | 右上角压边框的"已锁定"（S graphite，card 底） |
  | 答对（`.win`） | ink 2px | ink 600 | ✓ ink |
  | 答错（`.lose`） | hairline 1px，bezel 底 | graphite，删除线 | ✕ graphite |
  | 已排除或未选（答完后） | hairline 1px | graphite | — |
  | 揭晓正解（`.reveal`） | ink 2px 虚线 | ink | "答案"，S graphite |

- 不变色、不抖动。
- 写课的人：2–4 个选项，每个 ≤ 24 字。选项里的式子跟随 B，不放大。

### 5.11 演算
- **算式列**（≤ 3 行）：式子 E，旁注 S graphite 在右侧；最新一行 ink，旧行 graphite。
- **分块**（≥ 4 行的推导）：每块一张卡，小标题 B 600 说这一步做什么（"动量守恒""两式相除"），下面 1–3 行式子 E，可加一句 S graphite 说明；结论写在最后一块，用结论框；一屏最多 4 块。
- 推导尽量配画面或表格放在对面一栏；实在没有，就走 derive 版式。

### 5.12 定义卡和总结（`.def`）
- 一张卡，各行之间 hairline 分隔。名称一列不折行、宽度按最长名称，B 600 ink；定义 B；注意和出处 S graphite。
- 跟读高亮：一屏列出多条结论时，一开始全部排好，没讲到的用 steel（唯一允许低于 4.5:1 的地方，它马上会变成 ink），讲到哪条哪条变 ink，版面不动。

### 5.13 填空（`.def.fill`）
- 用于"把结论补全"：整张结论卡从第一拍起就显示，关键词挖成空格，不只给一句孤零零的话。
- 空格 `<span class="blank">`：当前要填的加 `cur`（ink 2px 下划线、bezel 底）；填好的加 `done`，显示答案词。
- 右栏一次只放当前空的选项，上方 `.q-echo` 写"第 1 空""第 2 空"。
- 一空答对后：卡里的空填上；这组选项收成一行 `.ans-line`（"第 1 空：总动能 ✓"，S graphite），其容器加 `data-keep="0"`，外壳不强制保留；下一组选项出现。

### 5.14 数据表（`.dt`）
- 数值 B，等宽读数；首列 B graphite；表头 S 500 graphite。
- 放在右栏且三列放不下时整表退到 S；首列写短（如"0.4 / 0.2"），单位写进表头。
- 行高 `2×B`，表宽 ≤ 720。

### 5.15 小测结果、作业、完成页
- 得分 D；目标行 B；"回第 N 幕再看"文字按钮 B。
- 作业题干 B，题号 S graphite。
- 完成页：大字 D，副字 B graphite，按钮同 5.3 主按钮。
