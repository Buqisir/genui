# 第 4 节碰撞课：原型 → 方案 A 迁移对照表（2026-10-23，用户定）

原型：`mockups/collision/act1.js`–`act7.js`、`board.js`、`draw.js`。写法和组件见 `plans/step-lesson-syntax.md`（属性表 v0.1）。版式按板面规格 3.3 自动判定，下表"版式"一列是迁移后应判出的结果，和板面规格第 122 行的分配一致；判不出来就是组件写错了，不靠 `frame` 硬指定。

记号：句号从 0 数（同原型的 beat）。"@k" 表示组件写在第 k 句后面，从第 k 句起出现；"@前"表示写在第一句之前。

## 二、对属性表 v0.1 的修改（迁移中发现，提议进 v0.2）

| | 改什么 | 为什么（哪几步用） |
|---|---|---|
| A | 新组件 `<Collision>`：一维两体碰撞画面，导轨、两车（或两球）、速度箭头，下面动量、动能两组柱子。属性：`m`（两个质量）、`v`（碰前两个速度）、`after`（碰后两个速度）、`surface`（`magnet` / `rubber` / `velcro`）、`body`（`cart` / `ball`）、`names`、`massText`、`label`、`bars`（boolean 或 expr，默认 true）、`digits`、`still`（只画碰前，不播）。数值属性都接受 expr，`Lab` 改参数就能换条件 | 13 步用到（#a1s2–3、#a2s3、#a3s1–2、#a5s1–3、#a7s3–7）。`<Define>` 只能写数值表达式，没法共享画图代码，不做组件就得把 `draw.js` 的 90 行在课件里抄 13 遍 |
| B | `Choice` 加 `name`；选项加 `check`；预测题可以有一个 `correct`，锁定时不判对错。新组件 `<Recall choice="名字" />`，单独成段、占一句：说"你猜的是「…」，猜对了。"或"你猜的是「…」。"，再接那一项的 `check`；学生跳过了没选，就说 `correct` 那项的 `check` | #a1s3（回看 #a1s1 的猜测）、#a3s1、#a3s2。原型这三处是"先猜、看实测、再说你猜得对不对"，v0.1 把分支并进锁定时的 `say`，会在看实测之前就揭底，教学顺序不对。这一条取代 v0.1 第五节"先不做"的第一项 |
| C | `Lab` 加 `filled`（表一开始就按 `runs` 全部算好，不是停点、不出条件按钮）和 `first`（固定的首行，如"碰前"） | #a1s2 的"碰前"行；#a1s3、#a4s1 的已填好的数据表 |
| D | `Fill` 加 `mask`：列出结论链条目的 `title`，到这个 `Fill` 答完前盖住；`Conclude` 加 `blank`：被盖住时显示的挖空版，没写就只显示"……" | #a6s1（原型 `boardMask`），不然学生抄右边链上的答案 |
| E | `Result` 加 `say: { all, some }`，`{n}`、`{total}` 换成成绩；有 `Result` 的步可以不写正文 | #a7s8 全对和没全对说的话不同 |
| F | 同一步里的多个 `Def` 接成一张卡，后写的行在它所在的那一句出现 | #a2s2 的"注意""牛顿"两行逐句出现 |
| G | 选项的 `say` 可以是字符串数组，按句说 | 多处反馈超 60 字，拆成两句比硬删好 |
| H | `Choice`、`Work` 加 `label`（例题里的小节名"策略""解答"） | #a5s1 原型的"情境 / 策略 / 解答"三段 |
| I | 删掉 v0.1 的 `stop-at-end` 错误：停点可以是一步的最后一句，答完说完反馈，按钮变"继续"进下一步 | 小测 7 步、#a1s1 都是"最后一句是停点"，原型就这么走，没有问题 |
| J | `Conclude` 的 `settles` 不限于猜想：`holds` 也表示"这一条被新结论收编"，链上改显示新标题 | #a2s1 "弹开 ≠ 弹性" → "按动能分三类"；#a4s1 两个特例收进公式 |

全是新组件或新组件的属性，不碰已有组件，兼容规则上没有问题。
