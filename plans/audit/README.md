# 真题课件整体验收（2026-10-12）

范围：应用里能打开的 `lessons/` 19 课 + `generated-grok/bank/` 75 课，共 94 课、262 个场景。其他 grok 目录（zj-*、calib 等）是同一批题的重复生成，没纳入。

## 怎么跑的

- `run.sh`：并行跑 `screen.sh`（每课 `genui validate` + `genui layout`，写 `screen.jsonl`）和 `shoot.mjs`（每个场景截一张、时间拨到 40%、记控制台报错，写 `shots/` 和 `shoot.jsonl`）。
- `summarize.mjs`：合成排序表 `summary.md`（问题多的课在前）。
- `sheets/`：每 12 张拼一页总览（`sheet-NN.jpg`，对应文件名在 `sheet-NN.txt`），逐页看过。
- 不调用生成模型，只用现有课件 + 当前组件渲染。

## 组件 / 检查类问题（已修）

1. 排版检查把「组件画在自己实体上的标签」当问题：霍尔片的电流「I」、方块/行星上自带的名字。现在自带标签压在自己的实体（权重 ≥3）上不再报；箭头类照常报（标签压住自己的箭头确实难看）。`app/src/agent/layout.ts`。
2. `v.dim` 的尺寸文字占了标签位却没登记名字，之后所有标签的名字错一位，报告里出现「与标签『』重叠」这类空名字，或者张冠李戴。`app/src/sim/runtime.js` 的 `dim`。
3. 矩形 `v.vessel` 把整个外框（含空腔）登记成实体：标在容器里的「水」「p_上 = …」被报压住容器，自动摆放的标签也躲着空腔。现在只登记四面壁（开口那面不登记）。异形瓶（flask/bottle）仍按外框登记，没改。
4. 空字符串标签会占一个标签位：`placeLabel` 遇到空名字直接跳过。
- 测试：`app/src/agent/layout.test.ts` 新增 3 条（霍尔片自带标签、标注后标签名字对得上、容器里的标签），去掉修复时都会失败。

## 课件内容问题（只记录，不改课件）

### A. 用通用图元画实物，画成白底黑框（风格和 B+ 不统一）

模型没有用现成器材，而是用 `v.rect` / `v.path` / `v.line` 拼：

| 课件 | 画的东西 | 有现成器材可用吗 |
|---|---|---|
| gd21-12 | 滑动变阻器 | 有（Wiring / Circuit 的变阻器） |
| gd22-15 | 空调室内外机 | 没有，示意图可以接受 |
| gd23-02 | α/β/γ 穿透用的纸、铝、铅板；倾斜木板 | 板子可用 `v.block`/`v.incline` |
| gd23-03 | 真空管里的 Cs | 可用 `v.vessel` |
| gd23-11 | 毫米刻度尺（手画断口） | 有 `v.ruler` |
| gd23-12 | 样品池 | 可用 `v.vessel` |
| gd24-06 | 长方体介质（红光、绿光） | 有 `v.optics` 的介质 |
| gd24-11 | 双缝干涉装置 | 部分（光源、光屏） |
| gd24-12 | 电磁铁草图 | 有 `v.solenoid`/`v.magnet` |
| gd24-13 | 两个气缸：`v.path` 画壁、`v.block` 当气体 | 有 `v.cylinder` / `v.vessel` |
| gd24-14 | 安全气囊 | 没有 |
| gd24-15 | 安全带锁止机构 | 没有 |
| gd25-06 | 装置简图（计时器、电机） | 部分 |
