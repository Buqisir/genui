## 一、从教学设计里拿到的东西

### 骨架

| 项 | 原文要点 |
|---|---|
| 学情 | 学生已经学过向心力、圆周运动、牛顿运动定律。**上一节已经探究过太阳与行星间的引力。** 高一学生"容易停留在知识接受层面"，"不能建立明确的动态物理图像" |
| 目标 | 分四维：物理观念、科学思维（含"抓住主要矛盾，建立理想模型"）、科学探究（月-地检验，"提出问题 → 猜想与假设 → 理论分析 → 实验观测 → 验证结论"）、科学态度与责任 |
| 重点 | 推导思路和过程；定律的内容和公式 |
| 难点 | ① 对定律中**物体间距离**的理解；② 对**普遍性**的理解：任何物体之间都有引力，并且遵循同一规律 |
| 引入 | 用古诗词提出**月相变化和潮汐**之间的神秘关联。讲完定律以后"播放视频，解密月相和潮汐的联系"，首尾呼应 |
| 主线 | 天体间引力的普遍性（两个类比事实、两个猜想）→ 月-地检验 → 任意物体之间都有平方反比的吸引 → 得出定律和它的意义 → 扭秤测出 G → 知识总结、方法梳理。右侧一栏是"科学思想渗透" |
| 推导 | 自主学习提纲，5 个小问：①椭圆运动不会处理，怎么办？（简化成匀速圆周运动）②向心力由谁提供、方向如何？③哪个参量容易观测？（周期，所以用含周期的向心力公式）④结合开普勒定律得出什么？（F ∝ m/r²）⑤对这个结论有什么思考？ |
| 猜想 | 两个问题：太阳对行星的力和地球对月球的力是同一种力吗？地球对月球的力和地球对苹果的力是同一种力吗？接着用思想实验"牛顿大炮"：速度越大，轨迹越平；速度非常大，轨迹将和地面平行 |
| 检验 | 月-地检验流程图：假定两种力是同一种 → 月球轨道半径是地球半径的 60 倍 → 引力之比 60² → 用牛顿第二定律得加速度之比 1/60² → 用数据 r = 3.8×10⁸ m、T = 27.3 天、g = 9.8 m/s² 算出 a = rω² ≈ g/3600 |
| 扭秤 | 思考提纲，5 个设计问题：为什么用两个小球（平衡）；大球用两个还是一个（两个扭转更明显）；横杆长一些还是短一些（长，力矩大）；为什么装平面镜（用反射光的偏移看扭转）；标尺放远还是近（远，更容易测）|
| 小结 | 知识结构图，加方法链："提出问题、尝试解释 → 模型构建、科学推理 → 寻找证据、科学论证 → 归纳总结、合理外推" |
| 反思 | 100 多年才测出 G，主要原因是"普通常见物体间的万有引力太小而不易测量" |

### 原文里要改的两处

- 卡文迪什实验的年份写成了 1789 年，应为 **1798 年**。距 1687 年是 111 年，"100 多年"的说法不受影响。
- G 的"推荐标准值"写的是 6.67259×10⁻¹¹，这是 1986 年的值。现行推荐值是 6.67430×10⁻¹¹ N·m²/kg²。课上用 6.67×10⁻¹¹ 不受影响。

### 它做得好的地方，我们照着做

1. **衔接靠问题链。** 每一段都回答上一段留下的问题。
2. **难点拆成小步。** 推导被拆成 5 个小问，每一问只用学过的知识。
3. **高潮是用数据检验。** 月-地检验先算预测值，再用数据核对。
4. **首尾呼应。** 开头用潮汐和月亮提出问题，结尾解开它。
5. **扭秤用一连串设计问题来理解。** 每个问题都是"选 A 还是 B，为什么"。
6. **小结有两层**：知识结构和方法链。

### 它缺的，我们来补

- **目标没有检验手段。** 写了"理解普遍性""理解物体间距离"，但整节课没有一个环节能看出学生到底懂了没有。
- **难点①"物体间距离"在流程里没有专门的环节**，只在板书里写了一句"球心间的距离"。
- **没有针对错误想法。** 这一节学生常见的错误想法有：太空里没有引力；大物体对小物体的引力更大；r 是到地面的距离；r 趋于零时引力趋于无穷大。
- **"引力太小"只是说说**，没有让学生自己算一次，形成量级感。
- **没有接到真题。**
- 学情里说学生"不能建立动态的物理图像"，可是牛顿大炮和扭秤在原设计里都是静态图片。这正好是我们的组件能补上的。

## 二、课的设计原则

1. **先定目标，再定证据。** 每个目标都配一个练习，学生做对了就是达成的证据。
2. **每段结尾留一个问题，下一段来回答。**
3. **开头先让学生表态，结尾回扣他的选择**，并且解开引入时的悬念（潮汐）。
4. **每个练习只针对一个目标和一个错误想法。** 干扰项各自对应一个具体的错误想法；提示分三级：先指方向，再给关键一步，最后才给答案。
5. **板上的图都是真算出来的，解释也画在板上。** 原设计里的静态图（牛顿大炮、扭秤）改成可以操作的模拟，但每一帧只开放一个离散的选择。
6. **一节课最后接一道真题。**

## 三、目标和证据

| 目标 | 学生能做到 | 证据（练习） |
|---|---|---|
| 科学思维：理想模型 | 知道为什么可以把椭圆轨道当成圆 | S1 第①步 |
| 物理观念：推导思路 | 用学过的规律推出 F ∝ m/r² | S1 第③④步 |
| 科学探究：检验 | 由猜想算出预测值，再用数据核对 | P2 |
| 难点②：普遍性 | 用同一条曲线解释苹果和月球；知道引力是相互的、一样大 | 回扣开头的选择；P3a |
| 难点①：物体间距离 | 用球心距算出空间站处的引力 | P3b（约为地面的 89%） |
| 科学态度与责任：为什么 111 年才测出 G | 自己估算出两个人之间的引力有多小；说出扭秤是怎么把小效果放大的 | P4a；扭秤的设计选择 |
| 迁移 | 用"引力 = 已知的另一种力"求天体质量 | P4b 和真题 gd21-02 |

## 四、分段设计

版式沿用播放模式：左栏是逐句讲解和对话，右边是干净的板子，每一帧最多只有一样东西能操作。数值都由主会话核算过（见第六节）。

### S0 引入：潮汐和月亮

- **讲**：古人早就注意到"海上明月共潮生"，潮水的涨落跟着月亮走。月亮离我们 38 万公里，它是怎么"拉"动海水的？我们先回答一个更简单的问题。
- **板**：海面和月亮，标注"不按比例"。然后切到第二帧：地面上一棵树、一个正在下落的苹果，远处是绕地球转的月球。
- **作答**：表态，不判对错。拉苹果的力和拉月亮的力，是同一种力吗？选项：是 / 不是 / 说不清。记录下来，S2 结尾回扣。
- **衔接**："先从你上一节学过的地方找线索：太阳拉行星的力，是怎么随距离变的？"

### S1 回顾：太阳和行星之间的引力（快速）

上一节已经学过，这里压缩成 4 步，每一步是一个数字块填空或二选一：

1. **建模型**：行星的轨道是椭圆，我们不会处理，怎么办？
   - 近似成匀速圆周运动（正确）
   - 先不管轨道形状
   - **板**：真实的椭圆轨道慢慢变成圆，同时标出偏心率很小（地球约 0.017）。
2. **向心力由谁提供？** 太阳的引力，方向时刻指向太阳。**板**上出现力的箭头。
3. **哪个量好观测？** 周期 T。所以 F = m v²/r，再代入 v = 2πr/T，得 F = 4π² m r / T²。
4. **结合开普勒第三定律 r³/T² = k，得到什么？**
   - **F ∝ m/r²**（正确）
   - ∝ r
   - ∝ 1/r
   - ∝ r³
   - **我们的特色**：把六大行星的真实数据画到 `Plot` 上，横轴 r，纵轴 a = 4π²r/T²，双对数坐标，六个点落在一条斜率为 −2 的直线上。
- **P1**：行星到太阳的距离变为 2 倍，引力变为多少？
  - 1/4（正确）
  - 1/2（当成和距离成反比）
  - 2
  - 不变
- 再用牛顿第三定律：行星拉太阳的力一样大，所以 F ∝ Mm/r²。
- **衔接**，用原设计里的两个问题："太阳拉行星的力是平方反比。地球拉月亮的力，是不是也一样？它和拉苹果的力，又是不是同一种力？"

### S2 猜想与检验（本节高潮）

**S2a 思想实验：牛顿大炮（提出猜想）**

- **板**：地球，山顶上一门炮（`Motion` 按平方反比引力计算轨迹）。
- **唯一能操作的**：发射速度，只有 4 档可选：慢、较快、很快、刚好。每一档都画出真实的轨迹，前一档的轨迹保留为淡色。
- **作答**：速度越来越大，最后会怎样？
  - 绕着地球转，一直落不到地上（正确）
  - 落得更远，但总会落地
  - 沿直线飞走
- **讲**：月亮也在一直"落"，只是落不到地上。拉它的，会不会就是拉苹果的那个力？这就是猜想。具体要多大的速度，留到后面"宇宙航行"那一节。

**S2b 月-地检验（验证猜想）**

- **P2 预测**：月球到地心的距离约是地球半径的 60 倍。如果猜想成立，月球的加速度应是 g 的多少倍？
  - 1/3600（正确）
  - 1/60（只除了一次）
  - 1（以为天上地下一样）
  - 0（以为月亮不受地球的力）
- **观察**：板上用原设计的数据，由组件当场算：
  - r = 3.8×10⁸ m，T = 27.3 天
  - a = 4π²r/T² = **2.70×10⁻³ m/s²**
  - 预测 g/3600 = **2.72×10⁻³ m/s²**
  - 两根柱子（`Bars`）几乎一样高，相差 1%。
- **解释画在板上**：画出 g(r) = g(R/r)² 这条曲线，从地面画到月球轨道，苹果的点和月球的点落在**同一条曲线**上。这一帧就是"天地统一"。
- **回扣**："你开头选的是 ___。数据告诉我们：是同一种力。"
- **衔接**："太阳拉行星、地球拉月亮、地球拉苹果，都是同一种力。那任意两个物体之间呢？"

### S3 万有引力定律（推广，攻难点）

- **板**：两个均匀球，标出球心距 r。写出 F = G m₁m₂/r²。适用条件写在板子角上：可看成质点的物体，取质点间的距离；均匀球体，取球心间的距离。
- **P3a（难点②：引力是相互的）**：地球拉 0.2 kg 的苹果，力是 1.96 N。苹果拉地球的力是多少？
  - 1.96 N（正确）
  - 0
  - 远小于 1.96 N（以为大物体的力更大）
  - 无法确定
  - **解释画在板上**：两个力的箭头一样长、方向相反。再看效果：苹果的加速度是 9.8 m/s²，地球的加速度只有 **3.3×10⁻²⁵ m/s²**。
- **P3b（难点①：物体间距离）**：天和核心舱离地面约 400 km。航天员受的引力大约是在地面时的多少？
  - **约 90%**（正确：(6371/6771)² = 0.885）
  - 0（以为太空里没有引力，这是最常见的错误想法）
  - 约 10%
  - 约 50%
  - **板**：按真实比例画地球和空间站的轨道，400 km 只是地球外面一圈细线。
  - **三级提示**：
    1. r 是从哪里量到哪里的距离？
    2. r 从 6371 km 变成 6771 km，变了百分之几？
    3. 算 (6371/6771)² = 0.885。
  - **为什么航天员会"飘"**：只说一句"引力还在，都用来让他绕地球转了"，完整解释留到"完全失重"那一节。
- **解开引入的悬念**：月球对近月一侧海水的引力，比对地心的大约 **3.4%**；对远月一侧的，小约 **3.2%**。这个差别把海水往两边拉，就形成了潮汐。板上画地球、两侧的海水和三个长短不同的箭头。这一部分只作为拓展讲给学生，不出题。
- **衔接**："既然任意两个物体之间都有引力，为什么牛顿当年算不出 G？为什么两个同学站在一起，感觉不到相互吸引？"

### S4 引力常量：为什么过了 111 年才测出来

- **P4a 估算**：两个 50 kg 的同学相距 1 m，他们之间的引力约为多少？（G = 6.67×10⁻¹¹ N·m²/kg²）
  - **1.7×10⁻⁷ N**（正确）
  - 1.7×10⁻³ N
  - 17 N
  - 0
  - **板**：把这个力和人的体重 490 N 画在对数坐标上，两者相差 **3.4×10⁻¹⁰** 倍。这就是反思里说的"太小而不易测量"。
- **扭秤：把原设计的思考提纲变成连续 4 个设计选择。** 板上是扭秤模拟，学生每做一个选择，光点在刻度上的偏移量就跟着变：
  1. 横杆长一些还是短一些？（长，力矩更大）
  2. 大球用两个还是一个？（两个，扭转更明显）
  3. 为什么要装平面镜？（让反射光随扭转偏转，把很小的角度放大成光点的移动）
  4. 标尺放远还是近？（远，光点移动得更多）

  每一步都是二选一。选错了不判错，只是光点几乎不动，学生自然会换另一个选项。这样把"放大"的思路亲手走一遍。
- **P4b 称地球**：地面上 mg = GMm/R²，所以 M = ?（数字块填空）
  - gR²/G（正确，代入得 **5.96×10²⁴ kg**）
  - gR/G
  - GR²/g
- 讲 1687 年牛顿发表定律，1798 年卡文迪什测出 G，中间隔了 111 年。有了 G，定律才能真正拿来计算。
- **衔接**："有了 G，就能算天体的质量。来看一道真题。"

### S5 真题：gd21-02 天和核心舱

- 2021 广东卷第 2 题：已知引力常量，由下列哪组物理量能算出地球质量？答案 D：核心舱的线速度和绕地半径。用题库里现成的课件。
- 思路：引力提供向心力，GMm/r² = mv²/r，得 M = v²r/G。只知道核心舱的质量，或者只知道角速度和周期（这两个量不独立，而且缺少 r），都算不出来。
- 这一步要从"地面上 mg = GMm/R²"迁移到"轨道上的向心力"，也是下一节"万有引力理论的成就"的预告。这正好对应原设计的作业 2："收集资料，举例说明万有引力理论的成就"。

### S6 小结

- **知识结构图**：沿用原设计的结构图（太阳与行星间的引力 / 月-地检验 / 定律、公式、G、适用条件、适用领域 / 卡文迪什扭秤）。
- **易错点**：
  - r 是球心距；
  - 引力是相互的，两个力一样大；
  - 太空里也有引力；
  - G 很小，所以日常物体之间的引力感觉不到；
  - r → 0 时不能用这个式子。
- **方法链**：沿用原设计的"提出问题、尝试解释 → 模型构建、科学推理 → 寻找证据、科学论证 → 归纳总结、合理外推"。每一环旁边标出学生自己在哪道练习上走过这一步，例如"模型构建：S1 第①步"。
- **回扣**开头的表态和潮汐问题。

## 五、可以推广到其他课的模板（规律课）

情境悬念（学生先表态）→ 回顾线索、拆小步推理 → 思想实验提出猜想 → 预测并用数据检验 → 推广成规律，用练习攻难点 → 量级感或测量 → 真题迁移 → 小结（方法链，回扣悬念）

还有三种课型，要各自定模板，留到以后：概念课、实验课、习题课。习题课就是现有的真题课件，规律课最后一段接的就是它。
