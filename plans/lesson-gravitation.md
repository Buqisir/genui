# 画布授课样课设计：万有引力定律

（2026-10-20）新方向「用我们的组件做画布授课」的第一份样课设计。

参考了三样东西：

- 用户给的《万有引力定律 教学设计》全文。
- Gauth AI Course 的 9 张截图：讲解、练习、反馈、为什么、总结、测验、完成。
- genui 现有的组件、`Segment` 分段和真题课件库。

用户的要求：不照搬那份教学设计，只从里面提取重要的东西，其余靠我们自己重新设计，要比它做得更好。所以本文分两部分：第一节是从原设计里提取的内容，第二节起是重新设计的课。

**范围**（用户定）：做一整套像 Gauth 那样的课件，6 幕连起来。只配文字讲解，不配语音，不接大模型。所有对错反馈和提示都是事先写好的固定文字；左栏没有提问框；顶栏没有播放和倍速按钮，用上一步、下一步翻页。

## 一、从原设计里提取的

### 必须保留的

| 项 | 内容 |
|---|---|
| 两个难点 | ① 对**物体间距离**的理解；② 对**普遍性**的理解：任何物体之间都有引力，并且遵循同一规律 |
| 学情 | 上一节已经由开普勒定律推出太阳对行星的引力 ∝ 1/r²；学生"不能建立明确的动态物理图像" |
| 核心事件 | 月-地检验：月球离地心约 60R，月球加速度应是 g/3600，用数据核对 |
| 核心史实 | 1687 年牛顿发表定律，1798 年卡文迪什测出 G，中间隔了 111 年，原因是日常物体之间的引力太小，测不出来 |
| 科学方法 | 提出问题 → 猜想 → 推理 → 用证据检验 → 推广 |
| 好的做法 | 用问题链衔接各段；难点拆成小步；首尾呼应（用潮汐引入，结尾解开）；扭秤用一连串设计问题来理解 |

### 原文要改的两处

- 卡文迪什实验写成了 1789 年，应为 **1798 年**。
- G 的"推荐标准值"6.67259×10⁻¹¹ 是 1986 年的值，现行值是 6.67430×10⁻¹¹。课上用 6.67×10⁻¹¹，不受影响。

### 原设计的根本问题

月-地检验在原设计里是"**先假定**平方反比，再用数据核对一下"。学生只是在验证老师已经给出的答案，并没有经历"在几个猜想里用证据做选择"。这样一来，科学探究这个目标落空了。

另外几处：

- 普遍性只靠讲（"天上地下遵循同一法则"），学生没有亲眼看到。
- 难点①"物体间距离"没有专门的环节。
- 没有任何环节能检验目标是否达成。

## 二、重新设计的两个核心想法

### 想法一：让学生用数据**选出**平方反比，而不是验证它

问题这样提：如果拉苹果和拉月亮的是同一种力，它随距离怎么变？学生从四个候选规律里挑一个：

- 不随距离变
- 和距离成反比，∝ 1/r
- 和距离的平方成反比，∝ 1/r²
- 和距离的立方成反比，∝ 1/r³

板子按学生选的规律，**从苹果的 g 出发，算出月亮应该几天绕地球一圈**，再和实际的 27.3 天比较：

| 学生选的规律 | 月球加速度 | 预测周期 | 实际 |
|---|---|---|---|
| 不变 | 9.8 m/s² | **0.46 天**（11 小时） | 27.3 天 |
| ∝ 1/r | 0.163 m/s² | **3.5 天** | 27.3 天 |
| ∝ 1/r² | 2.70×10⁻³ m/s² | **27.4 天** | 27.3 天 |
| ∝ 1/r³ | 4.5×10⁻⁵ m/s² | **213 天** | 27.3 天 |

只有平方反比能活下来。学生**亲手排除**了三个错误的猜想，这才是真正的科学探究。

这一步的计算是：

- 月球加速度 a = g(R/r)ⁿ，r/R = 60.3；
- 周期 T = 2π√(r/a)。

板上同时画出月球按每种规律"应有的"轨道运动：选了"不变"，月亮转得飞快；选了 1/r³，月亮几乎不动；只有 1/r² 和真实月亮同步。这个画面本身就是证据。

**为什么比原设计好：**

1. 原设计的"假定 → 核对"变成了"多个猜想 → 用数据淘汰"；
2. 学生用的是周期这个人人都知道的量（大约一个月），不是一个抽象的加速度；
3. 错误的猜想不是简单判错，而是给出一个可以感受的后果，比如"月亮 11 小时转一圈"。

### 想法二：用画布的缩放把"普遍性"直接展示出来

这正好用上 Gauth 那种无限画布。画布上从小到大排一条"尺度阶梯"，每一级都是同一个公式 F = Gm₁m₂/r²，代入不同的数：

| 一级 | 力 |
|---|---|
| 两个同学，相距 1 m | 1.7×10⁻⁷ N |
| 地球拉一个苹果 | 1.96 N |
| 地球拉空间站里 70 kg 的航天员 | 607 N（地面上是 686 N） |
| 地球拉月球 | 2.0×10²⁰ N |
| 太阳拉地球 | 3.5×10²² N |

学生从两个同学开始，一路**拉远镜头**，跨过 29 个数量级，用的始终是同一个式子。"天地统一"不再是一句话，而是学生自己滑过的一段画布。

两个难点的练习，放在阶梯里对应的那一级上：

- **难点②（引力是相互的）**放在"苹果"那一级；
- **难点①（物体间距离）**放在"空间站"那一级。

## 三、目标和证据

| 目标 | 学生能做到 | 证据 |
|---|---|---|
| 科学探究 | 用数据在几个猜想里做选择 | 第 2 幕：选定规律，并说出排除其他规律的理由 |
| 难点②：普遍性 | 知道同一个式子从人到天体都适用；引力是相互的 | 第 3 幕：苹果拉地球的力是 1.96 N |
| 难点①：物体间距离 | 用球心距计算 | 第 3 幕：空间站处的引力约为地面的 89% |
| 科学态度与责任 | 自己算出为什么 111 年才测出 G；说出扭秤怎样放大 | 第 4 幕：估算；扭秤设计挑战 |
| 迁移 | 用"引力 = 已知的另一种力"求天体质量 | 第 4 幕称地球；第 5 幕真题 gd21-02 |

## 四、分幕设计

版式沿用播放模式：左栏逐句讲解，右边是干净的板子，每一帧最多只有一样东西能操作，作答都是离散的。提示分三级：先指方向，再给关键一步，最后才给答案。

### 第 1 幕：悬念（约 1 分钟）

- **讲**："海上明月共潮生"，潮水跟着月亮涨落。月亮在 38 万公里外，凭什么拉得动海水？
- **作答**：表态，不判对错。拉苹果的力和拉月亮的力，是同一种力吗？
- **衔接**："如果是同一种力，那它离地球越远，就应该越弱。弱多少？月亮会告诉我们。"

### 第 2 幕：月亮来作证（本节高潮）

1. **板**：地球、苹果（标出 g = 9.8 m/s²）、月球轨道（标出 r = 60R）。月球的真实周期 27.3 天先盖住，不显示。
2. **回顾一句**："上一节，太阳拉行星的力 ∝ 1/r²。地球会不会也这样？先别急着下结论，我们把四种可能都试一遍。"
3. **作答**：从四个规律里选一个，板子算出对应的周期，月亮按这个周期运动。学生可以把四个都试一遍，每试一个，结果就留在表格里。
4. **揭晓**：翻开实际周期 27.3 天。只有 ∝ 1/r² 对得上。
5. **追问**："这个结论对月球和苹果都成立。它说明了什么？"回扣第 1 幕学生的表态。
6. **补一帧，交代原来的思路**：牛顿当年是用加速度比较的，g/3600 = 2.72×10⁻³ m/s²，月球实际的向心加速度是 2.70×10⁻³ m/s²。和我们比周期是同一件事的两种说法。

### 第 3 幕：尺度阶梯（推广，攻两个难点）

- **板**：写出 F = Gm₁m₂/r²，标明 r 是质心间的距离（均匀球体取球心距）。然后画布从"两个同学"开始，学生每点一次"拉远"，画面就上一级，力的数字跟着出现。
- **苹果那一级，练习难点②**：地球拉 0.2 kg 的苹果，力是 1.96 N。苹果拉地球的力是多少？
  - 1.96 N（正确）
  - 0
  - 远小于 1.96 N
  - 无法确定
  - **解释画在板上**：两个箭头一样长。再看效果：苹果的加速度是 9.8 m/s²，地球的加速度是 3.3×10⁻²⁵ m/s²。
- **空间站那一级，练习难点①**：空间站离地面约 400 km，航天员受的引力是地面的多少？
  - 约 90%（正确，0.885）
  - 0
  - 约 10%
  - 约 50%
  - **板**：按真实比例画地球和空间站轨道，400 km 只是地球外面一圈细线。
  - **三级提示**：
    1. r 从哪里量起？
    2. r 从 6371 km 变成 6771 km，变了百分之几？
    3. 算 (6371/6771)² = 0.885。
- **月球那一级，解开潮汐悬念**：月球对近月一侧海水的引力比对地心的大 3.4%，对远月一侧的小 3.2%。这个差别把海水往两边拉，就形成了潮汐。只讲不考。
- **拉到太阳那一级，停下**："从两个同学到太阳和地球，差了 29 个数量级，用的是同一个式子。"

### 第 4 幕：你能测出 G 吗？

- **回到阶梯最底下那一级**："两个同学之间的力只有 1.7×10⁻⁷ N，是体重的 3.4×10⁻¹⁰。牛顿写出了式子，却没法测出 G。"
- **扭秤设计挑战**：目标是让 1.7×10⁻⁷ N 量级的力被看出来。学生连续做 4 个二选一的设计决定，每选一次，板上光点在刻度上的移动量都会按比例变大或变小：
  1. 横杆长还是短？
  2. 大球用一个还是两个？
  3. 直接看细丝的扭转，还是在细丝上装一面镜子看反射光？
  4. 刻度尺放远还是近？

  4 个都选对，光点从"看不出动"变成"移动一大段"。学生亲手把一个看不见的效果放大了，这就是 1798 年卡文迪什做的事。
- **称地球**：mg = GMm/R²，所以 M = ?（数字块填空：gR²/G，代入得 5.96×10²⁴ kg）
- **衔接**："有了 G，就能算出地球、太阳、任何天体的质量。"

### 第 5 幕：真题 gd21-02 天和核心舱

- 2021 广东卷第 2 题：已知引力常量，由哪组量能算出地球质量？答案 D：线速度和绕地半径。用题库现成的课件。
- 要求学生把"地面上 mg = GMm/R²"迁移到"轨道上 GMm/r² = mv²/r"。
- 这一题也是下一节"万有引力理论的成就"的预告。

### 第 6 幕：小结

- **知识**：
  - 定律和公式；
  - G = 6.67×10⁻¹¹ N·m²/kg²；
  - 适用条件（质点或均匀球体）；
  - 易错点：r 是球心距；引力是相互的；太空有引力；r → 0 时不能用。
- **方法**：画出学生自己走过的路：提出问题（第 1 幕）→ 列出候选猜想、用数据淘汰（第 2 幕）→ 推广（第 3 幕）→ 测量（第 4 幕）→ 应用（第 5 幕）。
- **回扣**第 1 幕的表态和潮汐问题。

## 五、规律课的通用模板（从这节课抽出来）

1. 悬念，学生先表态；
2. 列出几个候选猜想，**用数据淘汰**，让学生亲手选出规律；
3. 推广，在不同尺度或场景下复用同一个规律，用练习攻难点；
4. 量级感或测量；
5. 真题迁移；
6. 小结，回扣悬念。

和原设计的模板相比，关键差别在第 2 步：从"假定 → 核对"改成"多个候选 → 淘汰"。这一步要求板子能按学生的选择**当场算出后果**，这正是 genui 组件的强项。

## 七、要做的组件和格式改动（只加不删）

| 需要 | 现状 | 做法 |
|---|---|---|
| 逐句讲解，板上内容逐步出现 | 没有 | 讲稿写法（可选）；用隐藏的步骤参数，组件写成"步骤 ≥ k 时才出现" |
| 从几个候选里选一个，板子当场算出后果 | `Param`、`Define`、`Preset` | 一个离散选择参数（n = 0, 1, 2, 3），由 `Define` 算出周期；每个选项保留结果，汇成表格 |
| 选择、数字块填空、二选一设计决策 | `Question`、`Segment ask/reveal` | 新增练习组件。正确项取自 `answers` 或 `Define`；每个干扰项写对应的错误想法和提示；校验器检查正确项等于计算值 |
| 尺度阶梯（逐级拉远） | `FlowBoard` 能缩放 | 画布上按尺度排布各级，"拉远"就是镜头移到下一级 |
| 扭秤、潮汐、空间站按真实比例 | `Sim` 可以手画 | 样课阶段先用 `Sim` |
| 播放器外壳 | 有"上课"画布和翻页模式 | 新增学生自学版式，和老师投影模式并存 |
