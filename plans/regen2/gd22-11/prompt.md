# genui 课件

命令（任意工作目录都能跑）：`/Users/huangxuewei/Projects/genui/bin/genui`

先跑 `genui docs`（无参数）读 L0 入口。组件怎么写以文档为准，不要猜属性或 `v` 工具。

## 流程

1. 读题，先把物理过程和答案想清楚。
2. 按 L0 的选型路由表决定用哪些组件。
3. `genui docs <id>` 读对应的组件卡。缺细节时 `genui docs --search <词>`，再按 id 读。
4. 写成一份课件文件。
5. `genui validate <课件.md>`。每条问题末尾都写着该读的文档，读完再改，直到没有错误。
6. `genui layout <课件.md>`，按报告改掉压线、出界。
7. 能看图时再 `genui shot <课件.md> --out <目录>`。

退出码：0 通过，1 有错误，2 用法不对。`genui docs --list` 列出全部 id。

## 输出要求

- 只输出课件文件本身，第一行就是 `---`。不要任何解释，不要用代码围栏包住整个文件。
- 头信息：`id: gd22-11`，`source: 2022 广东卷 第 11 题（实验；必考题共 42 分，原卷未单列本题分值）`，`question` 原样抄题目。
- `answers`：每个能写成数值的答案一条 `{ name, value, unit }`。`name` 必须是课件里某个 `<Param>` 或 `<Define>` 的名字，`value` 是你单独算出的数值。校验器会在初始参数下用课件里的公式重新计算并核对，误差超过 1% 就退回。题目只有字母没有数值时，给参数取代表性数值，并在正文说明。
- 选择题：头信息写 `choice`（选出的选项字母，多选按字母顺序连写，如 `BD`），按第七节第 13 条逐项判断；没有数值答案时写 `answers: []`。
- 只用规范里列出的组件和属性；表达式只能引用已声明的名字；`<Sim>` 只能用规范里列出的 `v` 工具。
- 写之前先把物理过程想清楚，确认答案正确，再决定交互方式（遵守第六、七节）。

## 题目（小球撞橡胶的实验，2022 广东卷 第 11 题（实验；必考题共 42 分，原卷未单列本题分值））

某实验小组为测量小球从某一高度释放，与某种橡胶材料碰撞导致的机械能损失，设计了如图（a）所示的装置，实验过程如下：

【图（a）】底座上立着支架，顶部横梁标「释放装置」，其下用夹具吊着一个小球，标「小球」。小球正下方一条竖直虚线。中部向右伸出的水平臂标「光电门」，虚线从门中穿过，线上有一个小圆点。底座右上方一块垫块标「固定的橡胶材料」。左侧一个方盒标「数字计时器」，有导线连到光电门。

【图（b）】螺旋测微器的示数。固定套筒上标有 0 和 5：0 mm 刻线在左，5 mm 刻线约在套筒中部，套筒上还能看到 5 mm 之后的刻线，可动刻度筒的左缘落在 7 mm 刻线与 8 mm 刻线之间，并且与毫米刻线错开的半毫米刻线已经从套筒边缘露出。可动刻度上标有 35、40、45，固定套筒的水平基准线落在 38 与 39 之间、靠近 38 的一侧（大约在 38.3 到 38.4）。

（1）让小球从某一高度由静止释放，与水平放置的橡胶材料碰撞后竖直反弹。调节光电门位置，使小球从光电门正上方释放后，在下落和反弹过程中均可通过光电门。

（2）用螺旋测微器测量小球的直径，示数如图（b）所示，小球直径 d = ____ mm。

（3）测量时，应____（选填“A”或“B”，其中 A 为“先释放小球，后接通数字计时器”，B 为“先接通数字计时器，后释放小球”）。记录小球第一次和第二次通过光电门的遮光时间 t_1 和 t_2。

（4）计算小球通过光电门的速度，已知小球的质量为 m，可得小球与橡胶材料碰撞导致的机械能损失 ΔE = ____（用字母 m、d、t_1 和 t_2 表示）。

（5）若适当调高光电门的高度，将会____（选填“增大”或“减小”）因空气阻力引起的测量误差。
