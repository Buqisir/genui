# genui 课件

命令（任意工作目录都能跑）：`/Users/huangxuewei/Projects/genui/bin/genui`

先跑 `genui docs`（无参数）读 L0 入口。组件怎么写以文档为准，不要猜属性或 `v` 工具。

## 流程

1. 读题，先把物理过程和答案想清楚。
2. 按 L0 的选型路由表决定用哪些组件。
3. `genui docs <id>` 读对应的组件卡。缺细节时 `genui docs --search <词>`，再按 id 读。
4. 写成一份课件文件。
5. `genui validate <课件.md>`。每条问题末尾都写着该读的文档，读完再改，直到没有错误。
6. `genui layout <课件.md>`，按报告改掉压线、出界。
7. 能看图时再 `genui shot <课件.md> --out <目录>`。

退出码：0 通过，1 有错误，2 用法不对。`genui docs --list` 列出全部 id。

## 输出要求

- 只输出课件文件本身，第一行就是 `---`。不要任何解释，不要用代码围栏包住整个文件。
- 头信息：`id: gd21-14`，`source: 2021 广东卷 第 14 题（计算；必考题共 42 分，原卷未单列本题分值）`，`question` 原样抄题目。
- `answers`：每个能写成数值的答案一条 `{ name, value, unit }`。`name` 必须是课件里某个 `<Param>` 或 `<Define>` 的名字，`value` 是你单独算出的数值。校验器会在初始参数下用课件里的公式重新计算并核对，误差超过 1% 就退回。题目只有字母没有数值时，给参数取代表性数值，并在正文说明。
- 选择题：头信息写 `choice`（选出的选项字母，多选按字母顺序连写，如 `BD`），按第七节第 13 条逐项判断；没有数值答案时写 `answers: []`。
- 只用规范里列出的组件和属性；表达式只能引用已声明的名字；`<Sim>` 只能用规范里列出的 `v` 工具。
- 写之前先把物理过程想清楚，确认答案正确，再决定交互方式（遵守第六、七节）。

## 题目（花瓣形电子加速器，2021 广东卷 第 14 题（计算；必考题共 42 分，原卷未单列本题分值））

图是一种花瓣形电子加速器简化示意图，空间有三个同心圆 a、b、c 围成的区域，圆 a 内为无场区，圆 a 与圆 b 之间存在辐射状电场，圆 b 与圆 c 之间有三个圆心角均略小于 90°的扇环形匀强磁场区Ⅰ、Ⅱ和Ⅲ。各区感应强度恒定，大小不同，方向均垂直纸面向外。电子以初动能 E_{k0} 从圆 b 上 P 点沿径向进入电场，电场可以反向，保证电子每次进入电场即被全程加速，已知圆 a 与圆 b 之间电势差为 U，圆 b 半径为 R，圆 c 半径为 √3 R，电子质量为 m，电荷量为 e，忽略相对论效应，取 tan 22.5° = 0.4。

（1）当 E_{k0} = 0 时，电子加速后均沿各磁场区边缘进入磁场，且在电场内相邻运动轨迹的夹角 θ 均为 45°，最终从 Q 点出射，运动轨迹如图中带箭头实线所示，求Ⅰ区的磁感应强度大小、电子在Ⅰ区磁场中的运动时间及在 Q 点出射时的动能；

（2）已知电子只要不与Ⅰ区磁场外边界相碰，就能从出射区域出射。当 E_{k0} = keU 时，要保证电子从出射区域出射，求 k 的最大值。

【图】三个同心圆。最内空白圆的边界标 a，其外灰色环的外边界标 b，灰色环内沿多条半径画有指向圆心的箭头。圆 b 与最外圆之间是三个扇环，里面画“·”，扇环之间留有窄的空白缝：左上方标Ⅲ区，右上方标Ⅰ区，下方标Ⅱ区。过圆心有水平、竖直两条虚线。P 在左侧水平虚线与圆 b 的交点，旁有小圆点，并有沿虚线指向圆心的箭头。带箭头的实线轨迹在灰色环内沿半径来回，在三个扇环里各走一段圆弧，最后从右侧Ⅰ区与Ⅱ区之间的缝向外射出；射出箭头旁标 Q，右边竖排“出射区域”。右侧虚线框框住Ⅰ区和出射处。

【图（放大）】上述虚线框的放大。内弧标 a，中弧标 b，b 以内涂灰；外弧标 c，b 与外弧之间标Ⅰ区并画“·”。圆心处两条半径的夹角标 θ，靠下的一条半径接近水平，另一条斜向上。带箭头的轨迹从灰色区沿半径向外，进入Ⅰ区后走一段圆弧再折回。图下方两条尺寸线：到圆 b 标 R，到外边界标 √3 R。
