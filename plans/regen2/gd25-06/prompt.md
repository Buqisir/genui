# genui 课件

命令（任意工作目录都能跑）：`/Users/huangxuewei/Projects/genui/bin/genui`

先跑 `genui docs`（无参数）读 L0 入口。组件怎么写以文档为准，不要猜属性或 `v` 工具。

## 流程

1. 读题，先把物理过程和答案想清楚。
2. 按 L0 的选型路由表决定用哪些组件。
3. `genui docs <id>` 读对应的组件卡。缺细节时 `genui docs --search <词>`，再按 id 读。
4. 写成一份课件文件。
5. `genui validate <课件.md>`。每条问题末尾都写着该读的文档，读完再改，直到没有错误。
6. `genui layout <课件.md>`，按报告改掉压线、出界。
7. 能看图时再 `genui shot <课件.md> --out <目录>`。

退出码：0 通过，1 有错误，2 用法不对。`genui docs --list` 列出全部 id。

## 输出要求

- 只输出课件文件本身，第一行就是 `---`。不要任何解释，不要用代码围栏包住整个文件。
- 头信息：`id: gd25-06`，`source: 2025 广东卷（部分试题）第 6 题（实验）`，`question` 原样抄题目。
- `answers`：每个能写成数值的答案一条 `{ name, value, unit }`。`name` 必须是课件里某个 `<Param>` 或 `<Define>` 的名字，`value` 是你单独算出的数值。校验器会在初始参数下用课件里的公式重新计算并核对，误差超过 1% 就退回。题目只有字母没有数值时，给参数取代表性数值，并在正文说明。
- 选择题：头信息写 `choice`（选出的选项字母，多选按字母顺序连写，如 `BD`），按第七节第 13 条逐项判断；没有数值答案时写 `answers: []`。
- 只用规范里列出的组件和属性；表达式只能引用已声明的名字；`<Sim>` 只能用规范里列出的 `v` 工具。
- 写之前先把物理过程想清楚，确认答案正确，再决定交互方式（遵守第六、七节）。

图（a）是电磁铁磁感应强度的测量电路。所用器材有：电源 E（电动势 15V，内阻不计）；电流表 A（量程有 0.6A 和 3A，内阻不计）；滑动变阻器 R_P（最大阻值 100Ω）；定值电阻 R_0（阻值 10Ω）；开关 S；磁传感器和测试仪；电磁铁（线圈电阻 16Ω）；导线若干。图（b）是实物图，图中电机和底座相固定，圆形铝盘和电机转轴相固定。

【图（a）】测量电路。左侧竖直电阻标 R_0，其上端向右接到滑动变阻器左端 a。滑动变阻器画成长方形，左下标 a、右下标 b，上方滑片 P 的箭头向下指在电阻丝上。滑片引出的导线向右再向下，与从 b 端向上引出的导线接在同一个节点，然后向右进入电流表（圆圈内写 A）。电流表再向右接到电磁铁上端。电磁铁是开口向左的 U 形铁芯，右侧铁芯上绕有线圈；开口处有一小块，标“磁传感器”，用导线接到上方方框“测试仪”。电磁铁下端向左接到开关 S，开关处于断开。开关另一侧接电源 E：电源符号左边为长竖线、右边为短竖线，下方标 E。电源左端向上接回 R_0 的下端。

【图（b）】实物图，中间有一个虚线框。框内从左上到右下：滑动变阻器 R_P（瓷管上绕着电阻丝，上方有金属滑杆，两端各有一个红色接线柱）；右上是电流表，表盘下三个接线柱标 −、0、3，表盘上有指针；左下是装在小底座上的定值电阻 R_0；中间偏下是电池 E，红色正极在左、黑色负极在右；电池右侧是一个刀闸开关。框外右侧是电磁铁（叠片铁芯，中间窗口里有线圈），线圈上端有导线从框内电流表方向接入，下端有导线从框内开关方向接入。电磁铁右侧是水平圆盘，标“圆盘”，中心竖直杆标“转轴”，转轴下方是电机，电机固定在标“底座”的板上。圆盘上方有方框“计时器”，电机下方有方框“电源”，并有导线接到电机。虚线框里 R_P、R_0、电流表之间只接了部分导线，电池、开关、电磁铁之间已有导线相连。
