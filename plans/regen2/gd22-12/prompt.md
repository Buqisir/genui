# genui 课件

命令（任意工作目录都能跑）：`/Users/huangxuewei/Projects/genui/bin/genui`

先跑 `genui docs`（无参数）读 L0 入口。组件怎么写以文档为准，不要猜属性或 `v` 工具。

## 流程

1. 读题，先把物理过程和答案想清楚。
2. 按 L0 的选型路由表决定用哪些组件。
3. `genui docs <id>` 读对应的组件卡。缺细节时 `genui docs --search <词>`，再按 id 读。
4. 写成一份课件文件。
5. `genui validate <课件.md>`。每条问题末尾都写着该读的文档，读完再改，直到没有错误。
6. `genui layout <课件.md>`，按报告改掉压线、出界。
7. 能看图时再 `genui shot <课件.md> --out <目录>`。

退出码：0 通过，1 有错误，2 用法不对。`genui docs --list` 列出全部 id。

## 输出要求

- 只输出课件文件本身，第一行就是 `---`。不要任何解释，不要用代码围栏包住整个文件。
- 头信息：`id: gd22-12`，`source: 2022 广东卷 第 12 题（实验；必考题共 42 分，原卷未单列本题分值）`，`question` 原样抄题目。
- `answers`：每个能写成数值的答案一条 `{ name, value, unit }`。`name` 必须是课件里某个 `<Param>` 或 `<Define>` 的名字，`value` 是你单独算出的数值。校验器会在初始参数下用课件里的公式重新计算并核对，误差超过 1% 就退回。题目只有字母没有数值时，给参数取代表性数值，并在正文说明。
- 选择题：头信息写 `choice`（选出的选项字母，多选按字母顺序连写，如 `BD`），按第七节第 13 条逐项判断；没有数值答案时写 `answers: []`。
- 只用规范里列出的组件和属性；表达式只能引用已声明的名字；`<Sim>` 只能用规范里列出的 `v` 工具。
- 写之前先把物理过程想清楚，确认答案正确，再决定交互方式（遵守第六、七节）。

## 题目（弹性导电绳拉长，2022 广东卷 第 12 题（实验；必考题共 42 分，原卷未单列本题分值））

弹性导电绳逐步成为智能控制系统中部分传感器的敏感元件，某同学测量弹性导电绳的电阻与拉伸后绳长之间的关系，实验过程如下：

（1）装置安装和电路连接；如图（a）所示，导电绳的一端固定，另一端作为拉伸端，两端分别用带有金属夹 A、B 的导线接入如图（b）所示的电路中。

【图（a）】一块木板，右端标「木板」。木板上方一根水平的导电绳，标「导电绳」。左端固定在支架上的金属夹，标「金属夹A」，有导线引出；右端金属夹标「金属夹B」，夹子装在一个小滚轮上，也有导线引出。绳的正下方是一把刻度尺，标「刻度尺」。

【图（b）】电路：电源 E 在左下方，与开关 S_1、滑动变阻器 R 串联，R 的滑片画在电阻丝右端，箭头向下接到下边的导线上。右侧竖直支路里有电流表，圆圈内标 A。电流表上端分成三条并联支路：最上是电压表，圆圈内标 V；中间是一个矩形电阻，标「定值电阻」；最下是矩形电阻，标「导电绳 R_x」，并与开关 S_2 串联。三条支路的左右端分别接在一起。

【图（c）】R_x–L 图像。横轴 L/cm，标度 51.00、51.20、51.40、51.60、51.80、52.00，每 0.20 cm 分成 5 小格。纵轴 R_x/kΩ，标度 1.15、1.20、1.25、1.30、1.35、1.40，每 0.05 kΩ 分成 5 小格。一条直线从左下升到右上。直线附近有五个蓝点，按网格估读大约在 (51.10 cm, 1.16 kΩ)、(51.30 cm, 1.21 kΩ)、(51.50 cm, 1.26 kΩ)、(51.70 cm, 1.31 kΩ)、(51.90 cm, 1.35 kΩ)；前四个点在这条直线上，最右边一点略低于直线。直线延伸到横轴 52.00 cm 附近时，纵轴读数大约在 1.36 kΩ 与 1.37 kΩ 之间。

（2）导电绳拉伸后的长度 L 及其电阻 R_x 的测量

①将导电绳拉伸后，用刻度尺测量并记录 A、B 间的距离，即为导电绳拉伸后的长度 L。

②将滑动变阻器 R 的滑片滑到最右端。断开开关 S_2，闭合开关 S_1，调节 R，使电压表和电流表的指针偏转到合适位置。记录两表的示数 U 和 I_1。

③闭合 S_2，电压表的示数____（选填“变大”或“变小”）。调节 R 使电压表的示数仍为 U，记录电流表的示数 I_2，则此时导电绳的电阻 R_x = ____（用 I_1、I_2 和 U 表示）。

④断开 S_1，增大导电绳拉伸量，测量并记录 A、B 间的距离，重复步骤②和③。

（3）该电压表内阻对导电绳电阻的测量值____（选填“有”或“无”）影响。

（4）图11(c)是根据部分实验数据描绘的 R_x–L 图线。将该导电绳两端固定在某种机械臂上，当机械臂弯曲后，测得导电绳的电阻 R_x 为 1.33 kΩ，则由图线可读出导电绳拉伸后的长度为____cm，即为机械臂弯曲后的长度。
