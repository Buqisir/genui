# genui 课件

命令（任意工作目录都能跑）：`/Users/huangxuewei/Projects/genui/bin/genui`

先跑 `genui docs`（无参数）读 L0 入口。组件怎么写以文档为准，不要猜属性或 `v` 工具。

## 流程

1. 读题，先把物理过程和答案想清楚。
2. 按 L0 的选型路由表决定用哪些组件。
3. `genui docs <id>` 读对应的组件卡。缺细节时 `genui docs --search <词>`，再按 id 读。
4. 写成一份课件文件。
5. `genui validate <课件.md>`。每条问题末尾都写着该读的文档，读完再改，直到没有错误。
6. `genui layout <课件.md>`，按报告改掉压线、出界。
7. 能看图时再 `genui shot <课件.md> --out <目录>`。

退出码：0 通过，1 有错误，2 用法不对。`genui docs --list` 列出全部 id。

## 输出要求

- 只输出课件文件本身，第一行就是 `---`。不要任何解释，不要用代码围栏包住整个文件。
- 头信息：`id: gd24-15`，`source: 2024 广东卷 第 15 题（计算）`，`question` 原样抄题目。
- `answers`：每个能写成数值的答案一条 `{ name, value, unit }`。`name` 必须是课件里某个 `<Param>` 或 `<Define>` 的名字，`value` 是你单独算出的数值。校验器会在初始参数下用课件里的公式重新计算并核对，误差超过 1% 就退回。题目只有字母没有数值时，给参数取代表性数值，并在正文说明。
- 选择题：头信息写 `choice`（选出的选项字母，多选按字母顺序连写，如 `BD`），按第七节第 13 条逐项判断；没有数值答案时写 `answers: []`。
- 只用规范里列出的组件和属性；表达式只能引用已声明的名字；`<Sim>` 只能用规范里列出的 `v` 工具。
- 写之前先把物理过程想清楚，确认答案正确，再决定交互方式（遵守第六、七节）。

## 题目（金属板间的带电粒子，2024 广东卷 第 15 题（计算））

如图甲所示。两块平行正对的金属板水平放置，板间加上如图乙所示幅值为 U_0、周期为 t_0 的交变电压。金属板左侧存在一水平向右的恒定匀强电场，右侧分布着垂直纸面向外的匀强磁场。磁感应强度大小为 B。一带电粒子在 t = 0 时刻从左侧电场某处由静止释放，在 t = t_0 时刻从下板左端边缘位置水平向右进入金属板间的电场内，在 t = 2t_0 时刻第一次离开金属板间的电场、水平向右进入磁场，并在 t = 3t_0 时刻从下板右端边缘位置再次水平进入金属板间的电场。已知金属板的板长是板间距离的 π/3 倍，粒子质量为 m。忽略粒子所受的重力和场的边缘效应。

（1）判断带电粒子的电性并求其所带的电荷量 q；

（2）求金属板的板间距离 D 和带电粒子在 t = t_0 时刻的速度大小 v；

（3）求从 t = 0 时刻开始到带电粒子最终碰到上金属板的过程中，电场力对粒子做的功 W。

【图甲】两块水平平行的金属板，每块板的右端各有一个小圆接线端，上下接线端之间有短线相连。金属板左侧标“电场”，画有若干水平向右的箭头。一条虚线轨迹从左侧水平向右，在下板左端的高度进入两板之间，在板间向上弯曲，到板的右端时又成为水平向右并离开板间。板的右侧是一片“·”，标 B，旁注“磁场”。轨迹进入这片区域后向下弯成一段圆弧，回到下板的右端；弧线上有沿轨迹的箭头。

【图乙】u–t 图像。纵轴 u，横轴 t，原点标 O。纵轴正方向标 U_0，负方向标 −U_0。横轴标 0.5t_0、t_0、1.5t_0、2t_0。图像是方波：从 t = 0 到 0.5t_0 为 −U_0，从 0.5t_0 到 t_0 为 U_0，从 t_0 到 1.5t_0 为 −U_0，从 1.5t_0 到 2t_0 为 U_0，在 2t_0 处再跳到 −U_0 并画出一小段水平线。
