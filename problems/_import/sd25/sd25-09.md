均匀介质中分别沿 x 轴负向和正向传播的甲、乙两列简谐横波，振幅均为 A = 10 cm，波速均为 v = 4 m/s，M、N 为介质中的质点。t = 0 时刻的波形图如图所示，M、N 的位移均为 y = 5\sqrt{2}\ \text{cm}。下列说法正确的是（　　）

A. 甲波的周期为 4 s

B. 乙波的波长为 8 m

C. t = 0.5 s 时，M 向 y 轴正方向运动

D. t = 0.5 s 时，N 向 y 轴负方向运动

【图】t = 0 的波形。横轴 x（单位 m）、纵轴 y（单位 cm）。甲波（实线）位于 x 轴负半轴，波峰在 x = −4 m、y = 10 cm，波谷在 x = −8 m、y = −10 cm，在 x = 0 处与横轴相交，传播方向向左。乙波（虚线）位于 x 轴正半轴，传播方向向右，波峰在 x = 4 m、y = 10 cm，波谷在 x = 8 m、y = −10 cm。质点 M 在 x = −6 m、y = 5\sqrt2 cm，质点 N 在 x = 2 m、y = 5\sqrt2 cm。
