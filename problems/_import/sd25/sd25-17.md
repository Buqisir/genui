  （1）水平方向动量守恒：m v_1 = M v_2。能量守恒：mgh = (1/2)m v_1^2 + (1/2)M v_2^2。代入 m = 1/2 kg、M = 9/2 kg、h = 2 m、g = 10 m/s^2，得 v_1 = 6 m/s，方向水平向左；v_2 = 2/3 m/s，方向水平向右。（2）小球与 a 碰撞后竖直速度为 0，水平方向 m v_1 = (m + m_a) v_3，得 v_3 = 2 m/s。弹簧拉力达 F = 15 N 时 b 解除锁定，形变量 x_1 = F/k = 0.3 m，机械能守恒 (1/2)(m + m_a) v_3^2 = (1/2)(m + m_a) v_4^2 + (1/2)k x_1^2，得 v_4 = 1 m/s。解锁后三者共速时弹性势能最大：(m + m_a) v_4 = (m + m_a + m_b) v_b，得 v_b = 2/3 m/s，方向水平向左；E_pm = (1/2)(m + m_a) v_4^2 + (1/2)k x_1^2 − (1/2)(m + m_a + m_b) v_b^2 = 5/2 J。

如图所示，内有弯曲光滑轨道的方形物体置于光滑水平面上，P、Q 分别为轨道的两个端点且位于同一高度，P 处轨道的切线沿水平方向，Q 处轨道的切线沿竖直方向。小物块 a、b 用轻弹簧连接置于光滑水平面上，b 被锁定。一质量 m = \dfrac{1}{2}\ \text{kg} 的小球自 Q 点正上方 h = 2\ \text{m} 处自由下落，无能量损失地滑入轨道，并从 P 点水平抛出，恰好击中 a，与 a 粘在一起且不弹起。当弹簧拉力达到 F = 15\ \text{N} 时，b 解除锁定开始运动。已知 a 的质量 m_a = 1\ \text{kg}，b 的质量 m_b = \dfrac{3}{4}\ \text{kg}，方形物体的质量 M = \dfrac{9}{2}\ \text{kg}，重力加速度大小 g = 10\ \text{m/s}^{2}，弹簧的劲度系数 k = 50\ \text{N/m}，整个过程弹簧均在弹性限度内，弹性势能表达式 E_p = \dfrac{1}{2}kx^{2}（x 为弹簧的形变量），所有过程不计空气阻力。求：

（1）小球到达 P 点时，小球及方形物体相对于地面的速度大小 v_1、v_2；

（2）弹簧弹性势能最大时，b 的速度大小 v_b 及弹性势能的最大值 E_{pm}。

【图】装置侧视。左侧物块 a、b 用轻弹簧连接，b 被锁定在水平面上。右侧是内有弯曲轨道的方形物体：左端端口 P 切线水平，右端端口 Q 切线竖直，P、Q 同高，轨道中间下凹。小球从 Q 正上方高 h 处自由下落，图中 h 用竖直箭头标注。
