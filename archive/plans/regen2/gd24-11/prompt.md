# genui 课件

命令（任意工作目录都能跑）：`/Users/huangxuewei/Projects/genui/bin/genui`

先跑 `genui docs`（无参数）读 L0 入口。组件怎么写以文档为准，不要猜属性或 `v` 工具。

## 流程

1. 读题，先把物理过程和答案想清楚。
2. 按 L0 的选型路由表决定用哪些组件。
3. `genui docs <id>` 读对应的组件卡。缺细节时 `genui docs --search <词>`，再按 id 读。
4. 写成一份课件文件。
5. `genui validate <课件.md>`。每条问题末尾都写着该读的文档，读完再改，直到没有错误。
6. `genui layout <课件.md>`，按报告改掉压线、出界。
7. 能看图时再 `genui shot <课件.md> --out <目录>`。

退出码：0 通过，1 有错误，2 用法不对。`genui docs --list` 列出全部 id。

## 输出要求

- 只输出课件文件本身，第一行就是 `---`。不要任何解释，不要用代码围栏包住整个文件。
- 头信息：`id: gd24-11`，`source: 2024 广东卷 第 11 题（实验）`，`question` 原样抄题目。
- `answers`：每个能写成数值的答案一条 `{ name, value, unit }`。`name` 必须是课件里某个 `<Param>` 或 `<Define>` 的名字，`value` 是你单独算出的数值。校验器会在初始参数下用课件里的公式重新计算并核对，误差超过 1% 就退回。题目只有字母没有数值时，给参数取代表性数值，并在正文说明。
- 选择题：头信息写 `choice`（选出的选项字母，多选按字母顺序连写，如 `BD`），按第七节第 13 条逐项判断；没有数值答案时写 `answers: []`。
- 只用规范里列出的组件和属性；表达式只能引用已声明的名字；`<Sim>` 只能用规范里列出的 `v` 工具。
- 写之前先把物理过程想清楚，确认答案正确，再决定交互方式（遵守第六、七节）。

## 题目（三个必做实验，2024 广东卷 第 11 题（实验））

下列是《普通高中物理课程标准》中列出的三个必做实验的部分步骤，请完成实验操作和计算。

（1）图甲是“探究加速度与物体受力、物体质量的关系”实验装置示意图。图中木板右端垫高的目的是_____。图乙是实验得到纸带的一部分，每相邻两计数点间有四个点未画出。相邻计数点的间距已在图中给出。打点计时器电源频率为 50Hz，则小车的加速度大小为_____ m/s^2（结果保留 3 位有效数字）。

【图甲】水平桌面上放一块木板，木板右端垫高，板上标“木板”。木板右端安装打点计时器，标“打点计时器”，纸带从计时器向右伸出，标“纸带”。木板上有一辆小车，标“小车”。木板左端有定滑轮，细绳跨过滑轮，下端悬挂砝码盘和砝码，标“砝码盘和砝码”。

【图乙】一条纸带，两端为波浪形撕口。从左到右有 7 个计数点，相邻计数点的间距（单位 cm）依次标为 16.29、13.43、10.59、7.72、4.88、2.01。

（2）在“长度的测量及其测量工具的选用”实验中，某同学用 50 分度的游标卡尺测量一圆柱体的长度，示数如图丙所示，图丁为局部放大图，读数为_____cm。

【图丙】一把游标卡尺，量爪之间夹着一小段圆柱。主尺和游标的刻度在尺的右部，旁边标“丙”。

【图丁】丙的局部放大，标“丁”。主尺标出 4、5、6（cm），其间有毫米刻线。游标尺标出 0、1、2、3、4。游标 0 线落在主尺 4 cm 之后第 1 条毫米刻线（4.1 cm）处，紧靠该线右侧；游标上从 0 数起的第 4 条刻线与主尺的一条刻线对齐。

（3）在“用双缝干涉实验测量光的波长”实验调节过程中，在光具座上安装光源、遮光筒和光屏。遮光筒不可调节。打开并调节_____。使光束沿遮光筒的轴线把光屏照亮。取下光屏，装上单缝、双缝和测量头。调节测量头，并缓慢调节单缝的角度直到目镜中观察到_____。
