# genui 课件

命令（任意工作目录都能跑）：`/Users/huangxuewei/Projects/genui/bin/genui`

先跑 `genui docs`（无参数）读 L0 入口。组件怎么写以文档为准，不要猜属性或 `v` 工具。

## 流程

1. 读题，先把物理过程和答案想清楚。
2. 按 L0 的选型路由表决定用哪些组件。
3. `genui docs <id>` 读对应的组件卡。缺细节时 `genui docs --search <词>`，再按 id 读。
4. 写成一份课件文件。
5. `genui validate <课件.md>`。每条问题末尾都写着该读的文档，读完再改，直到没有错误。
6. `genui layout <课件.md>`，按报告改掉压线、出界。
7. 能看图时再 `genui shot <课件.md> --out <目录>`。

退出码：0 通过，1 有错误，2 用法不对。`genui docs --list` 列出全部 id。

## 输出要求

- 只输出课件文件本身，第一行就是 `---`。不要任何解释，不要用代码围栏包住整个文件。
- 头信息：`id: gd21-08`，`source: 2021 广东卷 第 8 题（多选，6 分）`，`question` 原样抄题目。
- `answers`：每个能写成数值的答案一条 `{ name, value, unit }`。`name` 必须是课件里某个 `<Param>` 或 `<Define>` 的名字，`value` 是你单独算出的数值。校验器会在初始参数下用课件里的公式重新计算并核对，误差超过 1% 就退回。题目只有字母没有数值时，给参数取代表性数值，并在正文说明。
- 选择题：头信息写 `choice`（选出的选项字母，多选按字母顺序连写，如 `BD`），按第七节第 13 条逐项判断；没有数值答案时写 `answers: []`。
- 只用规范里列出的组件和属性；表达式只能引用已声明的名字；`<Sim>` 只能用规范里列出的 `v` 工具。
- 写之前先把物理过程想清楚，确认答案正确，再决定交互方式（遵守第六、七节）。

## 题目（五条龙舟的赛程，2021 广东卷 第 8 题（多选，6 分））

赛龙舟是端午节的传统活动。下列 v–t 和 s–t 图像描述了五条相同的龙舟从同一起点线同时出发、沿长直河道划向同一终点线的运动全过程，其中能反映龙舟甲与其它龙舟在途中出现船头并齐的有（　　）

A.【图】v–t 图，无刻度，原点 O。甲、乙都从 O 出发。甲上升较陡后转入水平，末端再略向上抬起，然后一条竖直虚线落到 t 轴，虚线顶端标“甲”。乙上升更缓、平台更低，水平段比甲更长，末端也略向上抬起，竖直虚线落在更靠右处，顶端标“乙”。甲的曲线全程在乙的上方，两曲线不相交。

B.【图】v–t 图，无刻度，原点 O。丙从 O 较陡上升后转入水平平台；甲上升较慢，开始在丙下方，随后超过丙并转入更高的水平段，末端略再升高。两曲线相交一次。甲、丙末端各有竖直虚线落到 t 轴，甲的虚线略在丙的左边，虚线顶端分别标“甲”“丙”。

C.【图】s–t 图，无刻度，原点 O。甲、丁都从 O 出发，曲线向上凹（越来越陡）。丁全程在甲上方，两曲线不相交。二者末端到达同一条水平虚线，丁的竖直虚线更靠左，甲更靠右，虚线顶端分别标“丁”“甲”。

D.【图】s–t 图，无刻度，原点 O。甲、戊都从 O 出发，曲线向上凹，两曲线相交一次。相交前甲在戊上方，相交后戊在上方，戊先到达同一条水平虚线，甲后到达。末端各有竖直虚线落到 t 轴，分别标“戊”“甲”。
