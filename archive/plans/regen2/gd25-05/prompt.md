# genui 课件

命令（任意工作目录都能跑）：`/Users/huangxuewei/Projects/genui/bin/genui`

先跑 `genui docs`（无参数）读 L0 入口。组件怎么写以文档为准，不要猜属性或 `v` 工具。

## 流程

1. 读题，先把物理过程和答案想清楚。
2. 按 L0 的选型路由表决定用哪些组件。
3. `genui docs <id>` 读对应的组件卡。缺细节时 `genui docs --search <词>`，再按 id 读。
4. 写成一份课件文件。
5. `genui validate <课件.md>`。每条问题末尾都写着该读的文档，读完再改，直到没有错误。
6. `genui layout <课件.md>`，按报告改掉压线、出界。
7. 能看图时再 `genui shot <课件.md> --out <目录>`。

退出码：0 通过，1 有错误，2 用法不对。`genui docs --list` 列出全部 id。

## 输出要求

- 只输出课件文件本身，第一行就是 `---`。不要任何解释，不要用代码围栏包住整个文件。
- 头信息：`id: gd25-05`，`source: 2025 广东卷（部分试题）第 5 题（实验）`，`question` 原样抄题目。
- `answers`：每个能写成数值的答案一条 `{ name, value, unit }`。`name` 必须是课件里某个 `<Param>` 或 `<Define>` 的名字，`value` 是你单独算出的数值。校验器会在初始参数下用课件里的公式重新计算并核对，误差超过 1% 就退回。题目只有字母没有数值时，给参数取代表性数值，并在正文说明。
- 选择题：头信息写 `choice`（选出的选项字母，多选按字母顺序连写，如 `BD`），按第七节第 13 条逐项判断；没有数值答案时写 `answers: []`。
- 只用规范里列出的组件和属性；表达式只能引用已声明的名字；`<Sim>` 只能用规范里列出的 `v` 工具。
- 写之前先把物理过程想清楚，确认答案正确，再决定交互方式（遵守第六、七节）。

## 题目（测直径与小车碰撞，2025 广东卷（部分试题）第 5 题（实验））

请完成下列实验操作和计算。

(1)在“长度的测量及其测量工具的选用”实验中，用螺旋测微器测量小球的直径，示数如图所示，读数 ____ mm。

【图】螺旋测微器。固定刻度的水平基准线下方标有 0 和 5，上方是半毫米刻线。从 0 起整毫米刻线依次露出，套筒左端面与 8 mm 刻线对齐，8.5 mm 刻线未露出。可动刻度可见 20、25，水平基准线与 26 刻线对齐（25 的上一格）。

(2)实验小组利用小车碰撞实验测量吸能材料的性能，装置如图所示，图中轨道由轨道甲和乙平滑拼接而成，且轨道乙倾角较大。

【图】一根水平长梁做底座，左右两端各有一条支腿。轨道整体左低右高。左段坡度较小，标“轨道甲”，从左到右依次是光电门B、小车1、光电门A。连接处下方有两个螺母顶在底座上。右段坡度明显更大，标“轨道乙”，向右上方倾斜；轨道面上标有点 M，M 的上方是小车2；右端有立柱支到底座上。

①选取相同的两辆小车，分别安装宽度为 1.00 cm 的遮光条。

②轨道调节。

调节螺母使轨道甲、乙连接处适当升高。将小车在轨道乙上释放，若测得小车通过光电门 A 和 B 的 ____ 。证明已平衡小车在轨道甲上所受摩擦力及其他阻力。

③碰撞测试

先将小车 1 静置于光电门 A 和 B 中间，再将小车 2 在 M 点由静止释放，测得小车 2 通过光电门 A 的时间为 t_2，碰撞后小车 1 通过光电门 B 的时间为 t_1。若 t_2 ____ t_1，可将两小车的碰撞视为弹性碰撞。

④吸能材料性能测试。

将吸能材料紧贴于小车 2 的前端。重复步骤③。测得小车 2 通过光电门 A 的时间为 10.00 ms，两车碰撞后，依次测得小车 1 和 2 通过光电门 B 的时间分别为 15.00 ms、30.00 ms，不计吸能材料的质量，计算可得碰撞后两小车总动能与碰撞前小车 2 动能的比值为 ____ （结果保留 2 位有效数字）。
