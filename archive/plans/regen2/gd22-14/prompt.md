# genui 课件

命令（任意工作目录都能跑）：`/Users/huangxuewei/Projects/genui/bin/genui`

先跑 `genui docs`（无参数）读 L0 入口。组件怎么写以文档为准，不要猜属性或 `v` 工具。

## 流程

1. 读题，先把物理过程和答案想清楚。
2. 按 L0 的选型路由表决定用哪些组件。
3. `genui docs <id>` 读对应的组件卡。缺细节时 `genui docs --search <词>`，再按 id 读。
4. 写成一份课件文件。
5. `genui validate <课件.md>`。每条问题末尾都写着该读的文档，读完再改，直到没有错误。
6. `genui layout <课件.md>`，按报告改掉压线、出界。
7. 能看图时再 `genui shot <课件.md> --out <目录>`。

退出码：0 通过，1 有错误，2 用法不对。`genui docs --list` 列出全部 id。

## 输出要求

- 只输出课件文件本身，第一行就是 `---`。不要任何解释，不要用代码围栏包住整个文件。
- 头信息：`id: gd22-14`，`source: 2022 广东卷 第 14 题（计算；必考题共 42 分，原卷未单列本题分值）`，`question` 原样抄题目。
- `answers`：每个能写成数值的答案一条 `{ name, value, unit }`。`name` 必须是课件里某个 `<Param>` 或 `<Define>` 的名字，`value` 是你单独算出的数值。校验器会在初始参数下用课件里的公式重新计算并核对，误差超过 1% 就退回。题目只有字母没有数值时，给参数取代表性数值，并在正文说明。
- 选择题：头信息写 `choice`（选出的选项字母，多选按字母顺序连写，如 `BD`），按第七节第 13 条逐项判断；没有数值答案时写 `answers: []`。
- 只用规范里列出的组件和属性；表达式只能引用已声明的名字；`<Sim>` 只能用规范里列出的 `v` 工具。
- 写之前先把物理过程想清楚，确认答案正确，再决定交互方式（遵守第六、七节）。

## 题目（极板间的两滴油，2022 广东卷 第 14 题（计算；必考题共 42 分，原卷未单列本题分值））

密立根通过观测油滴的运动规律证明了电荷的量子性，因此获得了 1923 年的诺贝尔奖。图是密立根油滴实验的原理示意图，两个水平放置、相距为 d 的足够大金属极板，上极板中央有一小孔。通过小孔喷入一些小油滴，由于碰撞或摩擦，部分油滴带上了电荷。有两个质量均为 m_0、位于同一竖直线上的球形小油滴 A 和 B，在时间 t 内都匀速下落了距离 h_1。此时给两极板加上电压 U（上极板接正极），A 继续以原速度下落，B 经过一段时间后向上匀速运动。B 在匀速运动时间 t 内上升了距离 h_2（h_2 ≠ h_1），随后与 A 合并，形成一个球形新油滴，继续在两极板间运动直至匀速。已知球形油滴受到的空气阻力大小为 f = k m^{1/3} v，其中 k 为比例系数，m 为油滴质量，v 为油滴运动速率，不计空气浮力，重力加速度为 g。

求：

（1）比例系数 k；

（2）油滴 A、B 的带电量和电性；B 上升距离 h_2 电势能的变化量；

（3）新油滴匀速运动速度的大小和方向。

【图】两条水平极板。上极板中间断开，断开处上方标「小孔」，上极板右端标「+」；下极板右端标「−」。左侧一条竖直双箭头跨越两板的间距，旁边标 d、U。小孔正下方、两板之间有两个竖直排列的实心圆点，上面的标 A，下面的标 B。
