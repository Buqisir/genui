# genui 课件

命令（任意工作目录都能跑）：`/Users/huangxuewei/Projects/genui/bin/genui`

先跑 `genui docs`（无参数）读 L0 入口。组件怎么写以文档为准，不要猜属性或 `v` 工具。

## 流程

1. 读题，先把物理过程和答案想清楚。
2. 按 L0 的选型路由表决定用哪些组件。
3. `genui docs <id>` 读对应的组件卡。缺细节时 `genui docs --search <词>`，再按 id 读。
4. 写成一份课件文件。
5. `genui validate <课件.md>`。每条问题末尾都写着该读的文档，读完再改，直到没有错误。
6. `genui layout <课件.md>`，按报告改掉压线、出界。
7. 能看图时再 `genui shot <课件.md> --out <目录>`。

退出码：0 通过，1 有错误，2 用法不对。`genui docs --list` 列出全部 id。

## 输出要求

- 只输出课件文件本身，第一行就是 `---`。不要任何解释，不要用代码围栏包住整个文件。
- 头信息：`id: gd21-11`，`source: 2021 广东卷 第 11 题（实验；必考题共 42 分，原卷未单列本题分值）`，`question` 原样抄题目。
- `answers`：每个能写成数值的答案一条 `{ name, value, unit }`。`name` 必须是课件里某个 `<Param>` 或 `<Define>` 的名字，`value` 是你单独算出的数值。校验器会在初始参数下用课件里的公式重新计算并核对，误差超过 1% 就退回。题目只有字母没有数值时，给参数取代表性数值，并在正文说明。
- 选择题：头信息写 `choice`（选出的选项字母，多选按字母顺序连写，如 `BD`），按第七节第 13 条逐项判断；没有数值答案时写 `answers: []`。
- 只用规范里列出的组件和属性；表达式只能引用已声明的名字；`<Sim>` 只能用规范里列出的 `v` 工具。
- 写之前先把物理过程想清楚，确认答案正确，再决定交互方式（遵守第六、七节）。

## 题目（斜管里的缓冲弹簧，2021 广东卷 第 11 题（实验；必考题共 42 分，原卷未单列本题分值））

某兴趣小组测量一缓冲装置中弹簧的劲度系数，缓冲装置如图所示，固定在斜面上的透明有机玻璃管与水平面夹角为 30°，弹簧固定在有机玻璃管底端。实验过程如下：先沿管轴线方向固定一毫米刻度尺，再将单个质量为 200 g 的钢球（直径略小于玻璃管内径）逐个从管口滑进，每滑进一个钢球，待弹簧静止，记录管内钢球的个数 n 和弹簧上端对应的刻度尺示数 L_0，数据如表所示。实验过程中弹簧始终处于弹性限度内。采用逐差法计算弹簧压缩量，进而计算其劲度系数。

【图】斜面上固定一根透明管，管与水平面的夹角标 30°。管内底部有弹簧，弹簧上叠放若干钢球，靠近弹簧的画成实线圆，上方几个画成虚线圆。管的上沿有一把刻度尺，尺的上端（管口一侧）标 0 cm，尺旁标“刻度尺”，管旁标“有机玻璃管”。斜面下方有地面斜线。

| --- | --- | --- | --- | --- | --- | --- |
| L_n / cm | 8.04 | 10.03 | 12.05 | 14.07 | 16.11 | 18.09 |

（1）利用 ΔL_i = L_{i+3} − L_i（i = 1, 2, 3）计算弹簧的压缩量：ΔL_1 = 6.03 cm，ΔL_2 = 6.08 cm，

ΔL_3 = ______ cm，压缩量的平均值 ΔL（字母上方有一横）= (ΔL_1 + ΔL_2 + ΔL_3)/3 = ______ cm；

（2）上述 ΔL（字母上方有一横）是管中增加 ______ 个钢球时产生的弹簧平均压缩量；

（3）忽略摩擦，重力加速度 g 取 9.80 m/s^2，该弹簧的劲度系数为 ______ N/m。（结果保留 3 位有效数字）
