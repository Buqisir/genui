## 一、题目条件分析

木柄静止，三根轻绳都绷紧。O 是三绳结点，质量不计，只受三根绳的拉力，三力平衡。

- 上绳竖直，拉力大小为 $F$，方向沿绳向上（支架把结点向上拉）。
- 下绳 OA、OB 的拉力大小为 $F_1$、$F_2$，且题目给出 $F_1 = F_2$。
- $\angle AOB = 60°$，就是两根下绳的夹角。图中木柄水平，两绳左右分开。
- 考试图里 $F_1$、$F_2$ 的箭头指向 O，画的是绳拉木柄（把 A、B 拉向 O）。对结点 O 来说，每根绳都把结点沿绳向外拉：上绳竖直向上，$F_1$ 沿 OA 指向 A，$F_2$ 沿 OB 指向 B。轻绳两端拉力大小相等，下面按结点来分析。

石磨和木柄有多重，题目没有给。重力只决定三根绳拉力的总大小，不改变 $F$ 与 $F_1$ 的比值。下面的互动把 $F_1$ 取成代表值 $10\ \text{N}$，便于和受力图解出的 $F$ 对数值；换成别的 $F_1$，比值不变。

水平方向合力为零，而 $F_1 = F_2$，所以上绳既然竖直，两根下绳与竖直方向的夹角必定相等。两绳夹角是 $60°$，因此每一边都是

$$
\alpha = \frac{60°}{2} = 30°
$$

## 二、完整解答

### 正交分解

取水平向右为 $x$ 正方向，竖直向上为 $y$ 正方向。$F$ 沿 $+y$。$F_1$、$F_2$ 各与竖直向下方向成 $30°$，竖直分力都向下，水平分力等大反向。

竖直方向：

$$
F = F_1\cos 30° + F_2\cos 30°
$$

$$
\cos 30° = \frac{\sqrt{3}}{2},\qquad F_1 = F_2
$$

$$
F = 2F_1\cdot\frac{\sqrt{3}}{2} = \sqrt{3}\,F_1
$$

水平方向：$F_1\sin 30° = F_2\sin 30°$，互相抵消，合力为零，与上面的结论不矛盾。

$$
\boxed{F = \sqrt{3}\,F_1}
$$

代表值 $F_1 = 10\ \text{N}$ 时，水平分力各为 $F_1\sin 30° = 5\ \text{N}$，竖直分力各为 $F_1\cos 30° = 5\sqrt{3}\ \text{N}$。上绳要平衡两个竖直分力：

$$
F = 10\sqrt{3}\ \text{N} = \boxed{17.320508\ \text{N}}
$$

$$
\frac{F}{F_1} = \sqrt{3} = \boxed{1.732051}
$$

### 矢量合成（同一结果）

$F_1$ 与 $F_2$ 大小相等，夹角 $60°$，合力沿角平分线竖直向下，大小

$$
R = \sqrt{F_1^2 + F_1^2 + 2F_1F_1\cos 60°} = \sqrt{3F_1^2} = \sqrt{3}\,F_1
$$

$F$ 与这个合力等大反向，所以仍然是 $F = \sqrt{3}\,F_1$。两等大拉力的合力最大为 $2F_1$（两力同向），最小为 $0$（两力反向），因此在本题条件下

$$
0 \le F \le 2F_1
$$

### 逐项判断

**A. $F = F_1$：错误。**

若把 $60°$ 误当成每根下绳与竖直方向的夹角，就会算成

$$
F = 2F_1\cos 60° = 2F_1\cdot\frac{1}{2} = F_1
$$

题目的 $60°$ 是两绳之间的夹角，与竖直方向的夹角只有 $30°$。$F = F_1$ 要 $2\cos\alpha = 1$，即 $\alpha = 60°$，对应 $\angle AOB = 120°$，不是题目的 $60°$。用余弦定理时若把夹角误代成 $120°$，$\cos 120° = -\tfrac{1}{2}$，也会得到 $R = F_1$，同样不是本题。

**B. $F = 2F_1$：错误。**

$2F_1$ 是把两个拉力的大小直接相加。只有两根下绳都竖直、夹角为 $0°$、没有水平分力时，才有 $F = F_1 + F_2 = 2F_1$。夹角 $60°$ 时，每根绳的竖直分力只是 $F_1\cos 30° = \dfrac{\sqrt{3}}{2}F_1$，合起来是 $\sqrt{3}\,F_1$，比 $2F_1$ 小。

**C. $F = 3F_1$：错误。**

余弦定理给出的是 $R^2 = 3F_1^2$，开方之后是 $R = \sqrt{3}\,F_1$。把 $3F_1^2$ 当成 $3F_1$，就漏掉了开方。另外 $2\cos\alpha = 3$ 要求 $\cos\alpha = 1.5$，没有这样的夹角。两段相等的拉力，合力不可能大于 $2F_1$，更到不了 $3F_1$。

**D. $F = \sqrt{3}\,F_1$：正确。**

夹角 $60°$，与竖直方向成 $30°$，$F = 2F_1\cos 30° = \sqrt{3}\,F_1$。代表值下 $F = 17.320508\ \text{N}$，$F/F_1 = 1.732051$。

$$
\boxed{D}
$$

## 四、结合受力图理解三个关键夹角

这不是随时间变化的过程，关键差别在夹角。

- **$\theta = 60°$（题目）。** 每根下绳与竖直方向成 $30°$。$F_1$ 的竖直分力是 $F_1\cos 30°$，两根合起来等于 $\sqrt{3}\,F_1$。矢量三角形里，$F_1$、$F_2$ 两条边相等，对着 $F$ 的那条边是它们的 $\sqrt{3}$ 倍，三角形闭合。指针落在 $\sqrt{3}$ 上，解出的 $F$ 与选项 D 的值相同，与 A、B、C 都不同。
- **$\theta = 120°$。** 与竖直方向成 $60°$，竖直分力只剩一半，$F = F_1$。三力大小相等、彼此夹角 $120°$，矢量三角形变成等边三角形。这是选项 A 成立的几何条件，不是题目。
- **$\theta = 0°$。** 两根下绳重合、都竖直，水平分力消失，$F = 2F_1$。这是选项 B 成立的条件，也是两等大拉力合力的上限。
- **选项 C 的 3。** 表盘把 3 标在最外侧。无论夹角怎么拖，指针都停在 $0$ 到 $2$ 之间，到不了 3。$60°$ 时比值的平方是 3，比值本身是 $\sqrt{3}$。

再点「$F_1$ 加倍，夹角仍为 $60°$」：$F$ 从 $17.32\ \text{N}$ 左右变成两倍，指针仍停在 $\sqrt{3}$。所以关系式写成 $F = \sqrt{3}\,F_1$，不必知道石磨有多重。

## 五、答案汇总

| 选项 | 判断 | 在什么情况下才会成立 |
|---|---|---|
| A. $F = F_1$ | 错误 | 两绳夹角为 $120°$，不是 $60°$ |
| B. $F = 2F_1$ | 错误 | 两绳平行、都竖直 |
| C. $F = 3F_1$ | 错误 | 没有任何夹角；漏掉了开方 |
| D. $F = \sqrt{3}\,F_1$ | 正确 | 本题 $\angle AOB = 60°$ |

代表值 $F_1 = 10\ \text{N}$ 时，$F = 17.320508\ \text{N}$，$F/F_1 = 1.732051$。

$$
\boxed{D}
$$
