## 一、题目条件分析

小球已经在某一水平面内做匀速圆周运动。冰坑光滑，沿切面方向没有摩擦力。

- 受力只有两个：重力 $G = mg$ 竖直向下，支持力 $N$ 垂直于小球所在处的切面、指向坑内。
- 切面与水平面的夹角为 $\theta$，所以 $N$ 与竖直方向的夹角也是 $\theta$，并且斜向水平圆周的轴线。
- 加速度只有水平指向轴线的向心加速度 $a_n$，竖直方向加速度为 $0$。向心力是 $N$ 的水平分力充当的效果，不是第三个受力。
- 题目数据：$R = 0.4\ \text{m}$（水平轨道半径），$\theta = 45^\circ$，$m = 0.1\ \text{kg}$，$g = 10\ \text{m/s}^2$。因此 $mg = 1\ \text{N}$。四个选项都是这组数据下的具体数值。

剖面里小球画在左壁，水平向右指向轴线，与试卷图一致。$R$ 是这个水平距离，不是沿坑壁量的斜线。

## 二、完整解答

取小球所在的竖直面。水平向右指向轴线，竖直向上为正。

支持力与竖直方向成 $\theta$、斜向轴线，所以

$$
N\cos\theta = mg
$$

$$
N\sin\theta = ma_n = m\frac{v^2}{R} = m\omega^2 R
$$

两式相除，$\tan\theta = a_n / g$，故

$$
a_n = g\tan\theta
$$

代入 $\theta = 45^\circ$，$\tan 45^\circ = 1$：

$$
a_n = 10\times 1 = \boxed{10\ \text{m/s}^2}
$$

$$
v^2 = a_n R = 10\times 0.4 = \boxed{4\ \text{m}^2/\text{s}^2}
$$

$$
v = \sqrt{a_n R} = \sqrt{4} = \boxed{2\ \text{m/s}}
$$

$$
\omega = \frac{v}{R} = \frac{2}{0.4} = \boxed{5\ \text{rad/s}}
$$

再由竖直方向

$$
N = \frac{mg}{\cos 45^\circ} = \frac{1}{\sqrt{2}/2} = \boxed{\sqrt{2}\ \text{N}}
$$

约 $1.41\ \text{N}$。也可以看分力：$\theta = 45^\circ$ 时 $N$ 的竖直分力、水平分力都是 $1\ \text{N}$，竖直分力平衡重力，水平分力等于 $ma_n$，所以 $N = \sqrt{1^2 + 1^2} = \sqrt{2}\ \text{N}$，并且 $a_n = g$。

### A. 角速度为 5rad/s

正确。$\omega = v / R = 2 / 0.4 = 5\ \text{rad/s}$。也可写成 $\omega = \sqrt{a_n / R} = \sqrt{10 / 0.4} = 5\ \text{rad/s}$。

### B. 线速度大小为 4m/s

错误。线速度是 $v = \sqrt{a_n R} = 2\ \text{m/s}$。

$4$ 是 $v^2$ 的数值：$a_n R = v^2 = 4\ \text{m}^2/\text{s}^2$。把 $a_n = v^2 / R$ 乘上 $R$ 得到的是 $v^2$，不是 $v$。单位也不是 $\text{m/s}$。若真把 $v$ 当成 $4\ \text{m/s}$，则 $a_n = v^2 / R = 40\ \text{m/s}^2$，$\omega = v / R = 10\ \text{rad/s}$，与 A、C 都对不上。

### C. 向心加速度大小为 10m/s^2

正确。$a_n = g\tan 45^\circ = 10\ \text{m/s}^2$。用线速度复核：$v^2 / R = 4 / 0.4 = 10\ \text{m/s}^2$。$\theta = 45^\circ$ 时水平分力与竖直分力相等，所以向心加速度正好等于 $g$。

### D. 所受支持力大小为 1N

错误。$1\ \text{N}$ 是重力 $mg$，不是支持力。竖直方向 $N\cos\theta = mg$，而 $\cos 45^\circ = \sqrt{2}/2 \neq 1$，所以

$$
N = \frac{mg}{\cos 45^\circ} = \sqrt{2}\ \text{N} \approx 1.41\ \text{N}
$$

支持力比重力大，多出来的那一部分用来提供水平向心力。若硬把 $N$ 当成 $1\ \text{N}$，就只能有 $\cos\theta = 1$，即 $\theta = 0^\circ$，与切面倾角 $45^\circ$ 矛盾。

A 与 C 来自同一组 $a_n = 10\ \text{m/s}^2$、$v = 2\ \text{m/s}$，彼此一致。B、D 是两个互不配套的错数。正确选项是 AC。

## 四、结合图像理解关键时刻

题目数据下周期 $T = 2\pi / 5\ \text{s}$。进度条上的 $1/4$ 圈、半圈、$3/4$ 圈把这一周期四等分，俯视轨迹也是四段 $90^\circ$ 的弧，频闪点再把每段平分。相等时间走过相等的弧，速率和角速度都不变，这就是匀速圆周运动。线速度沿切线，向心加速度指向圆心 $O$，二者始终垂直。

$\theta = 45^\circ$ 是这道题算得这么整齐的原因。向心加速度曲线在这里穿过 $g = 10\ \text{m/s}^2$，所以 C 正确，同时 $\omega = \sqrt{g / R} = 5\ \text{rad/s}$，A 正确。倾角离开 $45^\circ$ 后，$a_n$ 不再等于 $g$，A、C 里的两个数会一起变。

线速度图上，实线在 $45^\circ$、$R = 0.4\ \text{m}$ 处是 $2\ \text{m/s}$，虚线是 $4$。虚线的纵轴数值等于 $v^2$，单位是 $\text{m}^2/\text{s}^2$。选项 B 把这个 $4$ 当成了线速度。

支持力图上，实线整条都在重力虚线的上方。$45^\circ$ 时 $N = \sqrt{2}\ \text{N}$，重力才是 $1\ \text{N}$。只把质量滑大或滑小，角速度、线速度、向心加速度三条读数不动，支持力和重力按同一比例升降，因为运动学量里没有 $m$，而 $N = mg / \cos\theta$。

受力图的矢量三角形把同一件事画成几何关系：$N$ 与 $G$ 接不上的那段水平虚线就是 $ma_n$，指向轴线。$\theta = 45^\circ$ 时这段的大小正好等于重力。

## 五、答案汇总

| 选项 | 判断 | 题目数据下的结果 |
| --- | --- | --- |
| A | 正确 | $\omega = 5\ \text{rad/s}$ |
| B | 错误 | $v = 2\ \text{m/s}$；$4$ 是 $v^2$ 的数值 |
| C | 正确 | $a_n = 10\ \text{m/s}^2$ |
| D | 错误 | $N = \sqrt{2}\ \text{N} \approx 1.41\ \text{N}$ |

正确选项为 AC。
