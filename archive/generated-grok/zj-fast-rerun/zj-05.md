## 一、题目条件分析

- 两列简谐横波振幅都是 $A$，波长都是 $\lambda$，周期都是 $T$，沿同一绳子相向传播，波速 $v = \lambda/T$。
- 每列波都只由一次全振动产生，所以每列波的长度都是 $vT = \lambda$，后面没有后续的波。
- $t = 0$ 时，左波列向右传播，从左到右是一个波峰接一个波谷；右波列向左传播，从左到右是一个波谷接一个波峰。两列波相邻的内侧端点相距 $\lambda$，中间一段绳子停在平衡位置。
- 两列波的**前端都是波谷**：左波列的右端、右波列的左端，都是刚要从平衡位置进入波谷的那一点。先碰上的是波谷，不是波峰。
- 题目只给字母。下面的推导用 $\lambda$、$T$、$A$ 完成。交互图取 $\lambda = 4\ \text{m}$、$T = 4\ \text{s}$、$A = 1\ \text{cm}$，于是 $v = 1\ \text{m/s}$，$\lambda/2 = 2\ \text{m}$，$2A = 2\ \text{cm}$。波形按 $\lambda$ 和 $A$ 来比时与这组具体数字无关。绳子上振幅远小于波长，图中竖直方向已放大，不按比例。

取两列波正中间的间隙中点为原点，$x$ 向右为正，位移向上为正。$t = 0$ 时左波列在 $-1.5\lambda \le x \le -0.5\lambda$，右波列在 $0.5\lambda \le x \le 1.5\lambda$。

## 二、完整解答

波在绳子上不改变形状，只是整体平移。右行的左波列用 $x - vt$ 代替 $x$，左行的右波列用 $x + vt$ 代替 $x$。只在各自波列覆盖的区间里位移才不为零：

$$
y_1 = -A\sin\frac{2\pi}{\lambda}(x - vt), \qquad y_2 = A\sin\frac{2\pi}{\lambda}(x + vt)
$$

$t = 0$ 时，$y_1 = -A\sin(2\pi x/\lambda)$ 在左波列上从左到右是峰、谷；$y_2 = A\sin(2\pi x/\lambda)$ 在右波列上从左到右是谷、峰。与图 1 一致。重叠区内合成位移 $y = y_1 + y_2$，没有重叠的地方只有经过那里的那一列。

### A. 错误

$t = T/4$ 时，每列波只前进 $\lambda/4$，相向靠近的距离一共是 $\lambda/2$。内侧端点之间还空着

$$
\Delta x = \lambda - 2v\cdot\frac{T}{4} = \frac{\lambda}{2}
$$

按所取数值，$v = 1\ \text{m/s}$，

$$
\Delta x = \boxed{2\ \text{m}}
$$

左波列仍整个落在 $-1.25\lambda \le x \le -0.25\lambda$，形状仍是波峰接波谷；右波列仍在 $0.25\lambda \le x \le 1.25\lambda$，形状仍是波谷接波峰。两列波还没有公共区间。甲图是两段直线中间两个相邻的向上小峰、没有波谷。这一时刻绳子上每列波都带着自己的波峰和波谷，甲图与它不符。

### B. 正确

$t = T/2$ 时，每列波前进 $\lambda/2$。左波列占据 $-\lambda \le x \le 0$，右波列占据 $0 \le x \le \lambda$，两端刚好在 $x = 0$ 相接。

左波列在这段上仍是先峰后谷：波峰在 $x = -0.75\lambda$，$y = A$；波谷在 $x = -0.25\lambda$，$y = -A$。右波列仍是先谷后峰：波谷在 $x = 0.25\lambda$，$y = -A$；波峰在 $x = 0.75\lambda$，$y = A$。$x = 0$ 是两列波的端点，两边的位移都是 0。

从左向右看，就是：一个波峰，一个波谷，在中点回到 0 后再进入另一个波谷，然后是右侧的波峰。两个波谷肩并肩，合起来是一段宽波谷，正中那个回到 0 的接点两侧斜率一正一负，形成一个向上的尖。这就是图 2 乙。

### C. 错误

$t = 3T/4$ 时，每列波前进 $3\lambda/4$。两列波的前半段都是长 $\lambda/2$ 的波谷，并且刚好都落在 $-0.25\lambda \le x \le 0.25\lambda$ 上，完全叠在一起。后半段的波峰还留在两侧，没有进入这段重叠区：左侧波峰在 $-0.75\lambda \le x \le -0.25\lambda$，右侧波峰在 $0.25\lambda \le x \le 0.75\lambda$。

重叠区内两列波的位移相同，

$$
y = y_1 + y_2 = -2A\cos\frac{2\pi x}{\lambda}
$$

中点 $x = 0$ 处

$$
y(0) = 2A\sin\frac{3\pi}{2} = \boxed{-2\ \text{cm}}
$$

两侧波峰的高度仍是 $A = 1\ \text{cm}$。波谷深度与波峰高度之比

$$
\frac{|y(0)|}{A} = \boxed{2}
$$

峰、谷、峰三段的宽度都是 $\lambda/2$，这一点和丙图相同。丙图还要求波谷深度与两侧波峰高度相同。这里的波谷是两个波谷相加，深度是 $2A$。丙图与这一时刻的波形不符。

### D. 正确

$t = T$ 时，每列波都前进了一个波长，两列波都刚好占据 $-0.5\lambda \le x \le 0.5\lambda$。把 $vt = \lambda$ 代入：

$$
y_1 = -A\sin\frac{2\pi x}{\lambda}, \qquad y_2 = A\sin\frac{2\pi x}{\lambda}
$$

$$
y_1 + y_2 = 0
$$

重叠区外面两列波都还没到达，位移也是 0。整根绳子的位移都是 0，波形与横轴重合，就是图 2 丁。

这一瞬间位移为零，两列波仍在绳子上，只是处处相反。再往后它们会分开，各自回到原来的形状。$t = 2T$ 时，原来的左波列已经移到右侧，原来的右波列已经移到左侧，中间再次空出 $\lambda$。丁图只描述 $t = T$ 这一张位移快照，这个判断成立。

四个选项里符合图的是 B 和 D：

$$
\boxed{BD}
$$

易错的地方有两处。一是把有限波列当成一直在振动的无限长波，重叠区以外并没有另一列波可叠加。二是只看丙图“左峰、中谷、右峰”的轮廓，漏掉深度：谷是两列波的谷叠出来的，深度是 $2A$。

## 四、结合图像理解关键时刻

把进度条停在四个选项上，对照图 2，再看中点位移曲线。

| 时刻 | 绳子上的情形 | 与图 2 的关系 |
|---|---|---|
| $t = 0$ | 左波列先峰后谷，右波列先谷后峰，中间空出 $\lambda$ | 图 1 |
| $t = T/4$ | 间距缩短为 $\lambda/2$，两列波形状不变，仍各有一个波谷 | 不是甲 |
| $t = T/2$ | 两侧各一个波峰，两个波谷在中点相接并回到 0 | 乙，B 正确 |
| $t = 3T/4$ | 峰、谷、峰相连，宽度都是 $\lambda/2$，谷深 $2A$、峰高 $A$ | 不是丙 |
| $t = T$ | 两列虚线相反，实线与横轴重合，中点位移曲线回到 0 | 丁，D 正确 |
| $t = 2T$ | 两列波交换左右位置，各自仍是出发时的形状 | 波没有消失 |

中点位移曲线在两列波盖住中点之前一直是 0。盖住以后按 $y(0) = 2A\sin(2\pi t/T)$ 变化：$t = 3T/4$ 时是 $-2A$，$t = T$ 时是 0，$t = 5T/4$ 时会到 $+2A$。$t = T$ 的直线只是位移为零的那一张快照，曲线过了这一点又会离开横轴。
