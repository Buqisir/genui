## 一、题目条件分析

公园里的桶仿的是古代欹器：能绕一根固定的水平轴转动，水管一直往里注水，过一段时间翻一次，把水倒出。

题目没有给质量、流量或力的数值，问的是**哪一个因素决定它会不会翻**。桶被轴约束着，会不会翻要看各力对这根轴的力矩，不能只看力的大小。

空桶先稳稳地停在正位，要等一会儿才翻，说明不是水一冲上去就被掀翻，而是桶里的水慢慢改变了整体的质量分布。古代说的「满则覆」，就是水加多之后自己翻倒。

下面先得到与具体数字无关的判据，再用一组**代表性数值**把重心高低画出来。这组数不是试卷给的。

## 二、完整解答

### 正位附近的重力矩

正位时桶左右对称。不论重心在转轴上面还是下面，重力作用线都过转轴，力矩为零，所以正位总是平衡位置。稳不稳，要看稍偏一点之后力矩把桶拉回来，还是把它推得更偏。

设桶底到整体重心的高度为 $y_c$，桶底到转轴的高度为 $y_O$，桶加水的总质量为 $M+m$。从正位逆时针转过小角 $\theta$ 后，重心相对转轴的水平坐标是

$$
x = -(y_c - y_O)\sin\theta
$$

重力竖直向下，对转轴的力矩（逆时针为正）为

$$
\tau = -(M+m)gx = (M+m)g(y_c - y_O)\sin\theta
$$

- $y_c < y_O$：重心在转轴**下方**，$\tau$ 与 $\theta$ 异号，是恢复力矩，松手后回到正位。
- $y_c > y_O$：重心在转轴**上方**，$\tau$ 与 $\theta$ 同号，偏离被放大，松手后翻转。
- $y_c = y_O$：小角度力矩仍为零，是临界；重心再高才会翻。恰好落在转轴上不算翻转。

水沿对称轴注入。水深为 $h$、每米水深对应的水质量为 $k$ 时，水的质量 $m = kh$，水的重心在 $h/2$。桶本身质量 $M$、重心高度 $y_M$，则

$$
y_c = \frac{M y_M + kh\cdot h/2}{M + kh}
$$

空桶要能停住，必须 $y_M < y_O$。令 $y_c = y_O$，得到唯一的正根

$$
h_c = y_O + \sqrt{y_O^2 + \frac{2M(y_O - y_M)}{k}}
$$

桶高为 $H$。$h_c < H$ 时，注到 $h_c$ 以上就会翻；$h_c \ge H$ 时，加满后重心仍不高于转轴，不会自己翻。

轴对桶的力作用在转轴上，力矩为零，不参与这个判断。

### 逐项判断

**A. 错误。** 水桶重力 $G = Mg$ 会按同一个比例放大上面的 $\tau$，但不改变 $\tau$ 的正负。正负只由 $y_c - y_O$ 决定。同一只桶、同一个 $G$，水深在 $h_c$ 以下不翻，超过 $h_c$ 就翻。

重力大小会间接影响 $y_c$：桶越重，同样的水越不容易把重心抬过转轴。$M$ 大到 $h_c \ge H$ 时，加满也不翻。这仍然是「重心没有高过转轴」，不是重力的数值本身在发号施令。只告诉你重力有多大、不告诉你重心在轴上还是轴下，无法判断翻不翻。

**B. 错误。** 每秒出水量 $q$（质量流量）只出现在注水时间里：

$$
t = \frac{kh}{q}
$$

$y_c$ 和 $h_c$ 的式子里都没有 $q$。$q$ 大，重心更早升到转轴；$q$ 小，更晚升到。只要最终能升过转轴，桶就会翻。若加满后重心仍不高于转轴，流量再大也只是从桶沿溢出，不会翻。

**C. 错误。** 题图里水从桶口上方落入，落点在对称轴上，对转轴的力臂 $d = 0$，撞击力矩

$$
\tau_F = Fd = 0
$$

与撞击力 $F$ 的大小无关。$F = 0$ 时，只要重心升过转轴，桶仍会翻；$F$ 很大时，只要重心还在转轴下方，桶仍是稳定的。题目说「过一段时间」才翻，也说明不是阀门一开就被水撞翻。

**D. 正确。** 由上面的力矩可知：整体重心低于转轴则正位稳定，高于转轴则正位不稳定、稍有偏离就会翻转。注水改变的是这个高低，所以它是决定桶能否翻转的主要因素。

$$
\boxed{D}
$$

### 用一组代表性数值核对

试卷没有数字。下面这组数只用于画图和核对，取得使临界水深是一个整齐的数：

- 桶：质量 $M = 8\ \text{kg}$，重心 $y_M = 0.10\ \text{m}$，内高 $H = 0.60\ \text{m}$
- 转轴离桶底 $y_O = 0.20\ \text{m}$（在桶身中下部，空桶重心在轴下）
- 水：$k = \rho S = 1.0\times 10^3\times 0.032 = 32\ \text{kg/m}$
- 出水量 $q = 2\ \text{kg/s}$，取 $g = 10\ \text{m/s}^2$
- 水流打在对称轴上，力臂取 $0$

代入临界水深：

$$
h_c = 0.20 + \sqrt{0.20^2 + \frac{2\times 8\times(0.20-0.10)}{32}} = 0.20 + \sqrt{0.09} = \boxed{0.50\ \text{m}}
$$

此时水的质量、注到临界所需的时间：

$$
m_c = kh_c = 32\times 0.50 = \boxed{16\ \text{kg}}
$$

$$
t_c = \frac{m_c}{q} = \frac{16}{2} = \boxed{8\ \text{s}}
$$

加满仍能刚好把重心抬到转轴的最大桶质量（$h_c = H$）：

$$
M_{\max} = \frac{kH(H-2y_O)}{2(y_O-y_M)} = \frac{32\times 0.60\times 0.20}{0.20} = \boxed{19.2\ \text{kg}}
$$

三个点可以直接验算 $y_c$：

| 状态 | $y_c$ | 和转轴 $0.20\ \text{m}$ 比 |
|---|---|---|
| $M=8\ \text{kg}$，$h=0.30\ \text{m}$ | $(0.80+1.44)/17.6 = 0.127\ \text{m}$ | 在轴下，稳定 |
| $M=8\ \text{kg}$，$h=0.55\ \text{m}$ | $(0.80+4.84)/25.6 = 0.220\ \text{m}$ | 在轴上，会翻 |
| $M=24\ \text{kg}$，$h=0.60\ \text{m}$ | $(2.40+5.76)/43.2 = 0.189\ \text{m}$ | 加满仍在轴下，不翻 |

第三行就是选项 A 的迷惑之处：桶重了确实可能不翻，但原因是重心没过转轴。前两行桶的重力都是 $80\ \text{N}$，一个不翻、一个会翻。

$q$ 改成 $4\ \text{kg/s}$ 时，$h_c$ 仍是 $0.50\ \text{m}$，$t_c$ 变成 $4\ \text{s}$。$F$ 从 $0$ 改到几十牛，$\tau_F$ 仍是 $0$。

> 刚注水时 $y_c$ 会先略降再上升：最先进来的水积在桶底，低于空桶重心，把整体重心往下拉；水再加高，重心才越过转轴。这不改变「过轴才翻」的结论。

> 若把转轴抬到桶的中线或更高（$y_O \ge H/2$），水的重心最高只有 $H/2$，再叠上更低的桶重心，整体重心到不了转轴上方，桶永远不会自己翻。装置能翻，就是因为转轴低到让重心有机会升到它上面。

figure({
  draw(ctx, p, v) {
    const yO = p.yO
    const H = p.Hb
    const w = p.halfW
    const th = (p.beta * Math.PI) / 180
    const h = p.hw > 0 ? p.hw : 0
    const mview = v.view({ xmin: -0.95, xmax: 0.95, ymin: -0.62, ymax: 1.02, equal: true, pad: 14 })

    function bw(u, vBody) {
      const vv = vBody - yO
      return [u * Math.cos(th) - vv * Math.sin(th), u * Math.sin(th) + vv * Math.cos(th)]
    }

    function waterPoly(hh, tan) {
      const f = (pt) => hh - pt[0] * tan - pt[1]
      const poly = [[-w + 0.006, 0.006], [w - 0.006, 0.006], [w - 0.006, H], [-w + 0.006, H]]
      const out = []
      const n = poly.length
      for (let i = 0; i !== n; i++) {
        const A = poly[i]
        const B = poly[(i + 1) % n]
        const fa = f(A)
        const fb = f(B)
        const ain = fa >= -1e-8
        const bin = fb >= -1e-8

## 四、结合图像理解关键时刻

前两张图的横轴是水深，跟着「桶内水深」滑块走，不随动画时间走。第三张图才是动画的时间轴。

重心曲线先略降、再上升。下降是因为水先积在桶底，低于空桶重心 $0.10\ \text{m}$。曲线和转轴高度 $0.20\ \text{m}$ 的交点就是临界水深。初始的桶在 $h_c = 0.50\ \text{m}$ 过轴；把桶的质量拖过约 $19.2\ \text{kg}$，交点会移出桶高，加满也不再相交。

力矩曲线在同一个水深由负变正。图上固定用 $5^\circ$，所以它不跟试探倾角联动：$\beta$ 只改变力矩的大小，不改变变号的位置。$\beta = 0$ 时侧栏里的力矩变成零，但只要再偏一点，符号仍由重心在轴上还是轴下决定。

出水量不改变前两张图，只把 $t_c = m_c/q$ 和第三张图的时间轴拉长或压短。撞击力不进任何一条曲线，侧栏里的撞击力矩一直是零。

动画在初始参数下，水深约在 $8\ \text{s}$ 升到 $h_c$，进度条上出现「重心过轴」。随后倾角增大，水从较低的桶沿倒出，重心落回转轴下方，桶回到正位。桶质量大于 $M_{\max}$ 时没有这些标记，桶一直正立。

## 五、答案汇总

选择题答案是 $\boxed{D}$。

| 选项 | 判断 | 理由 |
|---|---|---|
| A. 水桶自身重力的大小 | 错误 | 重力只放大力矩，不改变力矩方向；方向只看重心在轴上还是轴下 |
| B. 水管每秒出水量的大小 | 错误 | 只改变注到临界水深的时间，不改变临界水深 |
| C. 水流对桶撞击力的大小 | 错误 | 水流落在对称轴上，对转轴的力矩始终为零 |
| D. 水桶与水整体的重心高低 | 正确 | 重心低于转轴则稳定，高于转轴则翻转 |

代表性数值下的核对结果（不是试卷要求的数）：

| 量 | 结果 |
|---|---|
| 临界水深 $h_c$ | $0.50\ \text{m}$ |
| 临界时水的质量 $m_c$ | $16\ \text{kg}$ |
| 注到临界的时间 $t_c$ | $8\ \text{s}$ |
| 加满仍能翻的最大桶质量 $M_{\max}$ | $19.2\ \text{kg}$ |
