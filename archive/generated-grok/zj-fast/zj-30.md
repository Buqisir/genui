## 一、题目条件分析

图中 A 在左、B 在右，两板之间有一段空隙；C 是质点，放在 B 的右端，右端与 B 对齐。地面光滑。题干给的速度图上没有画出。

- 三者质量相同：$m_A = m_B = m_C = m = 1\ \text{kg}$。
- 取向右为正。碰撞前 $v_A = 4\ \text{m/s}$，$v_B = v_C = -2\ \text{m/s}$。C 与 B 一起匀速，相对静止，板间还没有滑动摩擦。
- A、B 的碰撞时间极短，粘在一起，是完全非弹性碰撞。这段时间里摩擦力的冲量可以忽略，**C 的速度在碰撞瞬间不变**。
- 板长 $L = 0.75\ \text{m}$，C 与 A、B 间的动摩擦因数都是 $\mu = 0.5$。
- 题目没有给重力加速度。下面按高中常用值 $g = 10\ \text{m/s}^2$ 计算，这样 D 项的 $0.6\ \text{m}$ 与结果一致。摩擦热的结果与 $g$ 无关。
- 图中的空隙题目没有给长度。演示里取 $0.6\ \text{m}$，它只决定碰撞前两板靠近要用多久，不进入碰撞之后的计算。

系统水平方向不受外力，总动量守恒：

$$
p = m\cdot 4 + m\cdot(-2) + m\cdot(-2) = 0
$$

所以三者最终若相对静止，对地的共同速度只能是 $0$。这是摩擦作用完以后的状态，不是碰撞那一瞬间。

## 二、完整解答

### 碰撞刚结束时的速度

C 不参与这一下碰撞。对 A、B 用动量守恒：

$$
m\cdot 4 + m\cdot(-2) = 2m\, v_{AB}
$$

$$
v_{AB} = \frac{4-2}{2} = \boxed{1\ \text{m/s}}
$$

C 的速度仍是碰撞前的值：

$$
v_C = \boxed{-2\ \text{m/s}}
$$

此时 C 相对长板向左滑，相对速度大小为 $1-(-2) = 3\ \text{m/s}$。

### 选项 A

**错误。** 碰撞瞬间 C 相对地面的速度是向左 $2\ \text{m/s}$，不是 $0$。

碰撞时间极短，C 与板之间的摩擦力来不及给 C 冲量。系统最终确实会停住，那是因为总动量本来就是 $0$，还要再靠摩擦把相对速度消掉，不能把“最终静止”安到碰撞瞬间。

### 碰后的摩擦，以及选项 B

滑动摩擦力大小

$$
f = \mu mg = 0.5\times 1\times 10 = 5\ \text{N}
$$

C 相对板向左滑，摩擦力使 C 向右加速、使 AB 向左加速：

$$
a_C = \frac{f}{m} = 5\ \text{m/s}^2,\qquad a_{AB} = -\frac{f}{2m} = -2.5\ \text{m/s}^2
$$

设碰撞后经历时间 $t$（这时 $t$ 从碰撞刚结束量起）：

$$
v_C = -2 + 5t,\qquad v_{AB} = 1 - 2.5t
$$

共速时二者相等：

$$
-2 + 5t = 1 - 2.5t \quad\Rightarrow\quad 7.5t = 3 \quad\Rightarrow\quad t = \boxed{0.4\ \text{s}}
$$

代入得共同速度为 $0$，与总动量为 $0$ 一致。相对加速度是 $5-(-2.5) = 7.5\ \text{m/s}^2$，用相对速度来算是同一结果：$t = 3/7.5 = 0.4\ \text{s}$。

**选项 B 错误。** $0.2\ \text{s}$ 只等于 $1/5$：若把粘在一起的板仍按 $1\ \text{kg}$ 计算，加速度变成 $5\ \text{m/s}^2$，再用板的速度变化量 $1\ \text{m/s}$ 去除，就会得到 $0.2\ \text{s}$。板的质量是 $2\ \text{kg}$，加速度大小是 $2.5\ \text{m/s}^2$，$1/2.5 = 0.4\ \text{s}$。

达到共速之后，水平方向没有其他外力，维持相对静止所需要的静摩擦力是 $0$，三者保持相对静止。

### 选项 C

**错误。** 摩擦产生的热量是 $3\ \text{J}$，不是 $12\ \text{J}$。

先看碰撞本身带走的机械能。碰前 A、B 的动能是 $8\ \text{J}+2\ \text{J}=10\ \text{J}$，碰后 AB 的动能是

$$
E_{k,AB} = \frac12\cdot 2m\cdot 1^2 = 1\ \text{J}
$$

碰撞损失 $9\ \text{J}$，这是 A、B 粘在一起时耗掉的，不是 C 与板的摩擦热。

碰后、摩擦开始前，系统动能只剩下

$$
E_k = 1\ \text{J} + \frac12 m\cdot(-2)^2 = 3\ \text{J}
$$

共速后动能为 $0$，这份动能全部变成摩擦热：

$$
Q = \boxed{3\ \text{J}}
$$

用摩擦力乘相对滑动距离核对：相对速度从 $3\ \text{m/s}$ 均匀减到 $0$，

$$
s = \frac12\times 3\times 0.4 = 0.6\ \text{m},\qquad Q = fs = 5\times 0.6 = 3\ \text{J}
$$

$12\ \text{J}$ 是碰撞前三者的总动能 $8+2+2$。它等于碰撞损失 $9\ \text{J}$ 加上摩擦热 $3\ \text{J}$，不能算作摩擦产生的热量。$Q = m v_{\text{相对}}^2/3 = 1\times 9/3$，式子里的 $g$ 消掉了，所以热量不随 $g$ 改变。

### 选项 D

**正确。** 上面已经得到 C 相对长板滑过的距离

$$
s = \boxed{0.6\ \text{m}}
$$

C 从 B 的右端向左滑。$0.6\ \text{m} < L = 0.75\ \text{m}$，全过程 C 都还在 B 上，没有滑到接缝，更没有滑出两板。动摩擦因数全程就是 $0.5$，不用分段。

A、B 上的动摩擦因数相同，即便滑过接缝，只要还在板上，加速度也不变；本题的 $0.6\ \text{m}$ 还没到那一步。

### 结论

A、B、C 错误，D 正确。答案是 $\boxed{D}$。

## 四、结合图像理解关键时刻

速度图上，碰撞前 A 是 $4\ \text{m/s}$，B 和 C 叠在 $-2\ \text{m/s}$。碰撞瞬间 A、B 跳到一起的 $1\ \text{m/s}$，C 的曲线连续，仍是 $-2\ \text{m/s}$，所以 A 项不成立。

从这一刻到两线相遇，C 与 B 之间围出的面积是相对滑动距离。题目数据下这段时间是 $0.4\ \text{s}$，面积是 $0.6\ \text{m}$。标着「选项 B 的 $0.2\ \text{s}$」的竖线落在两线相遇之前，那时 $v_C$ 大约是 $-1\ \text{m/s}$，$v_{AB}$ 大约是 $0.5\ \text{m/s}$，还没有相对静止。

位置图上，碰撞之后 C 从「B 右端」那条线向下离开，到共速时高度差是 $0.6\ \text{m}$，仍在虚线「接缝」的上方，所以 C 还在 B 上。

能量账本把 $12\ \text{J}$ 拆开：刚碰后动能只剩 $3\ \text{J}$，另外 $9\ \text{J}$ 已经在粘合时损失；再到相对静止，这 $3\ \text{J}$ 全部变成摩擦热。C 项把碰撞前的总动能当成了摩擦热。
