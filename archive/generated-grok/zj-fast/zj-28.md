## 一、题目条件分析

四个物体质量相同，细线轻且不可伸长，滑轮不计摩擦。题目给出质量，选项以 N 为单位，按高中常用取值 $g = 10\ \text{m/s}^2$。

- $m = 50\ \text{g} = 0.05\ \text{kg}$，每个物体的重力 $mg = 0.5\ \text{N}$。
- 配重 P、Q 静止，所以细线 d、c 的拉力等于配重的重力：$F_c = F_d = mg = 0.5\ \text{N}$。滑轮只改变拉力方向。
- c、d 互相平行，都与水平成 $\theta = 30°$。d 从 B 向左下，c 从 A 向右上，两条线的倾斜方向相同。
- a 竖直，上端固定在支架上，下端系在球 B。b 连接 B、A，A 在 B 的右下方。b 与水平的夹角 $\beta$ 题目没有直接给出，由平衡确定。

## 二、完整解答

取水平向右为 $x$ 正方向，竖直向上为 $y$ 正方向。

### 1. 整体法求 $F_a$

把 A、B 看成整体，b 是内力。外力有：$F_a$ 竖直向上，两个重力 $2mg$ 竖直向下，$F_c$ 沿右上与水平成 $\theta$，$F_d$ 沿左下与水平成 $\theta$。

因为 $F_c = F_d = mg$ 且两线平行：

$$
\sum F_x = mg\cos\theta - mg\cos\theta = 0
$$

$$
\sum F_y = F_a - 2mg + mg\sin\theta - mg\sin\theta = 0
$$

c、d 的水平分力互相抵消，竖直分力也互相抵消，于是

$$
F_a = 2mg = 2 \times 0.5 = \boxed{1\ \text{N}}
$$

这个结果与 $\theta$ 无关：只要 c、d 平行且拉力都等于 $mg$，a 就只承担 A、B 两个重力。P、Q 的重力由滑轮轴承担。

### 2. 隔离 A 求 $F_b$

设 b 与水平成 $\beta$，球 A 受到的 $F_b$ 指向 B，即向左上方。

$$
\sum F_x:\quad F_b\cos\beta = F_c\cos\theta = mg\cos\theta
$$

$$
\sum F_y:\quad F_b\sin\beta + F_c\sin\theta = mg
$$

$$
F_b\sin\beta = mg(1 - \sin\theta)
$$

$$
F_b = mg\sqrt{\cos^2\theta + (1-\sin\theta)^2} = mg\sqrt{2(1-\sin\theta)}
$$

$$
\tan\beta = \frac{1-\sin\theta}{\cos\theta}
$$

代入 $\theta = 30°$，$\sin 30° = 1/2$，$\cos 30° = \sqrt{3}/2$：

$$
\tan\beta = \frac{1/2}{\sqrt{3}/2} = \frac{1}{\sqrt{3}} \quad\Rightarrow\quad \beta = 30°
$$

$$
F_b = mg\sqrt{2\left(1-\frac12\right)} = mg = \boxed{0.5\ \text{N}}
$$

此时 b 也与水平成 $30°$，和 c、d 平行。两个分量是

$$
F_b\cos 30° = 0.5\times\frac{\sqrt{3}}{2} = \frac{\sqrt{3}}{4}\ \text{N},\qquad F_b\sin 30° = 0.25\ \text{N}
$$

合成仍是 $0.5\ \text{N}$。

### 3. 用球 B 检验

球 B 上，$F_d$ 向左下与水平成 $30°$，$F_b$ 向右下与水平成 $30°$，二者水平分力都是 $(\sqrt{3}/4)\ \text{N}$，方向相反，水平方向平衡。竖直方向

$$
F_a = mg + F_d\sin 30° + F_b\sin 30° = 0.5 + 0.25 + 0.25 = 1\ \text{N}
$$

与整体法一致。

### 逐项判断

### 选项 A：2 N，1 N

**错误。** 若把每个物体的重力当成 $1\ \text{N}$（$100\ \text{g}$ 才重约 $1\ \text{N}$，相当于质量用成 $100\ \text{g}$），会得到 $F_a = 2mg' = 2\ \text{N}$，$F_b = mg' = 1\ \text{N}$。题目是 $50\ \text{g}$，$mg = 0.5\ \text{N}$，所以两个拉力是 $1\ \text{N}$ 和 $0.5\ \text{N}$。

### 选项 B：2 N，0.5 N

**错误。** $F_b = 0.5\ \text{N}$ 与隔离 A 的结果相同，但 $F_a$ 不是 $2\ \text{N}$。a 是竖直线，它的拉力全部向上；$F_c$ 与 $F_d$ 的竖直分力在整体上抵消，所以 $F_a = 2mg = 1\ \text{N}$。若把 P、Q 的重力也加到 a 上，$4\times 0.5\ \text{N} = 2\ \text{N}$，就把滑轮轴承担的力重复算进了 a。

### 选项 C：1 N，1 N

**错误。** $F_a = 1\ \text{N}$ 与整体法一致，但 $F_b$ 不是 $1\ \text{N}$。球 A 的重力同时由 $F_b$ 和 $F_c$ 的竖直分力分担：$F_b\sin 30° = mg - F_c\sin 30° = 0.25\ \text{N}$，再和水平分力合成得 $F_b = 0.5\ \text{N}$。若漏掉 $F_c$ 向上的分力，写成 $F_b\sin 30° = mg$，就会得到 $F_b = 1\ \text{N}$。

### 选项 D：1 N，0.5 N

**正确。** 与上面的结果一致：细线 a 的拉力 $F_a = 2mg = 1\ \text{N}$，细线 b 的拉力 $F_b = mg = 0.5\ \text{N}$。

## 一、题目条件分析

- 四个物体质量相等：$m_A = m_B = m_P = m_Q = 50\ \text{g} = 0.05\ \text{kg}$。系统静止，滑轮摩擦不计。
- 题目没有写出 $g$。四个选项都是 $0.5\ \text{N}$ 的整数倍；$50\ \text{g}$ 在 $g = 10\ \text{m/s}^2$ 时重 $0.5\ \text{N}$，与选项吻合。下面按这个取值计算。
- 每个物体的重力

$$
G = mg = 0.05 \times 10 = \boxed{0.5\ \text{N}}
$$

- 细线 a 竖直，上端固定，下端系在左侧较高的球 B 上。细线 b 连接 B、A，A 在右下方。细线 d 从 B 向左下、与水平成 $\theta$ 后跨过左侧较低的定滑轮悬挂 P；细线 c 从 A 向右上、与水平成 $\theta$，与 d 平行，跨过右侧较高的定滑轮悬挂 Q。
- 所求是 a、b 的拉力 $T_a$、$T_b$。c、d 的方向夹角是题目给出的 $\theta = 30^\circ$，b 的倾角要由平衡求。

## 二、完整解答

### 1. 配重把 c、d 的拉力定死

P 只受重力和细线 d 的拉力，静止，所以 $T_d = G$。Q 同样，$T_c = G$。

$$
T_c = T_d = G = 0.5\ \text{N}
$$

### 2. 整体法求 $T_a$

取小球 A、B 为整体。c 拉 A 的方向是右上方与水平成 $\theta$，d 拉 B 的方向是左下方与水平成 $\theta$。$T_c = T_d$，这两个力等大、反向：

$$
T_c\cos\theta - T_d\cos\theta = 0
$$

$$
T_c\sin\theta - T_d\sin\theta = 0
$$

竖直方向还剩下 a 的拉力和两个小球的重力（向上为正）：

$$
T_a - m_A g - m_B g = 0
$$

$$
T_a = 2mg = 2 \times 0.5 = \boxed{1\ \text{N}}
$$

P、Q 的重力由支架经滑轮轴承担，不加到细线 a 上。$T_a$ 与 $\theta$ 无关：只要 c、d 平行且拉力相等，它们在整体上就抵消。

### 3. 隔离 A 求 $T_b$

设 b 与水平方向的夹角为 $\varphi$。B 在 A 的左上方，b 拉 A 的方向是左上方。水平、竖直平衡：

$$
T_b\cos\varphi = T_c\cos\theta = mg\cos\theta
$$

$$
T_b\sin\varphi + T_c\sin\theta = mg
$$

$$
T_b\sin\varphi = mg(1 - \sin\theta)
$$

两式相除：

$$
\tan\varphi = \frac{1 - \sin\theta}{\cos\theta}
$$

代入 $\theta = 30^\circ$，$\sin 30^\circ = \dfrac{1}{2}$，$\cos 30^\circ = \dfrac{\sqrt{3}}{2}$：

$$
\tan\varphi = \frac{1 - \dfrac{1}{2}}{\dfrac{\sqrt{3}}{2}} = \frac{1}{\sqrt{3}}
$$

$$
\varphi = \boxed{30^\circ}
$$

b 与水平也成 $30^\circ$，但向右下倾斜；c 向右上倾斜。两者关于竖直线对称，不是平行。于是 $T_b = T_c$：

$$
T_b = mg = \boxed{0.5\ \text{N}}
$$

用分量再核一次：

$$
T_b = \sqrt{\left(mg\cos 30^\circ\right)^2 + \left(mg \cdot \dfrac{1}{2}\right)^2}
= mg\sqrt{\dfrac{3}{4} + \dfrac{1}{4}} = mg = 0.5\ \text{N}
$$

竖直方向：$0.5\sin 30^\circ + 0.5\sin 30^\circ = 0.25 + 0.25 = 0.5\ \text{N}$，等于 A 的重力。

### 4. 用 B 复核

在 B 上，d 向左下与水平成 $30^\circ$，b 向右下与水平成 $30^\circ$，两边对称，拉力都是 $0.5\ \text{N}$，竖直分力都向下，各 $0.25\ \text{N}$。

$$
T_a = mg + T_d\sin 30^\circ + T_b\sin 30^\circ = 0.5 + 0.25 + 0.25 = 1\ \text{N}
$$

与整体法一致。一般角度下仍有 $T_a = 2mg$，而

$$
T_b = mg\sqrt{\cos^2\theta + (1 - \sin\theta)^2}
$$

只有 $\theta = 30^\circ$ 时 $T_b = mg$。

### 5. 逐项判断

### 选项 A

**错误。** 若把每个物体按 $100\ \text{g}$ 计算，重力变成 $1\ \text{N}$，则 $T_a = 2\ \text{N}$、$T_b = 1\ \text{N}$，数值正好是这个选项。题目给出的质量是 $50\ \text{g}$，重力是 $0.5\ \text{N}$，对应的拉力是 $1\ \text{N}$ 和 $0.5\ \text{N}$。

### 选项 B

**错误。** 在 $\theta = 30^\circ$ 时，$T_a = 2mg$、$T_b = mg$，所以 $T_a = 2T_b$。$2\ \text{N}$ 与 $0.5\ \text{N}$ 的比是 $4$，不满足这个关系。$2\ \text{N}$ 等于四个物体的总重 $4 \times 0.5\ \text{N}$：那是把 P、Q 的重力也加到了细线 a 上。滑轮轴已经把这两份重力传给支架，c、d 对两个小球的拉力又等大反向，a 只承担 A、B。

### 选项 C

**错误。** $T_a = 1\ \text{N}$ 这一半是对的。$T_b = 1\ \text{N}$ 来自漏掉 c 的竖直分力，并把 b 仍按与竖直方向成 $30^\circ$ 来除：

$$
T_b = \frac{mg}{\sin 30^\circ} = \frac{0.5}{0.5} = 1\ \text{N}
$$

正确的竖直方程是 $T_b\sin\varphi + T_c\sin\theta = mg$。其中 $T_c\sin 30^\circ = 0.25\ \text{N}$ 已经分担一半重力，$T_b\sin 30^\circ$ 只再承担 $0.25\ \text{N}$，所以 $T_b = 0.5\ \text{N}$。质量保持 $50\ \text{g}$ 时，$T_b$ 在 $\theta = 0^\circ$ 取得最大 $mg\sqrt{2} \approx 0.71\ \text{N}$，到不了 $1\ \text{N}$。

### 选项 D

**正确。** $T_a = 2mg = 1\ \text{N}$，$T_b = mg = 0.5\ \text{N}$，与上面的结果一致。

$$
\text{选项}\ \boxed{D}
$$

    v.line(m, postR, PRy, PRx, PRy, { color: v.color.steel, width: 2 })

    const rimToward = (x, y, cx, cy, r) => {
      const dx = cx - x
      const dy = cy - y
      const L = Math.hypot(dx, dy) || 1
      return [cx - (dx / L) * r, cy - (dy / L) * r]
    }
    const onBall = (x, y, tx, ty) => {
      const dx = tx - x
      const dy = ty - y
      const L = Math.hypot(dx, dy) || 1
      return [x + (dx / L) * ballR, y + (dy / L) * ballR]
    }

    v.rope(m, [[Bx, beamY], [Bx, By + ballR]])
    v.rope(m, [onBall(Bx, By, Ax, Ay), onBall(Ax, Ay, Bx, By)])
    v.rope(m, [onBall(Bx, By, PLx, PLy), rimToward(Bx, By, PLx, PLy, pr)])
    v.rope(m, [[PLx, PLy - pr], [PLx, Pby + bh]])
    v.rope(m, [onBall(Ax, Ay, PRx, PRy), rimToward(Ax, Ay, PRx, PRy, pr)])
    v.rope(m, [[PRx, PRy - pr], [PRx, Qby + bh]])

    v.pulley(m, PLx, PLy, pr)
    v.pulley(m, PRx, PRy, pr)
    v.ball(m, Bx, By, ballR, { label: 'B' })
    v.ball(m, Ax, Ay, ballR, { label: 'A' })
    v.block(m, PLx, Pby, bw, bh)
    v.block(m, PRx, Qby, bw, bh)

    const guide = 0.95
    v.line(m, Bx - guide, By, Bx - ballR, By, { color: v.color.graphite, dash: true, width: 1 })
    v.line(m, Bx + ballR, By, Bx + guide, By, { color: v.color.graphite, dash: true, width: 1 })
    v.line(m, Ax + ballR, Ay, Ax + guide, Ay, { color: v.color.graphite, dash: true, width: 1 })

    if (p.theta > 0.5) {
      v.ellipse(m, Bx, By, 0.52, 0.52, { from: 180, to: 180 + p.theta, color: v.color.ink })
      v.ellipse(m, Ax, Ay, 0.52, 0.52, { from: 0, to: p.theta, color: v.color.ink })
      v.label(m, Bx + 0.8 * cos(Math.PI + th / 2), By + 0.8 * sin(Math.PI + th / 2), 'θ')
      v.label(m, Ax + 0.8 * cos(th / 2), Ay + 0.8 * sin(th / 2), 'θ')
    }
    if (p.phi > 0.5) {
      v.ellipse(m, Bx, By, 0.72, 0.72, { from: -p.phi, to: 0, color: v.color.graphite })
      v.label(m, Bx + 0.98 * cos(-ph / 2), By + 0.98 * sin(-ph / 2), 'φ')
    }

    v.label(m, Bx + 0.36, (beamY + By) / 2, 'a')
    v.label(m, (Bx + Ax) / 2 + 0.34 * sin(ph), (By + Ay) / 2 + 0.34 * cos(ph), 'b')
    v.label(m, (Bx + PLx) / 2 - 0.36 * sin(th), (By + PLy) / 2 - 0.36 * cos(th), 'd')
    v.label(m, (Ax + PRx) / 2 - 0.32 * sin(th), (Ay + PRy) / 2 + 0.32 * cos(th), 'c')
    v.label(m, PLx + 0.46, Pby + bh * 0.5, 'P')
    v.label(m, PRx + 0.46, Qby + bh * 0.5, 'Q')
    v.text(m, postL, footY - 0.28, '夹角按平衡画出，绳长不按比例', {
      align: 'left',
      color: v.color.graphite,
      size: 12,
    })
  },

## 四、结合图像理解

装置图里，$\theta$ 增大时 d 更陡、左侧滑轮更低，c 更陡、右侧滑轮更高，这就是“调节定滑轮高度达到平衡”。$\varphi$ 标在 b 与过 B 的水平线之间。题目条件下 $\varphi = 30^\circ$：b 向右下，c 向右上，关于竖直线对称，所以 $T_b = T_c$。

A 的力三角形三条边是 $G$、$T_c$、$T_b$。$\theta = 30^\circ$ 时 $T_b$ 与 $T_c$ 等长，都是 $0.5\ \text{N}$，竖直分力各 $0.25\ \text{N}$，合起来等于重力。图上 $T_c$ 的虚线分力就是容易漏掉的那 $0.25\ \text{N}$。

B 的受力图里，$T_a$ 竖直向上。把 $\theta$ 拖开，$T_d$ 和 $T_b$ 的竖直分力都变，两者与 B 的重力之和仍是 $2mg$，$T_a$ 的箭头长度不动。曲线上 $T_a$ 因此是一条水平线；$T_b$ 随 $\theta$ 增大而减小。游标放在 $30^\circ$、质量为 $50\ \text{g}$ 时，读数是 $1\ \text{N}$ 和 $0.5\ \text{N}$。

质量保持 $50\ \text{g}$，把 $\theta$ 从 $0^\circ$ 拖到 $70^\circ$，$T_b$ 整条曲线都低于 $1\ \text{N}$，选项 C 的第二个数不会出现。质量改成 $100\ \text{g}$ 后，同一条曲线在 $30^\circ$ 处变成 $2\ \text{N}$ 和 $1\ \text{N}$，那是选项 A，对应的质量与题目不符。选项 B 的两个数在 $\theta = 30^\circ$ 时也不可能同时出现，因为这时 $T_a$ 必须是 $T_b$ 的 $2$ 倍。
