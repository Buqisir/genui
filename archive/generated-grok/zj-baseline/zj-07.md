## 一、题目条件分析

电容式触摸屏的传感层可看成平行板电容器。手指是导体，靠近屏幕时，手指与极板之间的电场重新分布，等效电容随之改变。本题只讨论图中的电场、电势和电子轨迹。

图中能直接读出的事实：

- 电场线从手指表面出发，弯曲后落到极板上。电场线从高电势指向低电势，所以手指电势高于这块极板；线在导体表面处与表面垂直。
- A 在手指与极板的间隙里、偏左，该处电场线较密；B 在右侧，电场线较疏。
- ab 是一条弯曲的电场线，从 A 附近延伸到极板。E 在 ab 上，靠近极板。
- C、D 在同一块导体极板的上、下表面，且在同一条竖直线上。

题目没有给出距离和电势的数值。下面的演示取一组代表性条件：极板接地，电势定为 0；手指断面是一个等势圆，电势初值 10 V，圆心高度初值 2.2（坐标只表示相对位置）。这些数值只用来比较大小，画面不按手机的真实尺寸。改变手指电势或高度，只会按比例改变场强和电势的数值，不改变下面四个选项的结论。

## 二、完整解答

### 选项 A

正确。电场线的疏密表示场强的相对大小。A 位于手指正下方的间隙中，电场线密；B 在同一高度的右侧，电场线疏，因此

$$
E_A > E_B
$$

$$
\boxed{E_A>E_B}
$$

演示里 A、B 两处的场强箭头用同一比例尺，右上角给出由该静电场算出的大小，可以直接核对。

### 选项 B

正确。沿电场线方向电势降低。手指是这一组电场线的高电势端，极板是低电势端。A 在手指下方的间隙里，B 在右侧疏区、离手指更远，更接近极板的电势，所以

$$
\varphi_A > \varphi_B
$$

电子电荷 $q=-e<0$，电势能 $E_p=q\varphi$。从 A 移到 B：

$$
\Delta E_p = q(\varphi_B-\varphi_A)=(-e)(\varphi_B-\varphi_A)
$$

$\varphi_B-\varphi_A<0$，负电荷乘上这个负的电势差，得到 $\Delta E_p>0$。也可以先看 $E_p/e=-\varphi$：A 的电势更高，$E_p/e$ 更负，电子在 A 的电势能更小，移到 B 后电势能变大。

电场力会把电子拉向高电势的手指。把电子从 A 挪到 B 是逆着电场力移动，电场力做负功，电势能增加，与上式一致。

$$
\boxed{\Delta E_p>0}
$$

### 选项 C

正确。极板是导体。静电平衡时，导体内部场强处处为零，整块导体是等势体，表面也在这个电势上。C 在上表面，D 在下表面，沿导体内部从 C 到 D，

$$
\varphi_C-\varphi_D=-\int_C^D \vec E\cdot\mathrm d\vec l=0
$$

$$
\boxed{\varphi_C=\varphi_D}
$$

演示里把极板接地，所以这两个电势都等于 0，内部场强也是 0。接地只是把这个共同电势定为 0。即便极板不接地，只要它仍是处于静电平衡的同一块导体，C、D 的电势依然相等。

### 选项 D

错误。ab 是弯曲的电场线，E 靠近它落在极板上的那一端。

在 E 点，电场线的切线指向极板。电子带负电，所受静电力与场强方向相反，释放瞬间加速度背离极板、指向电势更高的手指一侧，并不是顺着 ab 落到极板上。

即使只讨论轨迹是否与这条曲线重合，结论也同样是否定的。电子从静止释放后，最初一小段沿该点的切线加速；ab 随即转弯，速度方向不能跟着电场线一起弯，粒子会离开这条曲线。只有电场线是直线，并且初速度为零或已经沿这条直线时，轨迹才与电场线重合。

$$
\boxed{\text{电子不沿 ab 运动}}
$$

三个判断合在一起，正确选项是 A、B、C。

$$
\boxed{ABC}
$$

sim({
  at(t) {
    return { t: t }
  },
  draw(ctx, s, v) {
    const p = v.p
    const DUR = 2.4
    const m = v.view({ xmin: -1.35, xmax: 7.05, ymin: -2.05, ymax: 4.35, equal: true, pad: 42 })
    const opt = {
      conductors: [
        { cx: p.fingerX, cy: p.h, r: p.rF, V: p.Vf, label: '手指' },
        { points: [[p.xL, 0], [p.xR, 0], [p.xR, p.yBot], [p.xL, p.yBot]], V: 0, label: '极板' },
      ],
      density: 1.3,
      arrows: true,
      through: [[p.Sx, p.Sy]],
    }
    if (p.view == 2 || p.view == 3) opt.equipotentials = 4
    const field = v.efield(m, [], opt)

    function asVec(e) {
      if (!e) return [0, 0]
      if (Array.isArray(e)) return [+e[0] || 0, +e[1] || 0]
      return [+e.x || 0, +e.y || 0]
    }
    function fieldAt(x, y) {
      return asVec(field.E(x, y))
    }
    function fmt(x) {
      if (!isFinite(x)) return '—'
      const ax = Math.abs(x)
      if (ax < 5e-3) return '0'
      if (ax >= 100) return x.toFixed(0)
      if (ax >= 10) return x.toFixed(1)
      if (ax >= 1) return x.toFixed(2)
      return x.toFixed(3)
    }

    const raw = field.line(p.Sx, p.Sy) || []
    const linePts = []
    for (let i = 0; i < raw.length; i++) {
      const q = raw[i]
      if (Array.isArray(q)) linePts.push([q[0], q[1]])
      else if (q && q.x != null) linePts.push([q.x, q.y])
    }

    let ePos = null
    for (let i = 0; i < linePts.length; i++) {
      const py = linePts[i][1]
      if (py > 0.14 && py < 0.46 && (!ePos || py < ePos[1])) ePos = linePts[i]
    }
    if (!ePos) {
      let bestD = 1e9
      for (let i = 0; i < linePts.length; i++) {
        if (linePts[i][1] < 0.1) continue
        const d = Math.abs(linePts[i][1] - 0.3)
        if (d < bestD) {
          bestD = d
          ePos = linePts[i]
        }
      }
    }

    const EA = Math.hypot.apply(null, fieldAt(p.Ax, p.Ay))
    const EB = Math.hypot.apply(null, fieldAt(p.Bx, p.By))
    const phiA = +field.phi(p.Ax, p.Ay)
    const phiB = +field.phi(p.Bx, p.By)
    const phiC = field.potential ? +field.potential(1) : 0
    const phiD = phiC
    const inY = p.yBot / 2
    const Ein = Math.hypot.apply(null, fieldAt(p.Cx, inY))
    const phiIn = +field.phi(p.Cx, inY)

    let ex = ePos ? ePos[0] : p.Sx
    let ey = ePos ? ePos[1] : 0.3
    let path = ePos ? [[ex, ey]] : []
    let splitAt = null
    let splitPos = null

    function distToLine(x, y) {
      if (!linePts.length) return 0
      let dmin = 1e9
      for (let i = 0; i < linePts.length; i++) {
        const d = Math.hypot(x - linePts[i][0], y - linePts[i][1])
        if (d < dmin) dmin = d
      }
      return dmin
    }

    if (ePos) {
      const e0 = fieldAt(ePos[0], ePos[1])
      const E0 = Math.hypot(e0[0], e0[1])
      const gap = Math.max(0.3, p.h - p.rF)
      // 电荷质量比只缩放时间，不改变静止释放的轨迹形状；负号表示电子
      const alpha = E0 > 1e-9 ? -3.2 * gap / (E0 * DUR * DUR) : 0
      function acceleration(x, y) {
        if (y < 0.03) return [0, 0]
        if (Math.hypot(x - p.fingerX, y - p.h) < p.rF) return [0, 0]
        const ee = fieldAt(x, y)
        if (!isFinite(ee[0]) || !isFinite(ee[1])) return [0, 0]
        return [alpha * ee[0], alpha * ee[1]]
      }
      function rk4(x, y, vx, vy, dt) {
        const a1 = acceleration(x, y)
        const x2 = x + 0.5 * dt * vx
        const y2 = y + 0.5 * dt * vy
        const vx2 = vx + 0.5 * dt * a1[0]
        const vy2 = vy + 0.5 * dt * a1[1]
        const a2 = acceleration(x2, y2)
        const x3 = x + 0.5 * dt * vx2
        const y3 = y + 0.5 * dt * vy2
        const vx3 = vx + 0.5 * dt * a2[0]
        const vy3 = vy + 0.5 * dt * a2[1]
        const a3 = acceleration(x3, y3)
        const x4 = x + dt * vx3
        const y4 = y + dt * vy3
        const vx4 = vx + dt * a3[0]
        const vy4 = vy + dt * a3[1]
        const a4 = acceleration(x4, y4)
        return {
          x: x + dt * (vx + 2 * vx2 + 2 * vx3 + vx4) / 6,
          y: y + dt * (vy + 2 * vy2 + 2 * vy3 + vy4) / 6,
          vx: vx + dt * (a1[0] + 2 * a2[0] + 2 * a3[0] + a4[0]) / 6,
          vy: vy + dt * (a1[1] + 2 * a2[1] + 2 * a3[1] + a4[1]) / 6,
        }
      }
      const N = 160
      const dt = v.t > 0 ? v.t / N : 0
      let vx = 0
      let vy = 0
      if (dt > 0) {
        for (let i = 0; i < N; i++) {
          const nxt = rk4(ex, ey, vx, vy, dt)
          const hitF = Math.hypot(nxt.x - p.fingerX, nxt.y - p.h) <= p.rF + 0.05
          const hitP = nxt.y <= 0.045
          const outside = nxt.x < p.xL - 0.3 || nxt.x > p.xR + 0.3 || nxt.y > p.h + p.rF + 0.5
          if (hitF || hitP || outside || !isFinite(nxt.x) || !isFinite(nxt.y)) break
          ex = nxt.x
          ey = nxt.y
          vx = nxt.vx
          vy = nxt.vy
          path.push([ex, ey])
          if (splitAt == null && distToLine(ex, ey) > 0.2) {
            splitAt = (i + 1) * dt
            splitPos = [ex, ey]
          }
        }
      }
    }

    function marker(x, y, name, on, col, place) {
      v.circle(m, x, y, on ? 0.085 : 0.05, { color: on ? col : v.color.ink, width: on ? 2.4 : 1.3 })
      v.label(m, x, y, name, { place: place || 'above', color: on ? col : v.color.ink })
    }
    marker(p.Ax, p.Ay, 'A', p.view == 1 || p.view == 2, p.view == 2 ? v.color.charge : v.color.field, 'left')
    marker(p.Bx, p.By, 'B', p.view == 1 || p.view == 2, p.view == 2 ? v.color.charge : v.color.field, 'above')
    marker(p.Cx, 0, 'C', p.view == 3, v.color.field, 'above')
    marker(p.Cx, p.yBot, 'D', p.view == 3, v.color.field, 'below')

    if (p.view == 3) {
      v.line(m, p.Cx, -0.02, p.Cx, p.yBot, { color: v.color.field, dash: true, width: 1.5 })
      v.circle(m, p.Cx, inY, 0.045, { color: v.color.graphite, width: 1.4 })
      v.label(m, p.Cx, inY, '内部', { place: 'right', color: v.color.graphite })
    }

    if (linePts.length > 1) {
      v.label(m, linePts[0][0], linePts[0][1], 'a', { place: 'above', color: v.color.field })
      const b = linePts[linePts.length - 1]
      v.label(m, b[0], b[1], 'b', { place: 'below', color: v.color.field })
    }
    if (ePos) marker(ePos[0], ePos[1], 'E', p.view == 4, v.color.force, 'right')

    if (path.length > 1) {
      v.path(m, path, { color: v.color.velocity, width: 2.4 })
    }
    if ((p.view == 4 || v.t > 0.02) && ePos) {
      v.circle(m, ex, ey, 0.07, { fill: v.color.charge })
      v.label(m, ex, ey, 'e⁻', { place: 'left', color: v.color.charge })
    }

    if (p.view == 1) {
      const eA = fieldAt(p.Ax, p.Ay)
      const eB = fieldAt(p.Bx, p.By)
      const scale = 0.75 / (EA || 1)
      v.vec(m, p.Ax, p.Ay, eA[0] * scale, eA[1] * scale, { kind: 'field', label: 'E_A' })
      v.vec(m, p.Bx, p.By, eB[0] * scale, eB[1] * scale, { kind: 'field', label: 'E_B' })
    }

    if (p.view == 4 && ePos) {
      const ee = fieldAt(ex, ey)
      const em = Math.hypot(ee[0], ee[1]) || 1
      v.vec(m, ex, ey, ee[0] / em * 0.55, ee[1] / em * 0.55, { kind: 'field', label: 'E' })
      v.vec(m, ex, ey, -ee[0] / em * 0.55, -ee[1] / em * 0.55, { kind: 'force', label: 'F' })
    }

    const info = []
    if (p.view == 1) {
      info.push('E_A = ' + fmt(EA))
      info.push('E_B = ' + fmt(EB))
      info.push(EA > EB ? 'E_A > E_B' : 'E_A ≤ E_B')
    } else if (p.view == 2) {
      info.push('φ_A = ' + fmt(phiA) + ' V')
      info.push('φ_B = ' + fmt(phiB) + ' V')
      info.push('E_pA/e = ' + fmt(-phiA) + ' V')
      info.push('E_pB/e = ' + fmt(-phiB) + ' V')
      info.push(-phiB > -phiA ? 'A→B 电势能增大' : 'A→B 电势能不增大')
    } else if (p.view == 3) {
      info.push('φ_C = ' + fmt(phiC) + ' V')
      info.push('φ_D = ' + fmt(phiD) + ' V')
      info.push('内部 φ = ' + fmt(phiIn) + ' V')
      info.push('内部 E = ' + fmt(Ein))
    } else if (ePos) {
      info.push('与 ab 相距 ' + fmt(distToLine(ex, ey)))
      info.push(v.t < 0.02 ? '尚未释放' : '轨迹见速度色曲线')
    }
    let yText = 4.05
    for (let i = 0; i < info.length; i++) {
      v.text(m, 6.85, yText, info[i], { align: 'right', size: 13, color: v.color.ink })
      yText -= 0.34
    }

    if (ePos) {
      v.event(m, ePos[0], ePos[1], '在 E 点释放', { at: 0, kind: 'force' })
      if (splitPos) v.event(m, splitPos[0], splitPos[1], '离开电场线 ab', { at: splitAt, kind: 'velocity' })
    }
  },
})

## 四、结合图像理解关键时刻

先看静止的电场，再释放电子。

- 观察重点放在 A。手指下方的电场线明显比右侧密，场强箭头在同一比例尺下 A 更长。手更靠近时，间隙里的线更密，$E_A$ 更大，$E_A>E_B$ 仍然成立。这就是手指靠近时触摸屏能感应到电容变化的场分布。
- 观察重点放在 B，打开等势线。等势线靠近手指处电势高，靠近极板处电势降到 0。同一高度上 A 比 B 更靠近手指，所以 $\varphi_A>\varphi_B$。电子的 $E_p/e=-\varphi$，因此 A 的电势能更低，从 A 到 B 电势能增大。
- 观察重点放在 C、D。虚线穿过导体内部，内部场强为 0，C、D 和内部是同一个电势。接地只把这个电势定为 0，相等本身来自导体是等势体。
- 时间轴在 0：电子停在 E。该处电场线指向极板，静电力箭头相反，指向手指一侧。进度到「飞离极板」之后，速度色的轨迹和加粗的 ab 分开；电子朝手指走，不会沿 ab 落到极板上。ab 是弯曲的，静止释放的电子只在最初一瞬间沿切线加速，随后离开这条曲线。
