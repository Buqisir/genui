## 一、题目条件分析

- α 粒子电荷 $q = +2e$，金原子核电荷 $Q = +79e$，两者都带正电，库仑力是斥力。
- 题目给出金核静止，图中核的位置不动。下面把金核当作固定在圆心的点电荷，只讨论 α 粒子的轨迹。
- 不考虑 α 粒子之间的相互作用，每个 α 粒子的电势能只由它到金核的距离决定。
- 虚线圆以金核为圆心，圆上各点到核的距离相同，电势相同。
- 轨迹 1：从核的上方掠过，偏转很小，整段都在虚线圆外。轨迹 2：几乎正对金核射来，在 P 点圆滑转弯后向左下方离开。P 是这段轨迹离核最近的位置。
- 选项 D 把距离定为 $r = 10^{-14}\ \text{m}$，并给出 $k$、$e$ 和原子序数，可以算出库仑力的大小。

题目没有给 α 粒子的质量和初速度。动画里这两项以及静电力常量用示意数值，只保证斥力散射的形状、做功正负和能量转化与真实过程一致。库仑力的牛顿数仍只用题目数据计算。

## 二、完整解答

### A

**错误。** 库仑力沿两电荷连线、方向由金核指向 α 粒子。α 粒子从远处飞来再飞走，到金核的距离先减小、后增大。

距离减小时，电势能 $E_p = k(2e)(79e)/r$ 增大，动能减小，库仑力做负功。距离增大时，电势能减小，动能增大，库仑力做正功。轨迹 1 虽然偏转很小，同样要先靠近、再远离，中间有一个离核最近的时刻。因此是先做负功、后做正功。

### B

**错误。** P 是轨迹 2 的圆滑转弯点，也是这段轨迹上离金核最近的点。$r$ 最小时 $E_p$ 最大，所以「电势能最大」指的是这条轨迹上的最大，这一半成立。

「动能为零」不成立。最近点处，速度已经转到与半径垂直，径向分速度为零，但沿切线的速度还在。轨迹 2 过 P 之后继续弯向左下方，说明 P 处速度不是零。动能若真是零，粒子会停住，再沿来时的直线被斥回去，画不出图中不断开的圆滑弯折。动能减到零只出现在正对金核的对心碰撞里，那不是轨迹 2。

### C

**错误。** 固定点电荷的电势 $\varphi = kQ/r$ 只与到金核的距离有关。虚线圆以金核为圆心，圆上每个点的 $r$ 都等于半径，$\varphi$ 相同。

α 粒子的电荷都是 $+2e$，题目又要求不考虑它们之间的相互作用，所以电势能 $E_p = q\varphi$ 只由 $r$ 决定。三颗粒子都在这条虚线圆上，电势能相等。它们的速度、动能可以不同，选项说的是电势能。

### D

**正确。** α 粒子与金核相距 $r = 10^{-14}\ \text{m}$ 时

$$
\begin{aligned}
F &= \frac{k\cdot(2e)\cdot(79e)}{r^2} \\
&= \frac{9.0\times 10^{9}\times 2\times 79\times(1.6\times 10^{-19})^{2}}{(1.0\times 10^{-14})^{2}} \\
&= \frac{9.0\times 10^{9}\times 158\times 2.56\times 10^{-38}}{1.0\times 10^{-28}} \\
&= 9.0\times 158\times 2.56\times 10^{9-38+28} \\
&= 3640.32\times 10^{-1} \\
&= 364.032\ \text{N} = 3.64\times 10^{2}\ \text{N}
\end{aligned}
$$

按高中的写法，把数写成 $a\times 10^{n}$ 且 $1 \le a < 10$，这里 $a = 3.64$、$n = 2$，数量级是 $10^{2}\ \text{N}$。

$$
F = \boxed{3.64\times 10^{2}\ \text{N}}
$$

漏掉 α 粒子的因子 2，会得到约 $1.8\times 10^{2}\ \text{N}$，数量级仍然是 $10^{2}$。指数对这个因子不敏感，但 $r^{2} = 10^{-28}$ 不能写成 $10^{-14}$。

四个选项里只有 D 成立，所以选 $\boxed{D}$。

> 转弯不是停住：曲线在最近点的速度垂直于半径。做功看正在靠近还是正在远离。电势能看 $r$，不看方位角，也不看速度。数量级看 $10$ 的指数。

sim({
  at(t, p) {
    return p.fly.state(t)
  },
  draw(ctx, s, v) {
    const p = v.p
    const m = v.view({ xmin: -9.2, xmax: 9.2, ymin: -9.2, ymax: 9.2, equal: true, pad: 34 })
    v.line(m, -8.6, 0, 8.6, 0, { color: v.color.hairline })
    v.line(m, 0, -8.6, 0, 8.6, { color: v.color.hairline })

    function track(motion) {
      const pts = []
      const n = 90
      const T = motion.tEnd
      for (let i = 0; i <= n; i++) {
        const st = motion.state(T * i / n)
        pts.push([st.x, st.y])
      }
      return pts
    }
    function drawRef(motion, caption) {
      const pts = track(motion)
      v.path(m, pts, { color: v.color.steel, width: 1.5 })
      const a = pts[pts.length - 2]
      const bpt = pts[pts.length - 1]
      v.arrow(m, a[0], a[1], bpt[0], bpt[1], { color: v.color.steel })
      if (caption) v.label(m, bpt[0], bpt[1], caption)
    }
    drawRef(p.fly1, '轨迹 1')
    drawRef(p.fly2, '轨迹 2')
    drawRef(p.fly3, '')
    drawRef(p.fly4, '')

    const sp = p.fly2.state(p.tP2)
    const R = Math.hypot(sp.x, sp.y)
    v.ellipse(m, 0, 0, R, R, { color: v.color.field, dash: true, width: 1.6 })

    const fixedDeg = [140, 300]
    for (let i = 0; i < fixedDeg.length; i++) {
      const ang = fixedDeg[i] * Math.PI / 180
      v.ball(m, R * Math.cos(ang), R * Math.sin(ang), 0.28, { charge: true })
    }
    const ap = p.phi * Math.PI / 180
    v.ball(m, R * Math.cos(ap), R * Math.sin(ap), 0.34, { charge: true, label: 'φ' })
    v.label(m, R * Math.cos(140 * Math.PI / 180), R * Math.sin(140 * Math.PI / 180), '圆上')

    v.regions(m, p.fly)

    v.path(m, track(p.fly), { color: v.color.velocity, width: 2.2 })
    v.trail(m, function (st) { return [st.x, st.y] }, { kind: 'velocity', every: 0.2 })
    v.ball(m, s.x, s.y, 0.36, { charge: true, label: 'α' })

    const rlen = Math.hypot(s.x, s.y) || 1
    v.vec(m, s.x, s.y, s.vx * 0.2, s.vy * 0.2, { kind: 'velocity', label: 'v' })
    const fShow = Math.max(0.55, Math.min(2.3, 5 / rlen))
    v.vec(m, s.x, s.y, (s.x / rlen) * fShow, (s.y / rlen) * fShow, { kind: 'force', label: 'F' })

    v.circle(m, sp.x, sp.y, 0.12, { fill: v.color.field, color: v.color.field })
    v.label(m, sp.x, sp.y, 'P')
    if (Math.abs(p.b) > 0.15) v.dim(m, 0.45, 0, 0.45, p.b, 'b')
    v.event(m, s.x, s.y, '离核最近', { at: p.tP, kind: 'field' })
  },
})

## 四、结合图像理解关键时刻

入射时 α 粒子还在远处，电势能较小，功率为负，动能开始减小。播放轨迹 1，功率曲线整段先在横轴下方，到「离核最近」才改号。选项 A 把正负说反了。

切到「轨迹 2：到达 P」。能量账本里这一行的电势能最高，动能仍留着一块，最近点速率不是 0。再切到「对心碰撞」：粒子停在虚线圆内侧，动能才减到 0，随后沿原路返回。轨迹 2 的弯折不是这种停住。选项 B 把对心碰撞的结论套到了曲线轨迹上。

P、方位角 φ 处的 ⊕、以及圆上另一颗 ⊕，到金核的距离都是虚线圆半径，电势能都是 $E_{p圆}$。拖动 φ，粒子沿圆走动，这个读数不动。把当前轨迹改成轨迹 1，最近点在圆外，$E_{pP} < E_{p圆}$；改成对心，停在圆内，$E_{pP} > E_{p圆}$。电势能只随距离变。选项 C 说圆上三颗粒子的电势能不相等，不成立。

把距离滑块放回 $10^{-14}\ \text{m}$。读数是 $F = 364\ \text{N}$，$a = 3.64$，$n = 2$，也就是 $3.64\times 10^{2}\ \text{N}$。表盘指针在 $100\ \text{N}$ 到 $1000\ \text{N}$ 的色带里。把 $r$ 调到 $5\times 10^{-15}\ \text{m}$，力增大到约 $1.5\times 10^{3}\ \text{N}$，数量级变成 $10^{3}$；调到 $4\times 10^{-14}\ \text{m}$，数量级变成 $10^{1}$。题目所给的距离对应 $10^{2}\ \text{N}$，选项 D 成立。

## 五、答案汇总

| 选项 | 判断 | 要点 |
|---|---|---|
| A | 错误 | 先靠近后远离，库仑力先做负功、后做正功 |
| B | 错误 | P 处电势能在该轨迹上最大，但动能不为零 |
| C | 错误 | 虚线圆上 $r$ 相同，三颗 α 粒子电势能相等 |
| D | 正确 | $F = 364.032\ \text{N} = 3.64\times 10^{2}\ \text{N}$，数量级为 $10^{2}\ \text{N}$ |

答案是 $\boxed{D}$。
