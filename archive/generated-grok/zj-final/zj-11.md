## 一、题目条件分析

俯视。正方形线框绕中心转过 $45^\circ$，一条对角线沿 $Ox$，另一条沿竖直方向。边长为 $\sqrt{2}\,L$，对角线为 $2L$，中心到任一顶点的距离为 $L$。

磁场在边界 $CD$（直线 $X = 0$）的左侧，垂直地面向下。中心坐标记为 $x$：左顶点在 $x - L$，右顶点在 $x + L$，上顶点 $C$、下顶点 $D$ 的横坐标都是 $x$。$x = 0$ 时竖直对角线与 $CD$ 重合，左半在磁场中，右半在磁场外。

开关闭合后，恒流源把电流维持为大小 $I$、方向逆时针（右上边由右顶点流向 $C$）。水平面光滑，不计空气阻力。支持力和重力竖直，水平方向只有安培力。

题目给的是字母。交互里取一组代表值，使各问的数值都是整数：

$$
I = 2\ \text{A},\quad B = 2\ \text{T},\quad L = 1\ \text{m},\quad m = 1.5\ \text{kg},\quad R = 1\ \Omega
$$

符号结果对任意正的 $I$、$B$、$L$、$m$、$R$ 都成立。滑块初始值就是这组数。

## 二、完整解答

中心在 $0 \le x \le L$ 时，磁场边界交线框于 $(0,\ L - x)$ 和 $(0,\ -(L - x))$。留在磁场里的是左侧那段折线，电流从上方交点经左顶点流到下方交点，等效成沿 $CD$ 向下的直导线，等效长度

$$
l = 2(L - x)
$$

$B$ 垂直纸面向里，左手定则：掌心迎向纸外，四指向下，拇指指向右。安培力水平向右，大小

$$
F = IlB = 2IB(L - x)
$$

核对：左上、左下两段都与 $B$ 垂直，每段受力大小为 $IB(L - x)\sqrt{2}$，分别指向右下方和右上方。竖直分量抵消，水平分量各为 $IB(L - x)$，合力仍是 $2IB(L - x)$，向右。$x > L$ 后线框整体在磁场外，$F = 0$。

### （1）① 刚闭合时的安培力

$x = 0$ 时 $l = 2L$，

$$
F = 2IBL
$$

方向水平向右。大小

$$
\boxed{2IBL}
$$

### （1）② 功和冲量

从 $x = 0$ 到 $x = L/2$，$F$ 始终向右且与位移同向：

$$
W = \int_0^{L/2} 2IB(L - x)\,\mathrm{d}x = 2IB\left[Lx - \frac{x^2}{2}\right]_0^{L/2} = 2IB\left(\frac{L^2}{2} - \frac{L^2}{8}\right) = \frac{3}{4}IBL^2
$$

光滑水平面上只有安培力做功，

$$
\frac{1}{2}mv^2 = W \Rightarrow v = L\sqrt{\frac{3IB}{2m}}
$$

初动量为零，冲量等于末动量，方向向右：

$$
J = mv = L\sqrt{\frac{3IBm}{2}}
$$

$$
\boxed{\dfrac{3}{4}IBL^{2}},\qquad \boxed{L\sqrt{\dfrac{3IBm}{2}}}
$$

功只由 $F(x)$ 决定，表达式里没有 $m$。冲量等于 $mv$，含有 $m$。

### （1）③ 恒流源的电压

磁场中的面积是底为 $2(L - x)$、高为 $L - x$ 的三角形，

$$
S = (L - x)^2,\qquad \Phi = B(L - x)^2
$$

$x$ 增大时向下的磁通量减小。感应电流要补充向下的场，方向为顺时针，与恒流源的逆时针电流相反，动生电动势是反电动势：

$$
\mathcal{E} = B\left|\frac{\mathrm{d}S}{\mathrm{d}t}\right| = 2B(L - x)v = Blv
$$

它也等于 $Fv/I$。恒流源同时支付焦耳热和机械能，$UI = I^2R + Fv$，所以

$$
U = IR + \mathcal{E}
$$

$x = L/2$ 时 $l = L$，$\mathcal{E} = BLv = BL^2\sqrt{3IB/(2m)}$，

$$
\boxed{IR + BL^{2}\sqrt{\dfrac{3IB}{2m}}}
$$

### （2）时间差

$0 \le x \le L$ 时

$$
m\ddot{x} = 2IB(L - x)
$$

令 $\xi = L - x$，则

$$
\ddot{\xi} + \omega^2\xi = 0,\qquad \omega = \sqrt{\frac{2IB}{m}}
$$

平衡位置在 $\xi = 0$（即 $x = L$）。从静止出发，$\xi = \xi_0\cos\omega t$。第一次到达 $\xi = 0$ 时 $\omega t = \pi/2$，

$$
t = \frac{\pi}{2\omega} = \frac{\pi}{2}\sqrt{\frac{m}{2IB}}
$$

这段时间只由 $\omega$ 决定，与振幅 $\xi_0$ 无关。

- 从 $x = 0$ 出发：$\xi_0 = L$，到达 $x = L$ 用 $t_1 = \pi/(2\omega)$。
- 从 $x = L/2$ 出发：$\xi_0 = L/2$，到达 $x = L$ 用 $t_2 = \pi/(2\omega)$。

两次的 $\xi_0$ 都不超过 $L$，走到 $\xi = 0$ 之前力的规律 $F = 2IB(L - x)$ 一直成立。到达 $x = L$ 之后线框离开磁场，$F$ 保持为 $0$，改为匀速，不再按简谐运动返回。题目要的是到达 $x = L$ 的时刻，正好是这四分之一周期：

$$
t_1 - t_2 = \boxed{0}
$$

显式写出来：$x_1 = L(1 - \cos\omega t)$，$x_2 = L - (L/2)\cos\omega t$，都在 $\omega t = \pi/2$ 时等于 $L$。出口速度不同，$v_1 = L\omega$，$v_2 = (L/2)\omega$，所以同时到达之后从 $x = 0$ 出发的那一次更快。$t_1$、$t_2$ 不含 $L$，也不含出发位置。

### 代表值核对

$I = 2$，$B = 2$，$L = 1$，$m = 1.5$，$R = 1$：

$$
F = 2\times 2\times 2\times 1 = 8\ \text{N}
$$

$$
W = \frac{3}{4}\times 2\times 2\times 1 = 3\ \text{J}
$$

$$
v = \sqrt{\frac{3\times 2\times 2}{2\times 1.5}} = \sqrt{4} = 2\ \text{m/s},\qquad J = 1.5\times 2 = 3\ \text{N·s}
$$

$$
\mathcal{E} = 2\times 1\times 2 = 4\ \text{V},\qquad U = 2 + 4 = 6\ \text{V}
$$

$$
\omega = \sqrt{\frac{8}{1.5}} = \sqrt{\frac{16}{3}},\qquad t_1 = t_2 = \frac{\pi\sqrt{3}}{8}\ \text{s} \approx 0.680\ \text{s}
$$

$$
\boxed{8\ \text{N}},\ \boxed{3\ \text{J}},\ \boxed{3\ \text{N·s}},\ \boxed{6\ \text{V}},\ \boxed{0}
$$

侧栏「查看答案」对的是这五个数。读数区里随播放变化的是当前时刻；功、冲量和所求电压对应「中心到 $x = L/2$」那一时刻。

      v.vec(m, s.x, L + 0.3 * L, 2 * kF * IBl, 0, { kind: 'force', label: '合力' })
    }
    const kV = (0.48 * L) / vExit
    if (s.v > 0.03 * vExit) {
      v.vec(m, s.x + L, 0.18 * L, kV * s.v, 0, { kind: 'velocity', label: 'v' })
    }

    v.event(m, L / 2, 0.42 * L, '中心到 x = L/2', { at: p.tHalf, kind: 'velocity' })
    v.event(m, L, -0.42 * L, '离开磁场，改为匀速', { at: p.t1, kind: 'force' })
  },
})
</Sim>

## 四、结合图像理解关键时刻

刚闭合时 $x = 0$，$F$–$x$ 图在纵轴上的截距是 $2IBL$。代表值下是 $8\ \text{N}$。画面上 $F_1$ 指向右下，$F_2$ 指向右上，合力向右。此时速度仍为 $0$，动生电动势为 $0$，恒流源电压等于 $IR$（代表值下 $2\ \text{V}$）。

中心到 $x = L/2$ 时，等效长度缩成 $L$，安培力降到刚闭合时的一半。$F$–$x$ 图上 $0$ 到 $L/2$ 的阴影就是功，代表值下 $3\ \text{J}$。账本里这一行的动能等于这份功，多出来的是焦耳热。电压图上这一刻的 $U$ 高于虚线 $IR$，代表值下是 $6\ \text{V}$。$\varepsilon = BL^2\omega\sin 2\omega t$，最大值在 $\omega t = \pi/4$，而 $x = L/2$ 对应 $\omega t = \pi/3$，所以所求电压不是全程最大电压。

$x$–$t$ 图上两条曲线在同一横坐标碰到 $x = L$。速度图上两条曲线也在这一时刻由正弦变成水平，上一条的平台是下一条的两倍。频闪点在此之后间距不再变化。时间差的读数在积分误差内为 $0$，公式上严格为 $0$。
