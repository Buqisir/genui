## 题目条件分析

**下潜前（水面处）**：瓶的容积 $V_容=380\ \text{mL}$，瓶里装了 80 mL 水，其余部分是被封住的空气，视为理想气体。此时瓶盖拧紧，气体压强就是大气压强，气体体积

$$p_1=p_0=1.0\times10^{5}\ \text{Pa},\qquad V_1=(380-80)\ \text{mL}=300\ \text{mL}$$

**到水底后**：倒置瓶身、打开瓶盖，水从瓶口进入瓶内，把瓶内气体压缩。全程气体不泄漏、温度不变，所以这是**等温过程**（玻意耳定律）。稳定后瓶内水的体积为 230 mL，故气体体积

$$V_2=(380-230)\ \text{mL}=150\ \text{mL}$$

瓶内气体与**瓶内水面**处的压强平衡。瓶内水面到瓶口只有几十厘米，这点高度差引起的附加压强远小于 $\rho g h$（原图也把瓶口处的压强直接当作瓶内气体的压强），于是

$$p_2=p=p_0+\rho g h$$

其中 $h$ 是水面到水底（瓶口）的深度。

## 完整解答

### （1）求水底的压强 p

瓶内气体的质量不变、温度不变，由玻意耳定律

$$p_1V_1=p_2V_2\quad\Rightarrow\quad p=p_0\frac{V_1}{V_2}=1.0\times10^{5}\times\frac{300}{150}\ \text{Pa}=\boxed{2.0\times10^{5}\ \text{Pa}}$$

水底压强恰好是大气压强的 2 倍。

### （2）求水的深度 h

由液体内部压强公式 $p=p_0+\rho g h$ 得

$$h=\frac{p-p_0}{\rho g}=\frac{(2.0-1.0)\times10^{5}}{1.0\times10^{3}\times10}\ \text{m}=\boxed{10\ \text{m}}$$

**顺带一看**：$h_0=\dfrac{p_0}{\rho g}=10\ \text{m}$ 正好是一个大气压对应的水柱高度，所以"水底压强是 2 个大气压"就等于"水深 10 m"，两个结果互相印证。

## 交互演示

拖动侧栏的**水深 h** 滑块，看瓶内液面怎么变：

- $h=0$（水面处）：瓶内气体 300 mL、压强 $p_0$，瓶内水 80 mL，液面很低（虚线是下潜前液面的位置）；
- $h=10\ \text{m}$：瓶内气体被压到 150 mL、压强升到 $2p_0$，水进入瓶内 230 mL，液面升到瓶身上部，这正是题目所求状态。

虚线是下潜前液面（80 mL 水）的位置，实线是当前瓶内液面；两者之间的距离就是"新进入瓶内的水"所占的体积。读数栏里的 $p$、$V_g$、$V_w$ 都跟着滑块变，点「水底：h = 10 m（答案）」可一键回到题目所求状态。

<Figure title="倒置的玻璃瓶在水底" height={470} size="narrow" params={["h", "Vw", "Vg"]} note="瓶的尺寸与水深不按比例">
figure({
  draw(ctx, p, v) {
    const m = v.view({ xmin: -2.4, xmax: 2.4, ymin: -2.1, ymax: 3.5 })
    const surfY = 2.8
    const floorY = -1.55
    const NX1 = -0.35, NX2 = 0.35, NY1 = -1.4, NY2 = 0
    const BX1 = -0.85, BX2 = 0.85, BY1 = 0, BY2 = 1.5
    const AN = (NX2 - NX1) * (NY2 - NY1)
    const AB = (BX2 - BX1) * (BY2 - BY1)
    const levelY = function (V) {
      const A = V / 380 * (AN + AB)
      if (A <= AN) { return NY1 + A / (NX2 - NX1) }
      return BY1 + (A - AN) / (BX2 - BX1)
    }

    v.line(m, -2.3, surfY, 2.3, surfY, { color: v.color.steel })
    v.label(m, -2.05, surfY + 0.24, "水面")
    v.label(m, 1.0, surfY + 0.24, "大气压强 p_0")
    v.ground(m, -2.3, 2.3, floorY)
    v.label(m, -2.0, floorY - 0.4, "水底")

    v.vessel(m, [
      { x1: BX1, y1: BY1, x2: BX2, y2: BY2 },
      { x1: NX1, y1: NY1, x2: NX2, y2: NY2, open: "bottom" }
    ], {})

    const yL = levelY(p.Vw)
    const pts = [[NX1, NY1], [NX2, NY1]]
    if (yL <= NY2) {
      pts.push([NX2, yL], [NX1, yL])
    } else {
      pts.push([NX2, NY2], [BX2, BY1], [BX2, yL], [BX1, yL], [BX1, BY1], [NX1, NY2])
    }
    v.path(m, pts, { close: true, fill: v.color.field, color: v.color.field })

    v.line(m, BX1, yL, BX2, yL, { color: v.color.field })
    const y0 = levelY(80)
    v.line(m, -1.55, y0, 1.55, y0, { color: v.color.steel, dash: true })
    v.label(m, -1.55, y0 - 0.3, "下潜前液面 80 mL")
    v.label(m, 1.55, yL + 0.3, "下潜后液面")
    v.label(m, 0, (yL + BY2) / 2, "气体 V_g = " + p.Vg.toFixed(0) + " mL")

    v.dim(m, 1.95, surfY, 1.95, NY1, "h = " + p.h.toFixed(1) + " m")
  }
})
</Figure>

- 曲线**向上凸、越来越平**：水越深，瓶内压强 $p=p_0+\rho gh$ 越大，气体越难再被压缩，同样多下潜一段，进入瓶内的水越来越少（瓶内最多只能装 380 mL 水，曲线以 380 mL 为渐近线）。
- 曲线上每一点都同时满足两条规律：气体等温 $p_0V_1=p\,(380-V_w)$ 与静水压强 $p=p_0+\rho gh$。
- $h=10\ \text{m}$ 处曲线读数正好是 230 mL，与题给条件吻合，这正是求出 $p=2p_0$、$h=10\ \text{m}$ 的依据。
