## 题目条件分析

运动员全程分成三个阶段，每个阶段受什么力、加速度是不是恒定，决定了 v–t 和 a–t 的形状：

1. **斜面 MN 段（0 ~ t₁）** 光滑斜面，重力沿斜面向下的分力 $mg\sin\theta$ 和垂直斜面的支持力都不变，合力恒定：
   $$a_1 = g\sin\theta,\qquad v = g\sin\theta\cdot t$$
   由静止开始匀加速，v–t 是一条过原点、斜率为 $g\sin\theta$ 的直线，a–t 是一条正的水平线。
2. **水平段 NP（t₁ ~ t_P）** 水平面上重力与支持力平衡，题目不计摩擦，合力为零：$a_2 = 0$，速度保持 $v_P$ 不变。题目说 NP 段「很短」，所以 v–t 上这一段很短。
3. **空中（t_P 之后到落地 Q）** 只受重力，$a_3 = g$ 恒定、方向竖直向下，是平抛运动，速度大小
   $$v = \sqrt{v_P^{2} + (g\tau)^{2}},\qquad \tau = t - t_P$$
   τ = 0 时切线水平（速度水平、重力竖直，重力此刻不改变速度大小），随后曲线向上弯曲，斜率由 0 逐渐增大、最后趋近 g。

要点：**三个阶段加速度都是恒定的**，所以 a–t 只能是三段水平平台；又因为 $\sin\theta < 1$，必有

$$\boxed{a_1 = g\sin\theta < g = a_3}$$

也就是 a–t 的第三段平台必须比第一段高。这是本题的判决点。

题目只有字母没有数值，下面取一组代表值定量演示：$\theta = 30^\circ$、$g = 10\ \mathrm{m/s^2}$、MN 长 10 m、NP 长 4 m、P 点高出落点坡面 3 m、落点坡面倾角 10°。由此

- $a_1 = g\sin 30^\circ = 5\ \mathrm{m/s^2}$，$a_2 = 0$，$a_3 = g = 10\ \mathrm{m/s^2}$；
- 离台速度 $v_P = \sqrt{2gL\sin\theta} = 10\ \mathrm{m/s}$。

## 完整解答

**A（v–t 图）——错误。** 前面「直线上升 → 一段短水平线」画对了，问题在第三段：它画成了一条直线，斜率还与第一段相近。离开 P 后
$$v=\sqrt{v_P^{2}+g^{2}\tau^{2}}$$
τ = 0 时切线水平（速度水平、重力竖直，重力此刻不改变速度大小），之后斜率由 0 逐渐增大、最后趋近 g，是一条向上弯曲的曲线；它也不是斜率为 $g\sin\theta$ 的直线，更不会与第一段平行。

**B（v–t 图）——错误。** 空中速度不可能减小。重力与速度方向的夹角始终小于 90°，重力做正功，速度大小单调增大；竖直分速度为 0 的那一瞬间速度取最小值，也只是回到 $v_P$。所以 v–t 的第三段只会上升，不会直线下降回 t 轴。

**C（a–t 图）——正确。** 三个阶段的加速度都是恒定的：斜坡上 $a_1 = g\sin\theta$（正的水平段），水平段 $a_2 = 0$（落到零），空中 $a_3 = g$（正的水平段）。由于 $\sin\theta<1$，$g\sin\theta<g$，第三段平台比第一段高，「低—零—高」三段水平线完全对得上。

**D（a–t 图）——错误。** 两段等高意味着 $g\sin\theta = g$，即 $\sin\theta = 1$，坡面必须竖直，与题图不符。实际上空中加速度 $g$ 一定大于斜面加速度 $g\sin\theta$，后一段必须更高。

## 交互演示

上面动画里拖动进度条（或点右边按钮）看运动员走过的三个阶段，两张图上的游标同步跟着走：

- 斜面段：v 线性增长、a 是高度 $g\sin\theta$ 的水平线，a 箭头沿斜面向下，斜率越大（θ 越大）这段越陡；
- 水平段：v 是一条短水平线、a 掉到 0，速度箭头长度不变；
- 空中段：a 跳高到 g，v 从水平切线开始向上弯曲地增长。

拖 θ 滑块可以改变斜面倾角，但无论 θ 取多少（只要 $\theta < 90^\circ$），v–t 的第三段都是曲线，a–t 的第三段都高于第一段——这正是排除 A、B、D 的依据。

## 结合图像理解关键时刻

以代表值（θ = 30°、g = 10 m/s²）为例：

| 时刻 | 事件 | 速度大小 | 加速度大小 |
| --- | --- | --- | --- |
| t = 0 | 从 M 由静止下滑 | 0 | $a_1 = g\sin\theta = 5\ \mathrm{m/s^2}$ |
| t = 2.0 s | 到 N，v–t 出现折点、a 从 5 跳到 0 | $v_P = 10\ \mathrm{m/s}$ | 0 |
| t = 2.4 s | 到 P，a 从 0 跳到 g，v–t 开始向上弯 | $v_P = 10\ \mathrm{m/s}$ | $g = 10\ \mathrm{m/s^2}$ |
| t = 3.37 s | 落到 Q，速度最大 | $v_Q\approx 13.9\ \mathrm{m/s}$ | $g = 10\ \mathrm{m/s^2}$ |

竖直分速度为 0 的那一瞬间速度最小（等于 $v_P$），所以空中段 v–t 的最低点就是离开 P 时的 10 m/s，之后一路上升到 13.9 m/s——B 图画的「降回零」根本不可能出现。

## 答案汇总

$$\boxed{\text{C}}$$

判定依据：$a_1 = g\sin\theta < a_3 = g$。三阶段加速度都恒定，故 a–t 是三段水平平台，第三段高于第一段；而 v 全程单调不减、第三段为曲线。
