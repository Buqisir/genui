## 题目条件分析

- 转子是中心在 O 点的条形磁铁，在纸面内绕 O 点匀速转动。设转动频率为 $f$，则角速度 $\omega = 2\pi f$，转一圈用时 $T = 1/f$。
- 定子的两个线圈轴线在同一平面内且互相垂直，两线圈到轴线交点 O 的距离相等、形状相同。所以磁铁在两个线圈处"地位完全对等"：穿过每个线圈的磁通量最大值相同，都记作 $\Phi_m$。它们唯一的区别是匝数 $n_1 > n_2$。
- 两个线圈各接一个阻值相同的电阻 $R$，线圈电阻、自感、互感都不计，因此每个线圈都可以看成"电动势 $e$ 加在自己的 $R$ 上"的独立回路，流过每个电阻的电流就是该线圈的电流。

取 $t = 0$ 为磁铁磁矩方向沿**线圈 1 轴线**的时刻，则磁矩方向与线圈 1 轴线的夹角 $\theta = \omega t$。磁通量正比于磁矩在轴线方向上的投影，于是

$$\Phi_1 = \Phi_m\cos\omega t,\qquad \Phi_2 = \Phi_m\sin\omega t$$

由法拉第电磁感应定律 $e = n\dfrac{\Delta\Phi}{\Delta t}$：

$$e_1 = -n_1\omega\Phi_m\sin\omega t,\qquad e_2 = n_2\omega\Phi_m\cos\omega t$$

峰值 $E_{1m} = n_1\omega\Phi_m$、$E_{2m} = n_2\omega\Phi_m$，有效值 $E = E_m/\sqrt2$。

## 参考数值

题目只给了字母条件（$n_1,n_2,R,f$ 都没给数）。为了把曲线和读数画出来，取一组有代表性的数值：$f = 1$ Hz（$T = 1$ s）、$n_1 = 100$ 匝、$n_2 = 50$ 匝、$\Phi_m = 0.01$ Wb（$R$ 取多少都不影响判断）。代入得 $\omega = 2\pi \approx 6.28$ rad/s。**所有结论都与这组数值的选取无关**，改变滑块只是让比例看得更清楚。

## 完整解答

### A. 两线圈产生的电动势的有效值相等——错误

有效值 $E = \dfrac{E_m}{\sqrt2} = \dfrac{n\omega\Phi_m}{\sqrt2}$，与匝数成正比。代入数值：

$$E_{1m} = 100\times6.28\times0.01 = 6.28\ \text{V},\quad E_{2m} = 50\times6.28\times0.01 = 3.14\ \text{V}$$

$$E_1 = \frac{6.28}{\sqrt2} = 4.44\ \text{V},\qquad E_2 = \frac{3.14}{\sqrt2} = 2.22\ \text{V}$$

$E_1 : E_2 = n_1 : n_2 = 2:1$，两个有效值**不相等**。（穿过两线圈的磁通量最大值相同，但匝数不同，所以电动势的峰值、有效值都不同。）

### B. 两线圈产生的交变电流频率相等——正确

磁铁转过一圈（用时 $T = 1/f$），穿过每个线圈的磁通量经历"最大 → 0 → 反向最大 → 0 → 最大"，恰好变化一个完整的周期；磁铁转 $k$ 圈，磁通量就变化 $k$ 个周期。所以两个线圈的电动势周期都等于转动周期 $T$，频率都等于 $f = 1$ Hz，**与匝数 $n$、与电阻 $R$ 都无关**。这就是"旋转磁极式发电机"里两相输出频率必然相同的原因。

### C. 两线圈产生的电动势同时达到最大值——错误

$e_1 \propto \sin\omega t$，在 $\omega t = 90°$、$270°$（磁矩与线圈 1 轴线垂直，即磁矩沿线圈 2 轴线）时达到峰值；$e_2 \propto \cos\omega t$，在 $\omega t = 0°$、$180°$（磁矩沿线圈 1 轴线）时达到峰值。两个峰值时刻相差 $\Delta t = T/4$，**不会同时达到最大值**。例如 $t = T/4$ 时 $e_1$ 达峰值而 $e_2 = 0$。

### D. 两电阻消耗的电功率相等——错误

电阻相同，功率 $P = \dfrac{E^2}{R}$，所以

$$P_1 : P_2 = E_1^2 : E_2^2 = n_1^2 : n_2^2 = 100^2 : 50^2 = 4 : 1$$

两个电阻消耗的电功率**不相等**，线圈 1 的电阻功率是线圈 2 的 4 倍。

## 交互演示怎么看

- **左图**：条形磁铁绕 O 在纸面内匀速转动，左侧是 $n_1$ 匝线圈（轴线水平），下方是 $n_2$ 匝线圈（轴线竖直），两个线圈各接一个阻值为 $R$ 的电阻。转动周期 $T = 1/f$。
- **曲线图**：$e_1$（蓝）与 $e_2$（橙）随 $t$ 变化。两条曲线的**周期完全相同**——这就是选项 B 正确的原因；但**峰值之比等于匝数之比**，峰值时刻相差 $T/4$——这就是 A、C 错误的原因。
- 侧栏读数给出 $E_{1m}$、$E_{2m}$、$E_1$、$E_2$ 和 $P_1/P_2$。拖动 $n_1$（同时 $n_2 = n_1/2$ 保持 $n_1 > n_2$）可以看到峰值、有效值、功率都按 $n$ 成比例变化，而频率始终不变；拖动 $f$ 可以看到两个线圈的峰值一起变大、频率一起变大，**频率始终保持相等**。

## 答案汇总

电功率比 $P_1 : P_2 = n_1^2 : n_2^2 = 4:1$；峰值 $E_{1m} = n_1\omega\Phi_m$、$E_{2m} = n_2\omega\Phi_m$；两者频率都等于磁铁转动频率 $f$。

$$\boxed{\text{B}}$$
