## 一、题目条件分析

**装置与几何**

- AB 倾角 θ = 37°，题目给出 $\sin 37° = 0.6$、$\cos 37° = 0.8$，课件里一律用题给的这两个数（它们对应 36.87°，与 37° 相差不到 0.2°，图中也按题给数值绘制）。
- 圆弧轨道 BCD 的圆心 O₁ 在弧的上方，C 是最低点；B、D 等高，都比 C 高 $R(1-\cos 37°) = 0.2$ m，弧的圆心角是 $2\theta$。
- DE 长 $L = 1.25$ m、倾角 37°，所以 E 比 D 高 $L\sin 37° = 0.75$ m，即 E 比 C 高 0.95 m。
- 圆弧管道 EF 的圆心 O₂ 在管道下方，F 端切线水平，F 比 E 高 $R(1-\cos 37°) = 0.2$ m，即 F 比 C 高 1.15 m。a 从 F 出去时速度方向水平，正好滑上 b 的上表面（b 的上表面与 F 等高）。
- 高度 h 是从 A 竖直量到 C 所在的水平面。

**受力与摩擦**

- 除 DE 外所有轨道（AB、BCD、EF）都光滑。
- DE 由特殊材料制成：上行 $\mu_1 = 0.25$，下行 $\mu_2 = 0.5$，最大静摩擦力等于滑动摩擦力。因为 $\tan 37° = 0.75 > \mu_2 > \mu_1$，a 在 DE 上无论停在哪里都会滑回，不会停在 DE 上。
- a 与 b 之间的动摩擦因数恒为 $\mu_1 = 0.25$，地面光滑；b 右端的竖直挡板与 b 固定，a 与挡板完全弹性碰撞。

**建模思路**

第(1)问问的是 a 在 DE 上的往复：一次上行、一次下行算一轮，每轮回到 D 时速率都要打折扣（DE 上摩擦做负功），折扣比是定值，于是路程和时间都成了等比数列。

第(2)问 a 从 F 出去滑上 b：a、b 等质量，系统水平方向动量守恒，a、b 之间滑动摩擦使二者趋于共速；a 碰到挡板后相对速度反向，要保证 a 不滑出 b 的左端。

## 二、完整解答

### 第(1)问：h = 0.8 m

**① 第一次经过 C 点的向心加速度**

A→B→C 全程光滑，机械能守恒（这是 a 第一次冲下，还没碰到 DE）：

$$mgh = \frac12 m v_C^2 \Rightarrow v_C = \sqrt{2gh} = \sqrt{2\times 10\times 0.8} = 4\ \text{m/s}$$

C 是圆弧 BCD 的最低点，半径就是曲率半径，所以向心加速度

$$a_n = \frac{v_C^2}{R} = \frac{4^2}{1} = \boxed{16\ \text{m/s}^2}$$

**② 在 DE 上经过的总路程**

先求 a 到达 D 时的速度。A 到 D 全程光滑（AB、圆弧 BCD 都光滑），D 比 C 高 0.2 m：

$$v_D^2 = 2g(h - 0.2) = 2\times 10\times 0.6 = 12 \Rightarrow v_D = \sqrt{12}\ \text{m/s}$$

在 DE 上上行时，摩擦力沿斜面向下，加速度大小

$$a_1 = g\sin 37° + \mu_1 g\cos 37° = 10\times 0.6 + 0.25\times 10\times 0.8 = 8\ \text{m/s}^2$$

第一次上行的路程

$$s_1 = \frac{v_D^2}{2a_1} = \frac{12}{2\times 8} = 0.75\ \text{m} < L = 1.25\ \text{m}$$

所以 a 没到 E 就减速到 0；又因为 $\tan 37° > \mu_2$，它立刻沿 DE 返回。下行时摩擦力沿斜面向上：

$$a_2 = g\sin 37° - \mu_2 g\cos 37° = 10\times 0.6 - 0.5\times 10\times 0.8 = 2\ \text{m/s}^2$$

下行 0.75 m 回到 D 时

$$v_D'^2 = 2a_2 s_1 = 2\times 2\times 0.75 = 3 = \frac{v_D^2}{4}$$

回到 D 后，a 经 D→C→B 上行，沿 AB 上滑一段再折返，再经 B→C→D 回到 D。这一段（圆弧 BCD 与直轨 AB）全程光滑，机械能不变，所以 a 下一次上行时在 D 处的速率与刚才回到 D 时的速率相同，仍是 $\sqrt{3}$ m/s。于是

$$s_2 = \frac{3}{2\times 8} = \frac{0.75}{4} = 0.1875\ \text{m}$$

一般地，每往返一轮回到 D，速率的平方变成原来的 $\dfrac{a_2}{a_1} = \dfrac{2}{8} = \dfrac14$，所以每轮的上行路程是前一轮的 $\dfrac14$。每轮上行、下行路程相同，总路程

$$s_{DE} = 2(s_1 + s_2 + s_3 + \cdots) = 2\times 0.75\times \frac{1}{1 - \frac14} = 2\times 0.75\times\frac43 = \boxed{2\ \text{m}}$$

**③ 在 DE 上向上运动时间 t_上 与向下运动时间 t_下 之比**

设第 n 轮上行前在 D 处的速率是 $u_n$，则

$$t_{上,n} = \frac{u_n}{a_1},\qquad t_{下,n} = \sqrt{\frac{2s_n}{a_2}} = \sqrt{\frac{2\cdot\frac{u_n^2}{2a_1}}{a_2}} = \frac{u_n}{\sqrt{a_1a_2}}$$

两者之比与 n 无关：

$$\frac{t_{上}}{t_{下}} = \frac{u_n/a_1}{u_n/\sqrt{a_1a_2}} = \sqrt{\frac{a_2}{a_1}} = \sqrt{\frac{2}{8}} = \frac12$$

即 $t_上 : t_下 = \boxed{1 : 2}$。（每一轮都是 1 : 2，全部相加仍是 1 : 2。）

具体数值：$u_n = \sqrt{12}\cdot\left(\frac12\right)^{n-1}$ 是公比 $\frac12$ 的等比数列，$\sum u_n = 2\sqrt{12}$，所以

$$t_上 = \frac{2\sqrt{12}}{8} \approx 0.87\ \text{s},\qquad t_下 = \frac{2\sqrt{12}}{\sqrt{8\times 2}} = \frac{2\sqrt{12}}{4} \approx 1.73\ \text{s}$$

### 第(2)问：h = 1.6 m

**a 到 F 的速率**

到 D 点：$v_D^2 = 2g(1.6 - 0.2) = 28$。

DE 段要爬 1.25 m，上行摩擦因数 $\mu_1 = 0.25$，加速度大小仍是 8 m/s²：

$$v_E^2 = v_D^2 - 2a_1L = 28 - 2\times 8\times 1.25 = 8$$

EF 是光滑圆弧管道，F 比 E 高 0.2 m：

$$v_F^2 = v_E^2 - 2g\times 0.2 = 8 - 4 = 4 \Rightarrow v_F = \boxed{2\ \text{m/s}}$$

**a 在 b 上滑动**

a 滑上 b 后，a、b 之间动摩擦因数恒为 $\mu_1 = 0.25$，摩擦力 $f = \mu_1mg = 0.25\times0.5\times10 = 1.25$ N。a、b 质量相同，所以

$$a_a = 2.5\ \text{m/s}^2\ (\text{减速}),\qquad a_b = 2.5\ \text{m/s}^2\ (\text{加速})$$

相对加速度大小 $2\times2.5 = 5$ m/s²。系统水平方向动量守恒（地面光滑）：

$$mv_F = 2mv_共 \Rightarrow v_共 = \frac{v_F}{2} = 1\ \text{m/s}$$

a 相对 b 滑动的总路程若不受挡板限制是 $\dfrac{v_F^2}{2\times 5} = 0.4$ m。

**与挡板碰撞**

b 的长度记为 $l$。a 相对 b 前进 $l$ 就撞上挡板（这要求 $l < 0.4$ m）。碰撞是 a 与"b + 挡板"之间的完全弹性碰撞，两者质量相等、碰撞时间极短（摩擦力的冲量可忽略），所以**速度交换**，即 a、b 之间的相对速度反向、大小不变。

设 a 到达挡板时相对速率为 $u$，由相对运动 $u^2 = v_F^2 - 2\times5l = 4 - 10l$。碰后相对速率仍为 $u$，方向相反，a 相对 b 向左滑动，直到二者共速，这段相对位移

$$d = \frac{u^2}{2\times 5} = \frac{4 - 10l}{10}$$

a 不滑出 b 的左端，要求

$$l \ge d = \frac{4-10l}{10} \Rightarrow 20l \ge 4 \Rightarrow l \ge 0.2\ \text{m}$$

取 $l = 0.2$ m 时：$u^2 = 4 - 2 = 2$，$d = 0.2$ m $= l$，即 a 恰好回到 b 的左端时相对速度刚好减为 0，恰好不脱离。此时 $l = 0.2\ \text{m} < 0.4$ m，a 确实能碰到挡板，自洽。

所以滑块 b 至少长 $\boxed{0.2\ \text{m}}$。（若 $l \ge 0.4$ m，a 根本碰不到挡板，也会停在 b 上不脱离；$0.2\ \text{m} \le l < 0.4$ m 时靠挡板把 a 弹回来，同样不脱离；只有 $l < 0.2$ m 时 a 才会从左端滑出。）

## 四、结合图像看关键时刻

- **第(1)问的 v–t 图**：从 A 释放后速度沿斜面线性增大（$a = g\sin37° = 6$ m/s²），过 C 时达到最大 4 m/s；进入 DE 后斜率变成 −8，第一次到达最高点时 v = 0；随后沿 DE 返回，斜率 +2（较缓），回到 D 时速率只有第一次的 $\sqrt{3} \approx 1.73$ m/s。此后每次回到 D 速率都乘 $\frac12$，所以图像是幅度按 $\frac12$ 递减的锯齿波——锯齿"上坡"时间总和与"下坡"时间总和之比始终是 1 : 2，这正是 ③ 的答案。
- **第(2)问的 v–t 图**：a 在轨道上一直加速/减速到 F（2 m/s）；滑上 b 后 a 减速、b 从 0 加速，两条线互相靠拢；在 $t_{Hit}$ 处两条线**交叉**（速度交换，a 的速度变成 b 原来的速度、b 的变成 a 原来的），这是完全弹性碰撞的典型特征；交叉之后两者继续靠拢，最后在 $v = 1$ m/s 处重合（共速）。两条曲线之间的面积差就是 a 相对 b 的滑动路程：其中 a 相对 b 走过 $l$ 的时刻就是碰撞时刻，碰撞后走回的距离必须不超过 $l$，即 $l \ge 0.2$ m。

## 五、答案汇总

（1）① 第一次经过 C 点的向心加速度 $a_n = \boxed{16\ \text{m/s}^2}$（此时 $v_C = 4$ m/s）。

（1）② 在 DE 上经过的总路程 $s = \boxed{2\ \text{m}}$（每轮上行路程按 1 : 1/4 : 1/16 … 递减）。

（1）③ $t_上 : t_下 = \boxed{1 : 2}$（$t_上 \approx 0.87$ s，$t_下 \approx 1.73$ s）。

（2）a 到 F 的速率 $v_F = 2$ m/s，滑块 b 至少长 $\boxed{l \ge 0.2\ \text{m}}$。
