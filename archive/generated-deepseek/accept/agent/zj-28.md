## 题目条件分析

四个物体（球 A、球 B、配重 P、配重 Q）质量相同，$m = 50\ \text{g}$。取 $g = 10\ \text{m/s}^2$，每个物体的重力

$$mg = 0.05 \times 10\ \text{N} = 0.5\ \text{N}$$

配重 P、Q 各自竖直悬挂而平衡，跨过定滑轮的细线又不计摩擦，所以细线 c、d 的张力都等于配重的重力：

$$T_c = T_d = mg = 0.5\ \text{N}$$

细线 c、d 平行、都与水平成 $\theta = 30°$：c 从球 A 沿**右上** 30° 拉向右侧滑轮，d 从球 B 沿**左下** 30° 拉向左侧滑轮。两绳张力大小相同、拉两球的方向相反，因此它们对**两球整体**（A＋B）的竖直分量正好等大反向、彼此抵消——这是本题的关键。

小球 A、B 都处于平衡，受力为：

- A：重力 $mg$（竖直向下）、c 的拉力 $T_c$（右上 30°）、b 的拉力 $T_b$；
- B：重力 $mg$（竖直向下）、d 的拉力 $T_d$（左下 30°）、b 的拉力 $T_b$（与 A 端大小相等、方向相反）、a 的拉力 $T_a$（竖直向上）。

b 的方向不是已知量，设 b 与水平方向的夹角为 $\alpha$，由平衡条件确定。

## 完整解答

### 1. 用整体法先求 a 的拉力

把球 A、B 看成一个系统。系统受到的外力里，竖直方向只有：

- a 的拉力 $T_a$（向上）；
- 两球的总重力 $2mg$（向下）；
- c 对 A 的竖直分量 $+T_c\sin\theta$（向上）、d 对 B 的竖直分量 $-T_d\sin\theta$（向下）。

因为 $T_c = T_d = mg$、c、d 又都与水平成同一个角 $\theta$，这一上一下两个分量**恰好抵消**。于是竖直方向平衡给出

$$T_a - 2mg + T_c\sin\theta - T_d\sin\theta = 0 \;\Rightarrow\; T_a = 2mg$$

$$T_a = 2 \times 0.5\ \text{N} = \boxed{1\ \text{N}}$$

注意这个结果与 $\theta$ 无关，也与 b 的方向无关；拖动课件里的 θ 滑块可以看到 $T_a$ 始终等于 2mg。

### 2. 隔离球 A，求 b 的拉力

设 b 与水平方向成角 $\alpha$（从 A 指向 B 为右上方向）。A 受三个力，正交分解：

$$\text{水平：}\quad T_b\cos\alpha = T_c\cos\theta,\qquad
\text{竖直：}\quad T_b\sin\alpha = mg - T_c\sin\theta$$

代入 $T_c = mg = 0.5\ \text{N}$、$\theta = 30°$：

$$T_b\cos\alpha = 0.5 \times \frac{\sqrt3}{2} \approx 0.433\ \text{N},\qquad T_b\sin\alpha = 0.5 - 0.5\times 0.5 = 0.25\ \text{N}$$

两式相除：$\tan\alpha = 0.25/0.433 \approx 0.577$，所以 $\alpha = 30°$，即 b 也与水平成 30°——b、c、d 三条斜绳两两平行。再由竖直分量

$$T_b = \frac{0.25}{\sin 30°} = \boxed{0.5\ \text{N}}$$

一般地 $T_b = mg\sqrt{2 - 2\sin\theta}$，当 $\theta = 30°$ 时恰好等于 $mg = 0.5\ \text{N}$。

### 3. 用球 B 复核

b 拉 B 的方向沿 b 指向 A（右下 30°），竖直向下分量 $T_b\sin 30° = 0.25\ \text{N}$；d 拉 B 的竖直向下分量 $T_d\sin 30° = 0.25\ \text{N}$。B 竖直方向平衡：

$$T_a = mg + T_d\sin\theta + T_b\sin\alpha = 0.5 + 0.25 + 0.25 = 1\ \text{N}$$

与整体法一致。水平方向 $T_b\cos\alpha = T_d\cos\theta$（0.433 N = 0.433 N）也自动成立。

### 4. 逐项判断

- **A. 2 N，1 N —— 错误。** 前一项 2 N 相当于把两球总重力 $2mg$ 又乘了 2；把质量滑块拖到 100 g，得到的是 (2 N, 1 N)，但那不是题目给的 50 g。两项是一组"整体质量翻倍"的结果。
- **B. 2 N，0.5 N —— 错误。** 后一项 $T_b = 0.5\ \text{N}$ 正确，但 $T_a = 2mg = 1\ \text{N}$，不是 2 N。
- **C. 1 N，1 N —— 错误。** 前一项正确；后一项 $T_b = mg\sqrt{2-2\sin\theta}\le \sqrt2\,mg \approx 0.71\ \text{N}$，在 $m = 50\ \text{g}$ 时无论怎样调滑轮高度都到不了 1 N。
- **D. 1 N，0.5 N —— 正确。** $T_a = 2mg = 1\ \text{N}$，$T_b = mg = 0.5\ \text{N}$。

### 5. 交互演示怎么看

- 装置图里两条斜绳严格按 $\theta$ 画出，左、右滑轮高度不同，正好让 c、d 平行；a 始终竖直，b 的倾角由平衡条件决定（图上随 θ 变化，可验证 $\alpha = 45° - \theta/2$）。
- 两张受力图分别给出球 A（三力）和球 B（四力）的矢量图，未知的 $T_a$、$T_b$ 由组件按 $\Sigma F = 0$ 解出，与正文结果一致。
- 拖动 θ：$T_a$ 始终是 1 N（50 g 时），$T_b$ 随 θ 减小而增大；把 θ 调到 10°，$T_b$ 也只有 0.64 N —— 直接排除选项 C。
- 拖动质量 m：$T_a$、$T_b$ 都按比例变化；拖到 100 g 得到 (2 N, 1 N)，说明选项 A 是把质量取错了。

**答案：D（1 N，0.5 N）**
