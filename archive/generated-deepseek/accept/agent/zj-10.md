## 一、题目条件分析

**结构**：底座 O 固定。OA、OD 是从 O 向左右伸出的两根弹性悬梁（相当于两根悬臂梁）；金属杆 ab 固定在悬梁端点 A、金属杆 cd 固定在悬梁端点 D，两根杆都与悬梁垂直、水平放置，彼此平行，长度都是 $l$，电流大小都是 $I_0$、方向相反。

**受力**：磁场 $B$ 水平向右，与悬梁平行，因此垂直于两根金属杆。由安培力 $F = BIl$，两根杆各自受到的安培力大小都是

$$F = B I_0 l$$

方向垂直于杆与 $B$ 所决定的平面，即**都在竖直方向**（一上一下）。竖直力作用在悬梁的端点，使悬梁弯曲。

**传感**：应变片贴在悬梁表面，随表面一起被拉伸或压缩——被拉伸时阻值增大，被压缩时阻值减小。

**电桥**：四个应变片接成电桥（图 2）。上臂 $R_1$（左）、$R_2$（右）的中点记作 f；下臂 $R_3$（左）、$R_4$（右）的中点记作 e；电源 $E$ 和开关 S 串接在电桥的左、右两端之间（不计内阻）。输出 $U_{ef} = \varphi_e - \varphi_f$。未加磁场时四片阻值都是 $R_0$，电桥平衡，$U_{ef} = 0$。

题目只给出字母，没有给出数值。为便于交互演示，正文取一组**代表值**：$R_0 = 100\ \Omega$、$E = 10\ \text{V}$、$I_0 = 2\ \text{A}$、$l = 0.25\ \text{m}$、$\alpha = 8\ \Omega/\text{N}$、$B = 0.5\ \text{T}$（换算出的 $\Delta R/R_0$ 比真实应变片大，只为看清读数）。下面所有公式对任意取值都成立。

## 二、第（1）问：两杆所受安培力的方向

判断安培力方向用**左手定则**（也可用 $F = I L \times B$，结果相同）：让磁场 $B$（水平向右）穿入掌心，四指指向杆中的电流方向，拇指所指就是安培力方向。由于 $B$ 与杆垂直，安培力垂直于"杆与 $B$ 所决定的平面"，即沿竖直方向。

- **ab 杆**：电流由 a 指向 b（由近处指向远处），可得 ab 所受安培力**竖直向下**；
- **cd 杆**：电流由 c 指向 d，与 ab 中电流方向相反，处在相同的磁场中，所以所受安培力**竖直向上**。

两力大小相等，都是 $F = BI_0 l$，方向一上一下。

## 三、第（2）问：四个应变片的阻值

安培力使悬梁弯曲，贴在表面的应变片随之被拉伸或压缩：

- **悬梁 OA**：端点 A 受到**向下**的力，OA 向下弯曲。梁弯曲时，靠外的一侧（**上表面**）被拉伸、靠里的一侧（**下表面**）被压缩，所以 $R_1$ 增大、$R_3$ 减小。
- **悬梁 OD**：端点 D 受到**向上**的力，OD 向上弯曲。这时上表面被压缩、下表面被拉伸，所以 $R_2$ 减小、$R_4$ 增大。

两根杆所受安培力大小相等（都是 $BI_0l$），两根悬梁的形变程度相同，所以四个阻值变化量的绝对值都是 $\Delta R$：

$$R_1 = R_0 + \Delta R,\quad R_2 = R_0 - \Delta R,\quad R_3 = R_0 - \Delta R,\quad R_4 = R_0 + \Delta R$$

即 $R_1 = R_4 = R_0 + \Delta R$，$R_2 = R_3 = R_0 - \Delta R$：**处在对角位置的两片阻值变化相同**。（若两片"同侧"的阻值同增同减，电桥反而仍然平衡，$U_{ef}$ 恒为 0，那就测不出磁场了——这也说明上面这个符号关系是对的。）

代入代表值（$\Delta R = \alpha B I_0 l = 8 \times 0.5 \times 2 \times 0.25 = 2\ \Omega$）：$R_1 = R_4 = 102\ \Omega$，$R_2 = R_3 = 98\ \Omega$。

## 四、第（3）问：B 与 U_ef 的关系

设电源使电桥左端电势比右端高 $E$（不计内阻）。

**上臂** $R_1$、$R_2$ 串联，从中点 f 看分压（以右端为电势零点）：

$$\varphi_f = E\frac{R_2}{R_1 + R_2}$$

**下臂** $R_3$、$R_4$ 串联，从中点 e 看：

$$\varphi_e = E\frac{R_4}{R_3 + R_4}$$

所以

$$U_{ef} = \varphi_e - \varphi_f = E\left[\frac{R_4}{R_3+R_4} - \frac{R_2}{R_1+R_2}\right]$$

把 $R_1 = R_0+\Delta R$、$R_2 = R_0-\Delta R$、$R_3 = R_0-\Delta R$、$R_4 = R_0+\Delta R$ 代入，注意 $R_1+R_2 = R_3+R_4 = 2R_0$：

$$U_{ef} = E\left[\frac{R_0+\Delta R}{2R_0} - \frac{R_0-\Delta R}{2R_0}\right] = E\frac{\Delta R}{R_0}$$

于是

$$\Delta R = \frac{R_0 U_{ef}}{E}$$

又 $\Delta R = \alpha F$，而每根杆受到的安培力 $F = B I_0 l$，所以 $\Delta R = \alpha B I_0 l$。两式联立：

$$\boxed{\,B = \frac{R_0 U_{ef}}{\alpha I_0 l\, E}\,}$$

（单位核对：$\dfrac{\Omega \cdot \text{V}}{\Omega/\text{N} \cdot \text{A} \cdot \text{m} \cdot \text{V}} = \dfrac{\text{N}}{\text{A}\cdot\text{m}} = \text{T}$。）

**两点说明**

1. 四个桥臂同时变化（$R_1$、$R_4$ 增大，$R_2$、$R_3$ 减小），输出是单臂变化时的 4 倍：只有一个桥臂变化时 $U_{ef} = \dfrac{E\Delta R}{4R_0}$，现在 $U_{ef} = \dfrac{E\Delta R}{R_0}$。这种接法既提高了灵敏度，也消除了温度等共模影响。
2. 代入代表值核对：$\Delta R = 8\times0.5\times2\times0.25 = 2\ \Omega$，$U_{ef} = \dfrac{10\times2}{100} = 0.2\ \text{V}$，反推 $B = \dfrac{100\times0.2}{8\times2\times0.25\times10} = 0.5\ \text{T}$，与设定的磁场一致。

## 五、结合图像理解

拖动侧栏的**磁感应强度 B** 滑块（或点「未加磁场」「题目条件」按钮）：

- 左图：$B = 0$ 时两根悬梁水平、四个应变片阻值相等；$B$ 增大时 ab 受向下的安培力、cd 受向上的安培力，两根悬梁朝相反方向弯曲，$R_1$、$R_4$ 增大而 $R_2$、$R_3$ 减小，弯曲程度与 $B$ 成正比。
- 电桥：四个桥臂阻值随 $B$ 实时改变，电压表（由电路求解得到）的读数与 $U_{ef} = E\Delta R/R_0$ 完全一致。
- 下图：$U_{ef}$ 随 $B$ 变化的图像是一条**过原点的直线**，斜率 $k = \dfrac{E\alpha I_0 l}{R_0}$。这正是这种磁场检测芯片的价值：输出与待测磁感应强度成正比，只要测得 $U_{ef}$ 就能由 $B = \dfrac{R_0 U_{ef}}{\alpha I_0 l E}$ 直接算出 $B$（实际使用时 $\alpha$、$I_0$、$l$、$E$、$R_0$ 都由器件和电路参数标定）。

## 六、答案汇总

**（1）** ab 所受安培力竖直**向下**，cd 所受安培力竖直**向上**；两力大小相等，都是 $F = BI_0 l$。

**（2）** $R_1 = R_4 = R_0 + \Delta R$，$R_2 = R_3 = R_0 - \Delta R$。

**（3）** $U_{ef} = \dfrac{E\Delta R}{R_0}$，故

$$B = \frac{R_0 U_{ef}}{\alpha I_0 l\, E}$$
