## 题目条件分析

四个物体质量相同，都是 $m = 50\ \text{g}$，所以每个的重力都等于

$$mg = 0.05 \times 10 = 0.5\ \text{N}\quad(\text{取 } g = 10\ \text{m/s}^2)$$

- 配重 P、Q 各自静止，滑轮无摩擦，同一根绳上张力处处相等，所以细线 c、d 上的张力分别等于配重的重力：$T_c = T_d = mg = 0.5\ \text{N}$。
- 细线 a 从支架横梁竖直悬挂球 B，细线 b 连接 A、B 两球。
- 整套装置静止，每个球都处于平衡状态；细线 d 与水平成 $30^\circ$ 向左下方拉 B，细线 c 与水平成 $30^\circ$ 向右上方拉 A。

## 完整解答

### 一、细线 c、d 的张力

配重 P、Q 都静止，绳两端张力相等：

$$T_c = T_d = mg = 0.5\ \text{N}$$

### 二、整体法求细线 a 的拉力

把 A、B 两球看成一个系统。细线 c 对 A 的拉力沿 c 向右上方、与水平成 $30^\circ$；细线 d 对 B 的拉力沿 d 向左下方、与水平成 $30^\circ$。这两个力大小相等、方向相反，在整个系统的外力中恰好互相抵消。

系统竖直方向只受细线 a 的拉力 $T_a$（向上）和总重力 $2mg$（向下），平衡条件给出

$$T_a = 2mg = 2 \times 0.5\ \text{N} = \boxed{1\ \text{N}}$$

### 三、隔离球 A 求细线 b 的拉力

球 A 受三个力：重力 $mg$ 竖直向下；细线 c 的拉力 $T_c = 0.5\ \text{N}$，方向与水平成 $30^\circ$ 向右上方；细线 b 的拉力 $T_b$。

重力与 $T_c$ 的合力，水平方向

$$T_c\cos 30^\circ = 0.5 \times \frac{\sqrt{3}}{2} \approx 0.433\ \text{N}\ (\text{向右})$$

竖直方向

$$T_c\sin 30^\circ - mg = 0.25 - 0.5 = -0.25\ \text{N}\ (\text{向下})$$

这两者的合力大小为

$$\sqrt{0.433^2 + 0.25^2} = 0.5\ \text{N}$$

方向与水平成 $30^\circ$ 向右下方。A 要平衡，$T_b$ 必须与它等大反向，因此

$$T_b = \boxed{0.5\ \text{N}}$$

方向与水平成 $30^\circ$ 向左上方。这也说明细线 b 与水平方向的夹角恰好是 $30^\circ$。

### 四、隔离球 B 校验

球 B 受四个力：重力 $mg = 0.5\ \text{N}$ 向下；$T_d = 0.5\ \text{N}$，与水平成 $30^\circ$ 向左下方；$T_b = 0.5\ \text{N}$，与水平成 $30^\circ$ 向右下方；$T_a$ 竖直向上。

竖直方向平衡：

$$T_a = mg + T_d\sin 30^\circ + T_b\sin 30^\circ = 0.5 + 0.25 + 0.25 = 1\ \text{N}$$

与整体法结果一致。

### 五、逐项判断

- **A. 2 N，1 N**：错误。$T_a$ 应为 $1\ \text{N}$，$T_b$ 应为 $0.5\ \text{N}$，两项都不对。
- **B. 2 N，0.5 N**：错误。$T_b$ 对，但 $T_a = 1\ \text{N} \neq 2\ \text{N}$。
- **C. 1 N，1 N**：错误。$T_a$ 对，但 $T_b = 0.5\ \text{N} \neq 1\ \text{N}$。
- **D. 1 N，0.5 N**：正确，两项都符合上面算出的结果。

答案是 **D**。

## 结合图像理解关键时刻

- **θ = 30°（题目条件）**：$T_b = 0.5\ \text{N}$，$T_a = 1\ \text{N}$，正是选项 D。此时细线 b 与水平方向也恰好成 $30^\circ$，三根斜线的倾角相同。
- **θ 变小时**：$T_b$ 变大（重力 $mg$ 与 $T_c$ 的合力方向更陡，需要更大的 $T_b$ 才能拉住 A），但 $T_a$ 始终是 $1\ \text{N}$。
- 球 A 的三个力（$mg$、$T_c$、$T_b$）和球 B 的四个力（$mg$、$T_d$、$T_b$、$T_a$）在每一时刻都各自闭合，这正是“调节滑轮高度达到平衡”的含义。

## 答案汇总

细线 a 的拉力为 $1\ \text{N}$，细线 b 的拉力为 $0.5\ \text{N}$，**选 D**。
