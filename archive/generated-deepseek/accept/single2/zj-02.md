## 题目条件分析

剪断前吊篮静止，A、B、C 三球在水中处于平衡。

- A 为铁球，$\rho_{\text{铁}}>\rho_{\text{水}}$，重力大于浮力，弹簧被压缩，弹簧对 A 的弹力向上。
- B 为木球，$\rho_{\text{木}}<\rho_{\text{水}}$，浮力大于重力，弹簧被拉长，弹簧对 B 的弹力向下。
- C 为木球，浮力大于重力，细线绷直，细线对 C 的拉力向下。

剪断吊篮绳的瞬间，吊篮、水杯和水一起自由下落，水处于完全失重状态，水压瞬间消失，浮力瞬间消失。弹簧形变来不及改变，弹簧弹力仍保持原来的大小和方向；细线不能推，C 所需的向下拉力可以突变为零，细线松弛。

为便于画出示意，图中取代表值 $\rho_{\text{木}}:\rho_{\text{水}}:\rho_{\text{铁}}=0.5:1:7.8$，仅表示相对大小，不影响方向判断。

## 完整解答

取剪断后的水杯为参考系。剪断后水杯自由下落，水也自由下落，水对球的浮力为零；在随水杯自由下落的参考系中，重力的效果被惯性力抵消，球只受弹簧弹力或细线拉力的作用。

### A 球

A 为铁球，原来平衡时

$$G_A=F_{\text{浮}A}+F_{\text{弹}A}$$

其中 $F_{\text{弹}A}$ 向上。剪断后浮力消失，弹簧仍被压缩，弹力仍向上。因此 A 在随杯自由下落的参考系中受到向上的弹力，相对于杯底向上运动。

$$\boxed{A\text{ 球向上运动}}$$

### B 球

B 为木球，原来平衡时

$$F_{\text{浮}B}=G_B+F_{\text{弹}B}$$

其中弹簧被拉长，$F_{\text{弹}B}$ 向下。剪断后浮力消失，弹簧仍被拉长，弹力仍向下。因此 B 受到向下的弹力，相对于杯底向下运动。

$$\boxed{B\text{ 球向下运动}}$$

### C 球

C 为木球，原来由细线拉住，细线对 C 的拉力向下：

$$F_{\text{浮}C}=G_C+T$$

剪断后浮力消失，细线不能推球，张力立刻变为零，C 球只受重力。C 球与水杯都自由下落，加速度同为 $g$，所以 C 相对于杯底静止。

$$\boxed{C\text{ 球相对杯底不动}}$$

### 逐项判断

- A 项：错误。剪断后 A 球向上，B 球向下，C 球相对杯底不动，不是 B、C 都向下。
- B 项：错误。A 球向上，但 B 球向下，不是向上。
- C 项：错误。A 球向上，B 球向下，与选项方向相反。
- D 项：正确。A 球向上运动，B 球向下运动，C 球不动。

$$\boxed{\text{答案：D}}$$

## 结合图像理解关键时刻

- 剪断前：A 的弹簧被压缩，弹力向上；B 的弹簧被拉长，弹力向下；C 的细线被拉紧，拉力向下。
- 剪断瞬间：水杯和水开始自由下落，浮力消失。A 仍受向上弹力，所以相对杯底向上；B 仍受向下弹力，所以相对杯底向下；C 的细线不能推，张力变为零，C 与水杯一起自由下落，相对杯底静止。
- 关键区别在“浮力消失，而弹簧形变来不及改变，弹力仍在；细线只能拉不能推，张力可以立即消失”。
