## 题目条件分析

**活塞的受力**：A 内的活塞轻质、无摩擦，上方除大气压 $p_0$ 外只压着铁砂。设活塞横截面积为 $S$、铁砂质量为 $m$，活塞平衡时

$$p_A S = p_0 S + mg \quad\Longrightarrow\quad p_A = p_0 + \frac{mg}{S}$$

- $m = 0$ 时 $p_A = p_0$，与温度无关，所以降温过程中 A 内气体是**等压**过程，活塞随气体收缩而下降。
- 倒入铁砂后 $p_A$ 随 $m$ 线性增大，压差 $\Delta = p_A - p_B$ 才有可能超过开启门限。

**B 内气体**：气缸 B 上端封闭、体积 $V_B$ 不变，只要阀门不打开就是**等容**过程（气体量不变时 $p_B \propto T$）。

**差压阀**：记压差 $\Delta = p_A - p_B$，$\Delta p = 0.11p_0 = 1.1\times10^4\ \mathrm{Pa}$。$\Delta > \Delta p$ 时阀打开，气体由 A 缓慢流入 B；$\Delta \le \Delta p$ 时阀关闭。A、B 导热良好，气体温度始终等于环境温度 $T$。

## 完整解答

### （1）B 内气体压强 $p_{B2}$

先判断阀门是否打开。不加铁砂时 $p_A = p_0$；若 B 内气体量不变、等容降温，则 $p_B \propto T$，$T_2 = 270\ \mathrm{K}$ 时 $p_B = 0.9p_0$，此时

$$\Delta = p_A - p_B = 0.1p_0 = 1.0\times10^4\ \mathrm{Pa} < \Delta p = 1.1\times10^4\ \mathrm{Pa}$$

降温过程中 $\Delta$ 由 0 单调增大到 $0.1p_0$，始终小于 $\Delta p$，所以**阀门始终关闭**，B 内气体量不变，等容降温的假设自洽。由查理定律

$$\frac{p_{B1}}{T_1} = \frac{p_{B2}}{T_2}\quad\Longrightarrow\quad p_{B2} = p_{B1}\frac{T_2}{T_1} = p_0\times\frac{270}{300} = 0.9p_0 = \boxed{9.0\times10^4\ \mathrm{Pa}}$$

### （2）A 内气体体积 $V_{A2}$

轻活塞、无铁砂，$p_A = p_0$ 保持不变，A 内气体等压降温，由盖–吕萨克定律

$$\frac{V_{A1}}{T_1} = \frac{V_{A2}}{T_2}\quad\Longrightarrow\quad V_{A2} = V_{A1}\frac{T_2}{T_1} = 4.0\times10^2 \times 0.9 = \boxed{3.6\times10^2\ \mathrm{m^3}}$$

### （3）倒入铁砂的质量 $m$

缓慢加砂，$p_A = p_0 + \dfrac{mg}{S}$ 逐渐增大，过程分两段：

1. **阀关闭段**：$p_A$ 从 $p_0$ 增大到 $0.9p_0 + \Delta p = 1.01p_0$，即 $m$ 从 0 增大到 $\dfrac{(1.01-1)p_0S}{g} = 10\ \mathrm{kg}$ 之前，压差还没到 $\Delta p$，阀关闭，B 内气体量不变，$p_B$ 保持 $0.9p_0$。
2. **阀打开段**：$m > 10\ \mathrm{kg}$ 后阀打开，气体缓慢由 A 流入 B。气体能持续流动，说明阀两侧压差恰好维持在门限上：

$$p_A - p_B = \Delta p \quad\Longrightarrow\quad p_B = p_A - \Delta p = p_0 + \frac{mg}{S} - \Delta p$$

$p_B$ 随 $m$ 线性增大（同时 A 内气体量减少，活塞继续下降）。

3. 要求 $p_B$ 回到 $p_0$：

$$p_0 + \frac{mg}{S} - \Delta p = p_0 \quad\Longrightarrow\quad \frac{mg}{S} = \Delta p = 0.11p_0$$

$$m = \frac{0.11p_0S}{g} = \frac{0.11\times1.0\times10^5\times0.10}{10}\ \mathrm{kg} = \boxed{110\ \mathrm{kg}}$$

此时 $p_A = 1.11p_0$，压差恰为 $\Delta p$，阀随之关闭，$p_B$ 保持在 $p_0$。若再加砂，$p_B$ 会超过 $p_0$，与"回到 $p_0$ 并保持不变"不符；若少加砂，$p_B$ 还到不了 $p_0$。所以倒入的铁砂恰好 110 kg。

## 结合图像理解关键时刻

**第一张图（降温）**：B 内气体等容降温，$p_B = p_0T/T_1$ 是过原点的直线，$T$ 从 300 K 降到 270 K 时 $p_B$ 从 $p_0$ 降到 $0.9p_0$；A 内 $p_A = p_0$ 是水平线（活塞受力平衡）。两线之间的竖直距离就是压差 $\Delta$，最大只有 $0.10p_0 < \Delta p = 0.11p_0$——阀门全程关闭，B 内气体量不变，等容规律才成立。

**第二张图（倒铁砂）**：虚线是阀打开后 $p_B$ 必须走的那条线 $p_A - \Delta p$。

- $m < m_开$（当前温度下是 10 kg）：$p_B$ 还停在 $0.9p_0$ 的水平段，压差没到 $\Delta p$，阀关着；
- $m > m_开$：$p_B$ 开始沿虚线上升，与 $p_A$ 之间夹着宽度恒为 $\Delta p$ 的一条带——这正是"阀打开后压差维持在门限上"的图像；
- 当 $p_B$ 升到 $p_0$（对应 $p_A = 1.11p_0$）时，横坐标就是答案 $m = 110$ kg。可以看到：先倒 10 kg 把阀"顶开"，再倒 100 kg 才把 $p_B$ 从 $0.9p_0$ 抬回 $p_0$。

## 答案汇总

（1）$p_{B2} = 0.9p_0 = 9.0\times10^4\ \mathrm{Pa}$；（2）$V_{A2} = 3.6\times10^2\ \mathrm{m^3}$；（3）$m = 110\ \mathrm{kg}$。
