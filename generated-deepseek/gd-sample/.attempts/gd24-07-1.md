## 题目条件分析

木块在释放点 O 由静止释放，下落 H 后压上竖直弹簧。取 O 为原点、**竖直向下为正**，则弹力只在 $y \ge H$（弹簧被压缩）时出现，方向向上：

- $0 \le y \le H$：只受重力，合外力 $F = mg$，恒定不变；
- $y \ge H$：$F = mg - k(y-H)$，是一条斜率为 $-k$ 的直线。

注意 $F$ 只由位置 $y$ 决定，与运动方向无关，所以木块上升时必然沿着同一条 $F–y$ 曲线返回。"第一次回到原点"指木块回到 O 点，此时速度恰好为零（弹簧恢复原长、重力势能回到原值，动能与释放时一样为 0）。整个过程分三段：① $0\to H$ 自由下落；② $H \to$ 最低点 $\to H$ 压缩弹簧（是简谐运动的一段）；③ $H \to 0$ 竖直上抛。

题目只给字母，课件取一组代表值：$m = 1.0\ \mathrm{kg}$、$g = 10\ \mathrm{m/s^2}$、$k = 100\ \mathrm{N/m}$、$H = 0.40\ \mathrm{m}$（另取弹簧原长 0.5 m，只用于作图，不影响任何结论）。这些数值只改变具体数字，不改变图线的形状和判断。

## 完整解答

### 一、F–y 图线（判 A、B）

**0 → H：只有重力**，$F = mg$，与 $y$ 无关，所以图线是一段水平线段。

**y ≥ H：弹力开始出现**，$F = mg - k(y-H)$，随 $y$ 线性减小，斜率 $-k$。三个特征位置：

- $y = H$ 处 $F = mg \ne 0$ ⇒ **折点恰好在 $y = H$**（弹力在这一刻为零，合力不突变）；
- $F = 0$ 处 $y = H + \dfrac{mg}{k} = 0.40 + 0.10 = 0.50\ \mathrm{m} > H$ ⇒ **零点在 $H$ 的右侧**；
- 最低点 $F = mg - k(y_{max} - H) = -30\ \mathrm{N} < 0$ ⇒ 斜线要**伸进负半轴**。

木块返回时 $F$ 由 $y$ 唯一决定，图线沿原路回到起点。所以正确的 F–y 图线是：一段水平线（到 $y = H$）+ 一段向右下倾的直线（过零点在 $H$ 右侧、伸入负半轴）。

- **A 错**：折点画在 $H$ 左侧（应在 $y = H$），且过零点画在 $y = H$（实际上 $y = H$ 处 $F = mg \ne 0$）。
- **B 对**：折点在 $y = H$，过零点在 $H$ 的右侧并伸到负半轴。

### 二、几个关键量

接触弹簧时 $v_C = \sqrt{2gH} = 2.83\ \mathrm{m/s}$；平衡位置（$F = 0$）$y_{eq} = H + \dfrac{mg}{k} = 0.50\ \mathrm{m}$；振幅

$$A = \sqrt{\left(\frac{mg}{k}\right)^2 + \frac{m v_C^2}{k}} = \sqrt{0.10^2 + 2\times0.40\times0.10} = 0.30\ \mathrm{m}$$

最低点 $y_{max} = y_{eq} + A = \boxed{0.80\ \mathrm{m}}$，此处 $F_{min} = -kA = \boxed{-30\ \mathrm{N}}$（弹力 40 N 大于重力 10 N）。自由下落时间 $t_1 = \sqrt{2H/g} = 0.283\ \mathrm{s}$，回到原点共约 $0.95\ \mathrm{s}$，最低点约在 $0.47\ \mathrm{s}$。

### 三、y–t 图线（判 C、D）

- **0 → H**：自由下落 $y = \frac12gt^2$，是抛物线，斜率（速度）从 0 逐渐增大到 2.83 m/s。
- **接触弹簧后**：$F = mg - k(y-H) = -k(y - y_{eq})$，木块做简谐运动的一段。因为刚接触时弹力为零，加速度恰好还是 $g$（与自由落体段连续），所以曲线在 $y = H$ 处**光滑连接**、斜率还要继续增大一段；越过平衡位置 $y_{eq}$ 后弹力大于重力，速度开始减小，到最低点 $v = 0$、切线水平——是**圆滑的极值点**，不是尖角。
- **回到 $y = H$ 之后**：弹力又为零，木块与弹簧分离，做竖直上抛，$y$ 从 $H$ 减到 0，历时 $v_C/g = 0.283\ \mathrm{s}$，与下落段相同。

全程没有机械能损失，所以整条 y–t 曲线**关于最低点完全对称**，且回到 $y = 0$ 时速度恰为零，**曲线与 t 轴相切**（紧接着木块还要再落下去，所以这只是一次相切，不是穿过）。

- **D 错**：画成折线、顶点是尖角，与"抛物线—简谐曲线—抛物线"的光滑连接不符。
- **C 错**：C 图的曲线没有满足上面的特征——它回到横轴时斜率不为零（速度不为零），两侧也不是关于最低点的对称曲线，与实际图线不符。

### 四、答案汇总

只有 F–y 图线的画法 B 与受力规律一致，故本题选 **B**。

**关键对比**：合外力在 $y = H$ 处**折而不变号**（仍是 $mg$），要再往里压缩 $mg/k$ 才减到零，所以"折点"和"零点"绝不可能重合——这正是排除 A 的关键。
