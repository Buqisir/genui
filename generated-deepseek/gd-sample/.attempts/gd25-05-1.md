题目条件分析：这是一道“测量仪器读数 + 验证性实验 + 数据处理”的组合题。

**(1) 螺旋测微器** 的读数 = 固定刻度（整毫米 + 半毫米）+ 可动刻度（每格 0.01 mm）。题图中 8 mm 刻线已露出、8.5 mm 刻线未露出，说明固定刻度是 8 mm；可动刻度与第 26 格对齐。

**(2) 小车碰撞实验**

- 轨道由坡度较小的**轨道甲**和倾角较大的**轨道乙**平滑拼接，整体左低右高。调节连接处下方的螺母升高接缝后，小车在甲上运动时重力沿甲向下的分力与摩擦力及其他阻力平衡，甲上可以做**匀速直线运动**。
- 光电门 A 在右（靠接缝），光电门 B 在左；小车 1 静置在 A、B 之间。小车 2 从乙上的 M 点由静止下滑，先经 A，再与小车 1 碰撞，碰后两车都向左运动，依次通过 B。
- 遮光条宽度 $d=1.00\ \mathrm{cm}$，遮光时间 $t$ 内小车的位移等于 $d$，故 $v=d/t$；$d$ 很小时这也就是通过光电门的**瞬时速度**。
- 两车质量相同（吸能材料的质量不计），这是等质量碰撞。

## 完整解答

### (1) 螺旋测微器的读数

$$\text{读数} = 8\ \mathrm{mm} + 26.0\times 0.01\ \mathrm{mm} = 8.260\ \mathrm{mm}$$

即 $\boxed{8.26\ \mathrm{mm}}$（固定刻度 8 mm，可动刻度第 26 格对齐，估读到 0.001 mm）。

### (2)② 平衡摩擦力及其他阻力的判据

小车在轨道乙上释放后沿斜面下滑，进入轨道甲后若做匀速直线运动，则它通过光电门 A 和 B 的遮光时间相等。所以填：**小车通过光电门 A 和 B 的时间（遮光时间）相等**（两光电门处的速度相同）。

### (2)③ 弹性碰撞的判据

设小车 2 碰前速度为 $v_0$，两车质量相同，弹性碰撞同时满足动量守恒和动能守恒：

$$mv_0 = mv_1 + mv_2,\qquad \frac12mv_0^2 = \frac12mv_1^2 + \frac12mv_2^2$$

解得 $v_1 = v_0$、$v_2 = 0$，即两车**交换速度**：小车 1 获得小车 2 碰前的速度，小车 2 停下来。两车遮光条宽度相同，所以碰后小车 1 通过 B 的遮光时间 $t_1$ 应等于碰前小车 2 通过 A 的遮光时间 $t_2$，即 $\boxed{t_1 = t_2}$。

### (2)④ 碰后两车总动能与碰前小车 2 动能之比

$d = 1.00\ \mathrm{cm} = 1.00\times10^{-2}\ \mathrm{m}$，由 $v = d/t$ 得

$$v_2 = \frac{d}{t_2} = \frac{1.00\times10^{-2}}{10.00\times10^{-3}} = 1.00\ \mathrm{m/s}$$

$$v_1 = \frac{d}{t_1} = \frac{1.00\times10^{-2}}{15.00\times10^{-3}} = 0.667\ \mathrm{m/s},\qquad v_2' = \frac{d}{t_2'} = \frac{1.00\times10^{-2}}{30.00\times10^{-3}} = 0.333\ \mathrm{m/s}$$

碰后小车 1 的速度大于小车 2，两车分离，所以能“依次”通过光电门 B。检验动量守恒：

$$mv_2 = 1.00\,m,\qquad mv_1 + mv_2' = (0.667+0.333)m = 1.00\,m$$

动量守恒成立。因为 $E_k = \frac12mv^2 = \frac12m\dfrac{d^2}{t^2}$，动能与 $t^2$ 成反比，所以

$$\frac{E_{k\text{后}}}{E_{k\text{前}}} = \frac{v_1^2 + v_2'^2}{v_2^2} = \left(\frac{t_2}{t_1}\right)^2 + \left(\frac{t_2}{t_2'}\right)^2 = \left(\frac{10.00}{15.00}\right)^2 + \left(\frac{10.00}{30.00}\right)^2 = 0.444 + 0.111 = 0.556 \approx \boxed{0.56}$$

即吸能材料吸收了约 44% 的动能（剩下 56% 仍为两车的动能）。

  at(t, p) {
    const xM = 3.3, xJ = 2.4, xCol = 2.05, x10 = 1.65, xPark = 0.42

    let x1 = x10, x2, u1 = 0, u2 = 0
    if (t <= p.tJ) {
      x2 = xM - 0.5 * a2 * t * t
      u2 = a2 * t
    } else if (t <= p.tCol) {
      x2 = xJ - p.v0 * (t - p.tJ)
      u2 = p.v0

## 结合图像理解关键时刻

| 时刻 | 状态 | 说明 |
|---|---|---|
| $t=0$ | 小车 2 在 M 由静止释放 | 在轨道乙上加速下滑，重力沿乙的分力大于阻力 |
| 进入轨道甲后 | 小车 2 匀速 | 甲上分力与阻力平衡，遮光条通过 A 的遮光时间 $t_2 = 10.00\ \mathrm{ms}$ |
| 碰撞瞬间 | 动量守恒 | $mv_2 = mv_1 + mv_2'$，吸能材料使碰撞不再弹性，动能减少 |
| 碰后 | 两车分离 | $v_1 = 0.667\ \mathrm{m/s} > v_2' = 0.333\ \mathrm{m/s}$，所以小车 1 先、小车 2 后通过 B |

曲线 $E_{k\text{后}}/E_{k\text{前}} \sim t_1$ 上三个关键点最值得看：

- $t_1 = t_2 = 10.00\ \mathrm{ms}$：弹性碰撞，两车交换速度，$v_2'=0$，比值 $\boxed{1.00}$——动能全部转移给小车 1，一点没损失。
- $t_1 = 15.00\ \mathrm{ms}$：本题数据，比值 $\boxed{0.56}$，约 44% 的动能被吸能材料吸收。
- $t_1 = 20.00\ \mathrm{ms}$：$v_1 = v_2' = 0.50\ \mathrm{m/s}$，两车碰后同速不再分开，这是完全非弹性碰撞，比值 $\boxed{0.50}$——等质量情况下动能损失的最大值。
