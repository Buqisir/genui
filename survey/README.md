## 二、这一轮做的组件

全部已实现，用法写在 `syntax-spec.md`，演示课件是 `lessons/_demo-gaokao.md`。

| 名称 | 形态 | 解决的题 |
|---|---|---|
| `v.efield` | Sim/Figure helper | 点电荷组（含异号、不等量）的电场线和等势线，数值追踪 |
| `v.field({shape})` | 扩展现有 helper | 圆形、环形、多边形磁场区域 |
| `v.track` | Sim/Figure helper | 实体轨道：直线段 + 圆弧，带外侧剖面线 |
| `v.photogate` | Sim/Figure helper | 光电门 + 遮光条计时数显 |
| `v.wire` | Sim/Figure helper | 垂直纸面的直导线（⊙/⊗）+ 同心磁感线 |
| `v.transformer` | Sim/Figure helper | 铁芯 + 原副线圈，匝数决定圈数 |
| `<Instrument>` | 预制组件 | 游标卡尺、螺旋测微器、电表（多量程、欧姆档）、电阻箱，读数随参数变化 |
| `<TickerTape>` | 预制组件 | 纸带：计数点按表达式排布，刻度尺、间距标注、相邻差 Δx |
| `ForceDiagram` 结点 | 扩展 | `body.shape: "knot"`：三绳共点，绳子画成实线 |
| `Circuit` 新元件 | 扩展 | `thermistor`、`photoresistor`、`motor` |

## 三、第二轮补做的组件

上一轮留下的四项都已完成，演示同样在 `lessons/_demo-gaokao.md`（三续、三再续、七、八、九节）。

| 名称 | 形态 | 解决的题 |
|---|---|---|
| `v.photogate({time})` + `v.block({flag})` | 扩展 helper | 数字计时器显示遮光时间（未挡光时显示「- - - -」），滑块上的遮光条 |
| `v.field({sector, border})` | 扩展 helper | 扇形、扇环磁场区域；可关掉边界线 |
| `v.cyclotron` | Sim/Figure helper | 回旋加速器俯视图：D 形盒 + 磁场、交流电源、缝中电场方向，轨迹第 k 个半圈半径 r₁√k，返回 `at(h)`、`upTo(h)` |
| `ForceDiagram` `triangle` | 扩展 | 力的矢量三角形，严格按比例首尾相接；闭合时注明合力为零，不闭合时画虚线合力。拖滑块就是动态平衡 |
| `<EnergyLevels>` | 预制组件 | 能级图（默认氢原子）、辐射/吸收/电离箭头、`allFrom` 自动列出 C(n,2) 种跃迁、选中跃迁的 hν 与波长、逸出功阈值和最大初动能 |
| `<Wiring>` | 预制组件 | 实物连线图：电池组、开关、电流表/电压表（多量程接线柱、指针按接入量程）、灵敏电流计、滑动变阻器（A/B/C/D）、电阻、电阻箱、小灯泡；导线可标为答案线（按钮显示）或按表达式显示 |

## 四、仍未做的

- `<Wiring>` 的自动排布只是「电表一排、其余按顺序换行」，元件多时导线交叉较多；要画得像课本，需要写 `x`、`y`（`lessons/_demo-gaokao.md` 两张连线图已改为手摆位置，伏安法那张零交叉）。电阻箱旋钮只画指针，没有 0–9 刻度。
- 真实交互回归：`app/scripts/interact-gaokao.mjs [night]` 用真实鼠标/键盘操作示例课件里的新组件（拖滑块、方向键、点单选、拖进度条、显示/隐藏答案线），核对读数，任何一项不对就以非零退出。
- 核反应方程、物理学史等纯文字题不需要组件。
- `generated/r6-03-hydrogen-levels.md` 仍是旧的手画能级图，可以改用 `<EnergyLevels allFrom={4} workFunction={3.2}>`。
