## 四、观察

1. 2008–2015 的全国卷几乎全覆盖。压轴是纸面内分区磁场，实验是读数和拟合。
2. 2020–2023 仍是全国卷。「部分」只落到 J9、J11、气柱和一根绳的可变约束。
3. 新高考从 2024 单独成卷。有图 24 题里完全 22。压轴仍在一个平面里，没有山东那种三维粒子轨迹。
4. 气柱三次撞上 `<GasTube>`：溢出后液柱不变短、两缸加阀门、变截面。等截面管和用 `v.tube` 画台阶不算新缺口。
5. 立体候选 8 题，主要是斜二测读图。真正要转视角的是斜面导轨、地磁环流和转动磁极。

## 五、验收记录
