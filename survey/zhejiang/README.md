### E. 小扩展和规范说明

- `<ForceDiagram>`：每个力可写附着点；不按比例的方向线（速度方向）`guides`。
- `<Motion>`：传送带恒定带速 `friction.belt` 和滑痕长度；完全失重时浮力消失；场区 `inner`。
- 刚体翻倒、重心标注（欹器、行李箱）。
- 规范补说明：三维情景画俯视加侧视；椭圆轨道按焦点放置的算法；点波源折射波前用 Define + `v.ellipse`；连续变化的 B(x) 可标注不按比例。

### 不建议做

三维轨迹（纸面内磁场、垂直纸面电场，3 题）、互感脉冲进求解器、转动的小孔、二维斜碰事件、照片类题图。

## 三、和广东卷相比

- 广东卷补的组件（仪器、纸带、连线、电场线、能级、气体）在浙江卷上基本都用得上：实验段完全 29/45。
- 浙江卷新增的重心在三处：光学（光路求解、干涉图样）、电磁感应压轴（转动、恒流源、二极管、螺线管、辐向场）、力学压轴的组合轨道。
- A 类五项是同一个问题：几何能画、物理要手算。它们最该先做，因为手算正是模型最容易出错、画面和答案最容易对不上的地方。
