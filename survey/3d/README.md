## 观察

1. 立体题集中在磁场和电磁感应：A–E 五族 28 道候选，占全部候选的三分之二。
2. 浙江近几年有上升：2025–2026 有 七11、七12、八15、九-21、五-5、十二23 六道候选，其中三道题干直接写了「俯视」。
3. 浙江、广东没有「竖直磁场 + 斜面导轨、安培力再分解到斜面」的题，斜面导轨题的磁场都垂直导轨平面，归在 B 族。（2026-10-11 补：后来调研的省份里有两道，山东 2025-18、四川 2015-11，见 `survey/national-summary.md` 第三节。）
4. 考卷图最难读的是斜二测：浙 五-5（U 形槽）、七18（偏转立方体）、粤 2015-19（三绳）、gd22-07（立方体两区磁场）。
5. A、B、D 三族共用的东西最多（圆柱导线、长方体、箭头、螺旋线、截面上的磁感线），三族合计 17 道候选，适合一起验证三维核心层。

## 选型

Grok 的调研报告：`selection-grok.md`。结论是自研轻量三维层，借鉴 fogleman/ln 的隐藏线算法和 Anatomy 的排序与审计思路。2026-10-11 核对：

- 已核实：Anatomy 的相机只有方位角和仰角（`references/kit.md`），没有斜投影；`lineSvg` 的 `dashed` 只是画线选项，不会自动判断遮挡。Zdog 的 README 写 MIT，GitHub 没识别出许可证文件，最后推送 2023-07。three-svg-renderer 是 GPL-3.0，最后推送 2023-05。JSXGraph v1.14.0 发布于 2026-10-05，`view3d.js` 有 `parallel` / `central` 两种投影和按元素的深度排序。three.js r186 发布于 2026-09-24。fogleman/ln 是 MIT，最后推送 2019-07。
- 没有核实：bundlephobia 上的体积数字。
- 修正一：报告把「斜二测和旋转视角之间的过渡」列为风险，其实不成立。任何秩为 2 的 3×2 线性映射都是一种平行投影，投影方向就是两行叉乘得到的零空间方向。所以斜二测矩阵和正交旋转矩阵之间线性插值，每一帧都是合法的平行投影，遮挡判断也照样能算。
- 修正二：工作量 4–5 周是按一个人从头做估的，偏高。我们的场景以线为主（导线、磁感线圆、箭头、螺旋线），实体只有少量凸体（长方体、圆柱）。隐藏线归结为一个通用操作：把线段按凸体切开，逐段判断是否被遮挡。螺旋线绕铁芯也是同一套。`magnetics.ts` 的 `helixSample` 已经在做三维采样加前后判断。
