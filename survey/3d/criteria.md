# 三维试点筛题：共同说明

项目：`/Users/huangxuewei/Projects/genui`。这是一个高考物理可视化系统：模型现场写课程文件，画面是二维教材示意图，物理量由求解器算。现在想挑少量题型做「三维试点」。

## 目标

三维不是为了好看，只为一件事：**题目本身是立体的，但考卷只给了一张二维图（侧视、俯视、截面、斜二测立体图或照片），学生在脑子里还原空间关系有困难。** 三维模型可以拖动旋转，并能转到和考卷原图同一个视角，教学生「这张图是从哪个方向看过去的」。

## 判定标准

逐题判断，只收真正立体的题：

**收（候选）**：理解或解题需要在脑子里重建三维关系。典型如下（不限于此）：
- 有关的矢量不在同一个平面里，且考卷图没有把它们都画进纸面：斜面导轨 + 竖直或垂直斜面的磁场、安培力要在斜面上分解；线圈在磁场中转动（中性面、有效切割）；霍尔片 / 电磁流量计 / 磁流体发电机（I、B、U 三向垂直）；带电粒子螺旋运动、非垂直入射磁场、三维轨迹。
- 考卷图是斜二测立体图，或同时给了立体图和截面图（学生要对应）。
- 空间支架、空间受力：晒衣架、三脚架、球体堆叠、圆锥摆、锥面 / 碗内圆周运动、转盘上的物体、空间绳系。
- 磁场的空间分布：通电直导线 / 线圈 / 螺线管 / 地磁场的立体图，磁通量穿过倾斜面，条形磁铁插入线圈。
- 其他：光在立体介质里（圆柱、球、立方体里的全反射，照亮区域）、天体轨道平面、立体电场（点电荷 + 平面）等。

**不收**：
- 标准的「纸面内运动 + 垂直纸面磁场（⊙/⊗）」：这是约定画法，学生已熟练，二维就够。
- 本来就是平面问题：斜面物块、抛体、单摆、电路图、平面光路、v–t 图等。
- 照片只做情境、不需要读图的题。

对拿不准的，收进来，标「边缘」并写理由。

## 每道候选题要写的字段

| 字段 | 内容 |
|---|---|
| 题号 | 用原记录里的编号（浙江如「七12」，广东如「gd23-10」或「2014-36」） |
| 年份 | |
| 情景 | 一句话 |
| 立体在哪里 | 哪些量 / 结构不在纸面内，学生要重建什么 |
| 考卷给的图 | 侧视 / 俯视 / 截面 / 斜二测立体 / 立体 + 截面 / 照片 / 无图 |
| 三维能补什么 | 具体：转到哪个视角、动什么、高亮什么 |
| 难度信号 | 有没有证据说明这里容易错（解析里强调方向判断、选项专设陷阱、原记录写了「缺」「画不对」等），没有就写「—」 |
| 题型归类 | 给一个短标签，如「斜面导轨+磁场」「转动线圈发电」「霍尔效应类」「螺旋运动」「圆锥摆/锥面」「空间支架」「球体堆叠」「磁通量倾斜面」「立体光学」「天体轨道」…… 同类题用同一个标签 |
| 判定 | 候选 / 边缘 |

## 输出

写到指定的输出文件（Markdown）：
1. 开头一行：本段共筛多少题，候选几题，边缘几题。
2. 候选表（按题型归类排序）。
3. 一个按题型归类的小计表：标签、题数、题号列表。
4. 最后几条观察（≤5 条）：哪类最多、哪类考卷图最难读、有没有意外发现。
