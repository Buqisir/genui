## 何时用

- 一道题有两三个明显的难点，想按难点一段一段讲，每段配一张只为这一段服务的图。（样板阶段，还没有写进生成规则。）
- 课件里只要出现 `<Segment>`，页面就改成「一段一屏」：顶部是分段导航，左边是这一段的图，图下面紧跟这一段的滑块和读数，右边是「动手 / 注意看」提示和讲解。手机上先显示提示，再显示图，最后是讲解。
- 不写 `<Segment>` 的课件仍是原来的版面。
- 分段课件的页首有「上课」按钮，打开给老师投影用的画布：题目、各段的图、滑块、提问和完整解答直接摆在一张大画布上（不套卡片），各段的图用箭头连起来（箭头上写全景段 `steps` 里的关系），可以拖动挪位置。翻页笔的「下一页」让镜头飞到下一段，按 O 拉远看全局，滚轮缩放，拖空白处平移；全景段 `link` 里的参数在整张画布上联动。顶栏的「翻页」切换到一屏一段的版面：先是题目页，然后一屏一段。屏幕上只有图、滑块和 `ask` 这一句提问；读数和后面的图要等揭晓后才出现；讲解收进只有老师打开的讲稿（按 N）。翻页笔的「下一页」先揭晓 `reveal`，再按一次才翻页。

## 最小例子

```lesson
---
id: example-segment
title: 分段
question: 示意
answers:
  - { name: h, value: 1 }
---

开场：这道题难在哪几处。

<Segment title="加热：等压上升" hint="拖动温度，从 330 K 拖到 440 K。" watch="摩擦力一直向下、大小不变。" ask="加热时活塞怎么动？" reveal="缓慢上升，气体压强不变。" />

这一段的讲解。

<Param name="T" label="温度" value={330} min={330} max={440} unit="K" />

<Define name="h" expr="T/330" />

<Figure title="活塞" params={["h"]}>
figure({
  draw(ctx, p, v) {
    const m = v.view({ xmin: -1, xmax: 1, ymin: 0, ymax: 2, equal: true })
    v.block(m, 0, p.h, 0.6, 0.1)
  },
})
</Figure>

<Segment title="完整解答" />

完整解答写在最后一段。
```

## 常见错误

- 一段里放好几张图、七八个读数 → 一段只讲一个难点，图和读数只留这一段要看的。
- 讲解里说「题目给了 400 K」，却要学生回到页首去找 → 写 `quote`，抄这一段用到的原题句子，关键条件用 `**…**` 标出，它显示在右栏最上面。
- `hint` 只写「拖动看看」 → 写清拖哪个量、从多少拖到多少；`watch` 写拖动时该盯住什么、会看到什么变化。
- `ask` 问的东西图里已经画出来了（比如问力的方向，图上却已有力的箭头）→ 在图里用一个隐藏参数控制答案画不画，写进 `revealParam`。上课时揭晓前它是 0、揭晓后是 1，学生自己看页面时一直是 1，所以这个参数的初值写 1。
- 想让学生看清几问之间怎么一环扣一环 → 在「完整解答」前加一个全景段：`chain` 列出要连起来的段号，`link` 列出这几段各自的同一个量（第一个显示成滑块，其余跟着它变），`steps` 写相邻两张图之间的关系。全景段里可以再放一个 `<Readout>`，列出链上每一环的数值。
- `ask` 写成长段 → 投影上一眼读完的一句话；`reveal` 一两句，讲稿里再展开。
- 把 `<Param>` 写在别的段里 → 滑块显示在它所在的那一段，写在要用它的那一段下面。

## 属性
<!-- props:Segment -->
| 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| title | string | 是 | 这一段讲什么（导航上显示） |
| quote | string |  | 这一段用到的原题句子，**…** 标出关键条件 |
| hint | string |  | 动手：拖哪个量、点哪个按钮 |
| watch | string |  | 注意看：拖动时该盯住什么 |
| ask | string |  | 上课时投在屏幕上问全班的一句话 |
| reveal | string |  | 上课时按空格揭晓的答案，一两句 |
| chain | array |  | 全景段：按顺序列出要连成一条链的段号（从 1 数），每段取它的第一张图 |
| link | names |  | 全景段：一起联动的参数，第一个显示成滑块，其余跟着它变 |
| steps | array |  | 全景段：相邻两张图之间箭头上写的关系，如 "ΔR = αF" |
| revealParam | string |  | 揭晓前设为 0、揭晓后设为 1 的隐藏参数名；图里据此先不画答案（如力的箭头） |
<!-- /props -->

## 规范原文
<!-- region:segment -->
### `<Segment>`：分段讲解

`<Segment title quote hint watch />` 是分段标记，自闭合。从它开始到下一个 `<Segment>` 之前的正文、图和控件都属于这一段；第一个 `<Segment>` 之前的正文是开场，只在第一段上方显示。最后一段通常写「完整解答」，不放图。`ask`、`reveal`、`revealParam` 只用于上课模式：`ask` 是投在屏幕上问全班的一句话，`reveal` 是按空格揭晓的答案，`revealParam` 是揭晓前设为 0、揭晓后设为 1 的隐藏参数。写了 `chain` 的是全景段：不放自己的图，而是把 `chain` 里各段的第一张图排成一行，用 `steps` 标在箭头上，由 `link` 的第一个参数统一驱动。上课模式还有画笔（P 键），在投影上圈画，翻页时自动擦掉。每段都写了 `quote` 时，页首的原题默认收成一行关键条件（头信息 `givens: ["…", …]`），点「题目原文」展开全文。
