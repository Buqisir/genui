整个过程分四段：

1. 小球自由下落到 Q。
2. 小球在方形物体的轨道里滑行。地面光滑，小球和方形物体组成的系统**水平方向动量守恒**，轨道光滑，**机械能守恒**。
3. 小球从 P 平抛，落到 a 上粘住。竖直速度被地面方向的冲击抵消，水平方向小球和 a 动量守恒。
4. a 带着小球向左运动，b 被锁定，弹簧被拉长。拉力达到 $15\ \mathrm{N}$ 时 b 解锁，a（含小球）、b 和弹簧组成的系统动量守恒、机械能守恒，三者共速时弹簧最长，弹性势能最大。

小球在 Q 点只有竖直速度，系统水平总动量为零。P、Q 同高，小球从释放到 P 下降的高度就是 $h$。

## 完整解答

**（1）** 取向左为正。小球在 P 点速度水平，方形物体速度也水平，水平方向动量守恒：

$$
mv_1 - Mv_2 = 0
$$

机械能守恒（P、Q 同高，小球比释放点低 $h$）：

$$
mgh = \frac{1}{2}mv_1^2 + \frac{1}{2}Mv_2^2
$$

代入 $m = \dfrac{1}{2}\ \mathrm{kg}$、$M = \dfrac{9}{2}\ \mathrm{kg}$、$h = 2\ \mathrm{m}$：由第一式 $v_2 = \dfrac{v_1}{9}$，代入第二式 $10 = \dfrac{1}{4}v_1^2 + \dfrac{1}{36}v_1^2 = \dfrac{5}{18}v_1^2$，得

$$
v_1 = \boxed{6\ \mathrm{m/s}}\ (\text{水平向左}),\qquad v_2 = \boxed{\frac{2}{3}\ \mathrm{m/s}}\ (\text{水平向右})
$$

**（2）** 小球落到 a 上粘住，水平方向动量守恒：

$$
mv_1 = (m + m_a)v_3 \quad\Rightarrow\quad v_3 = \frac{0.5 \times 6}{1.5}\ \mathrm{m/s} = 2\ \mathrm{m/s}
$$

b 锁定期间弹簧被拉长，拉力达到 $F = 15\ \mathrm{N}$ 时形变量 $x_1 = \dfrac{F}{k} = 0.3\ \mathrm{m}$，弹性势能 $\dfrac{1}{2}kx_1^2 = 2.25\ \mathrm{J}$。由机械能守恒

$$
\frac{1}{2}(m + m_a)v_3^2 = \frac{1}{2}(m + m_a)v_4^2 + \frac{1}{2}kx_1^2 \quad\Rightarrow\quad 3 = 0.75v_4^2 + 2.25,\quad v_4 = 1\ \mathrm{m/s}
$$

b 解锁后，三者共速时弹簧最长。动量守恒

$$
(m + m_a)v_4 = (m + m_a + m_b)v_b \quad\Rightarrow\quad v_b = \frac{1.5 \times 1}{2.25}\ \mathrm{m/s} = \boxed{\frac{2}{3}\ \mathrm{m/s}}\ (\text{水平向左})
$$

机械能守恒

$$
E_{pm} = \frac{1}{2}(m + m_a)v_4^2 + \frac{1}{2}kx_1^2 - \frac{1}{2}(m + m_a + m_b)v_b^2 = 0.75 + 2.25 - 0.5 = \boxed{\frac{5}{2}\ \mathrm{J}}
$$

sim({
  at(t, p) {
    const r = 0.4
    const H = 1.0
    const L = 0.4 + Math.PI * r + Math.PI / 2 * r
    // 轨道在方形物体参考系里的点和单位切线
    const pt = (s) => {
      if (s < 0.4) return [0.5, H - s, 0, -1]
      s -= 0.4
      if (s < Math.PI * r) { const a = -s / r; return [0.1 + r * Math.cos(a), 0.6 + r * Math.sin(a), Math.sin(a), -Math.cos(a)] }
      s = Math.min(s - Math.PI * r, Math.PI / 2 * r)
      const a = s / r
      return [-0.7 + r * Math.cos(a), 0.6 + r * Math.sin(a), -Math.sin(a), Math.cos(a)]
    }
    const mu = p.m * p.M / (p.m + p.M)
    const vQ = Math.sqrt(2 * p.g * p.h)
    const E = 0.5 * p.m * vQ * vQ + p.m * p.g * H
    const X0 = 3.0
    const shift = (s) => -p.m / (p.m + p.M) * (pt(s)[0] - 0.5)
    let bx = X0 + 0.5
    let by = H + p.h
    let X = X0
    if (t < p.tQ) {
      by = H + p.h - 0.5 * p.g * t * t
    } else if (t < p.tP) {
      // 沿轨道积分 dt = ds / ṡ，ṡ 由水平动量守恒和机械能守恒给出
      let s = 0
      let tt = p.tQ
      const ds = L / 400
      while (s < L - 1e-9) {
        const q = pt(s + ds / 2)
        const sd = Math.sqrt(2 * (E - p.m * p.g * q[1]) / (mu * q[2] * q[2] + p.m * q[3] * q[3]))
        if (tt + ds / sd > t) { s += (t - tt) * sd; break }
        tt += ds / sd
        s += ds
      }
      const q = pt(s)
      X = X0 + shift(s)
      bx = X + q[0]
      by = q[1]
    }
    const XP = X0 + shift(L)
    const v2 = p.m * p.v1 / p.M
    const xP = XP - 0.7
    const xa0 = xP - p.v1 * (p.tHit - p.tP)
    const D0 = 0.9
    let xa = xa0
    let xb = xa0 + D0
    let ext = 0
    if (t >= p.tP) {
      X = XP + v2 * (t - p.tP)
      if (t < p.tHit) {
        bx = xP - p.v1 * (t - p.tP)
        by = H - 0.5 * p.g * (t - p.tP) * (t - p.tP)
      }
    }
    if (t >= p.tHit) {
      const tau = t - p.tHit
      if (t < p.tU) {
        ext = p.v3 / p.w1 * Math.sin(p.w1 * tau)
        xa = xa0 - ext
      } else {
        const tq = t - p.tU
        const mA = p.m + p.ma
        const mT = mA + p.mb
        ext = p.x1 * Math.cos(p.w2 * tq) + p.v4 / p.w2 * Math.sin(p.w2 * tq)

        const xc = (mA * xa1 + p.mb * xb) / mT - mA * p.v4 / mT * tq
        xa = xc - p.mb / mT * (D0 + ext)
        xb = xc + mA / mT * (D0 + ext)
      }
      bx = xa
      by = 0.27
    }
    return { bx, by, X, xa, xb, ext, locked: t < p.tU }

## 结合图像理解

动画里小球在 Q 点竖直滑入时方形物体静止，小球绕到底部往左走时，方形物体被推向右，两者水平动量始终等大反向；小球从 P 飞出时速度 $6\ \mathrm{m/s}$，方形物体 $\dfrac{2}{3}\ \mathrm{m/s}$，正好是质量的反比。

$E_p$–$t$ 图上，粘住后弹性势能从 0 上升，到 $2.25\ \mathrm{J}$（拉力 $15\ \mathrm{N}$）时 b 解锁，曲线没有断，继续上升到峰值 $2.5\ \mathrm{J}$，此时 a、b 共速 $\dfrac{2}{3}\ \mathrm{m/s}$。账本里解锁瞬间的机械能 $3\ \mathrm{J}$ 分成两份：$0.5\ \mathrm{J}$ 是三者共同运动的动能，剩下的 $2.5\ \mathrm{J}$ 才能存进弹簧。

把 F 调小，b 解锁得早，a 还很快，共同速度更大，留给弹簧的势能也变了：最大弹性势能取决于解锁时 a 的速度和弹簧已有的形变。

## 答案

（1）$v_1 = 6\ \mathrm{m/s}$，水平向左；$v_2 = \dfrac{2}{3}\ \mathrm{m/s}$，水平向右。

（2）$v_b = \dfrac{2}{3}\ \mathrm{m/s}$，水平向左；$E_{pm} = \dfrac{5}{2}\ \mathrm{J}$。
