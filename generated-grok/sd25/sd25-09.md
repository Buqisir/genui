从图上读波长。

- **甲波**：$x = -6\ \mathrm{m}$ 处向右上升过零，$-5\ \mathrm{m}$ 波峰，$-4\ \mathrm{m}$ 过零，$-3\ \mathrm{m}$ 波谷，$-2\ \mathrm{m}$ 过零，一个完整波长是 $4\ \mathrm{m}$。M 在 $-6\ \mathrm{m}$ 右边一点、位移 $1\ \mathrm{cm}$，即 $x_M = -6 + \dfrac{\lambda_{\text{甲}}}{12} = -\dfrac{17}{3}\ \mathrm{m}$。
- **乙波**：$x = 2\ \mathrm{m}$ 和 $x = 6\ \mathrm{m}$ 处位移都是 $1\ \mathrm{cm}$，中间 $x = 4\ \mathrm{m}$ 是波谷。波谷两侧各 $2\ \mathrm{m}$ 处位移为 $1\ \mathrm{cm}$（振幅的一半），由 $-2\cos\dfrac{2\pi\cdot2}{\lambda_{\text{乙}}} = 1$ 得 $\dfrac{2\pi\cdot2}{\lambda_{\text{乙}}} = \dfrac{2\pi}{3}$。

质点的振动方向用「同侧法」：沿传播方向看，波形前方比质点高，质点就向上运动。

## 完整解答

**A 错误。** $\lambda_{\text{甲}} = 4\ \mathrm{m}$，$T_{\text{甲}} = \dfrac{\lambda_{\text{甲}}}{v} = \dfrac{4}{1}\ \mathrm{s} = 4\ \mathrm{s}$，不是 $6\ \mathrm{s}$。

**B 正确。** $\dfrac{4\pi}{\lambda_{\text{乙}}} = \dfrac{2\pi}{3}$，$\lambda_{\text{乙}} = 6\ \mathrm{m}$。周期 $T_{\text{乙}} = 6\ \mathrm{s}$。

**C 错误。** 甲波向左传。t = 0 时 M 左边紧挨着的波形比 M 低、右边比 M 高——波形向左平移时，M 的位置将被右边更高的部分占据，所以 M 向 $y$ 轴正方向运动。$t = 6\ \mathrm{s} = 1.5T_{\text{甲}}$，过了一个半周期，振动状态与 t = 0 相反：位移 $-1\ \mathrm{cm}$、向 $y$ 轴**负**方向运动。

**D 正确。** 乙波向右传。t = 0 时 N 左边的波形比 N 低，波形右移后 N 处将被更低的部分占据，N 向 $y$ 轴负方向运动。$t = 6\ \mathrm{s} = T_{\text{乙}}$，恰好一个周期，状态与 t = 0 相同，仍向 $y$ 轴负方向运动。

选 $\boxed{\text{BD}}$。

## 结合图像理解

播放动画：甲波一路向左，M 每 4 s 回到原来的状态；乙波一路向右，N 每 6 s 回到原来的状态。中间 $-\dfrac{5}{3}\ \mathrm{m}$ 到 $2\ \mathrm{m}$ 一段始终是平的，两列波背向传播，不会相遇叠加。

振动图像上，t = 6 s 处 M 的曲线（实线）正在下降，位移 $-1\ \mathrm{cm}$，所以 M 向 $y$ 轴负方向运动；N 的曲线（虚线）回到 t = 0 时的值 $1\ \mathrm{cm}$，同样在下降，N 向 $y$ 轴负方向运动。

## 答案

选 **BD**。
