## 一、题目条件分析

高能电子穿过铝箔，在箔后屏幕上形成同心圆环：中心是一个亮斑，向外明暗相间，越往外越淡，各环圆心与中心亮斑重合。铝箔是多晶，晶粒取向不同，同一衍射角上的斑点连成圆环。

这是电子德布罗意波的衍射图样。题目没有给出速度、加速电压、晶面间距和屏距。交互演示取代表值，并在正文里写明：

- 电子速度 $v = 6\times 10^{7}\ \text{m/s}$
- 电子质量 $m = 9.1\times 10^{-31}\ \text{kg}$，元电荷 $e = 1.6\times 10^{-19}\ \text{C}$
- 非相对论动能关系 $\frac{1}{2}mv^{2} = eU$，代表速度下加速电压为 $U = 10237.5\ \text{V}$
- 环半径比例常数 $k = 0.4\ \text{mm/pm}$，把晶面间距和屏距折在一起，只保留 $r \propto \lambda$

中学阶段用 $\lambda = h/(mv)$，不计入相对论修正。上面的速度远小于光速，用来看图样随速度怎么变。

## 二、完整解答

**A. 错误。** 衍射是波的现象。电子穿过铝箔后出现衍射环，表明电子具有波动性。粒子性的典型证据是光电效应、康普顿效应。选项把本实验的结论说成了粒子性。

**B. 错误。** 亮纹是大量电子打在屏幕上以后留下来的位置分布。每个电子落在屏上一个点，许多落点堆积成环。电子从电子枪出来，向前穿过铝箔，再打到屏幕上，并没有沿着圆环运动。亮纹不是运动轨迹。

**C. 正确。** 物质波的强度表示电子在该处出现的概率。亮纹处到达的电子多，出现的概率大；暗纹处概率小。图上越往外越淡，就是外圈概率更小。

$$\boxed{C}$$

**D. 错误。** 非相对论德布罗意波长

$$\lambda = \frac{h}{mv} \propto \frac{1}{v}$$

多晶衍射环满足布拉格条件 $n\lambda = 2d\sin\theta$。屏距为 $L$ 时，环半径 $r = L\tan 2\theta$。$\theta$ 很小时 $r \propto \lambda$。中心亮斑的角半径同样正比于波长（圆孔衍射里中心亮斑角半径约 $1.22\lambda/D$，晶体图样的整体尺度也随 $\lambda$ 缩放）。因此

$$r \propto \lambda \propto \frac{1}{v}$$

速度变大，动量变大，波长变短，衍射角变小，圆环向中心收缩，中心亮斑半径变小。

速度加倍时

$$\frac{r(2v)}{r(v)} = \frac{v}{2v} = \boxed{0.5}$$

容易把电子想成“更快就打得更靠外”。环的半径由波长决定：速度变大时波长变短，环更小。

## 四、结合图像理解关键时刻

三个预设对应图样的三种尺度。

代表速度 $6\times 10^{7}\ \text{m/s}$（$U = 10237.5\ \text{V}$）：屏幕上是中心亮斑加同心亮环。亮处电子到达得多，概率大，这是选项 C。侧视里电子束笔直穿过铝箔打到屏上，亮环并不是这条飞行路线，选项 B 不成立。

速度减半：波长加倍，第 1 亮环半径加倍，中心亮斑所占的范围一起变大，外圈更疏。

速度加倍：波长减半，第 1 亮环半径减半，环向中心收拢，中心亮斑变小。选项 D 说半径变大，与图样相反。

$r_1$–$v$ 曲线是反比关系。速度滑块向右时，游标沿曲线下降。第 1 亮环以内就是中心亮斑所在的范围，环半径变小，中心亮斑跟着变小。

## 五、答案汇总

| 选项 | 判断 |
| --- | --- |
| A | 错误。衍射环表明电子具有波动性 |
| B | 错误。亮纹是屏上的概率分布，不是轨迹 |
| C | 正确。亮纹处电子出现的概率大 |
| D | 错误。速度越大，波长越短，中心亮斑和衍射环越小 |
| 速度加倍后的半径比 | $0.5$ |

答案是 C。
