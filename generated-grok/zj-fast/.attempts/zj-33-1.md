## 一、题目条件分析

两板竖直正对，M 在左、N 在右。板长 L 是竖直方向的长度，粒子源在 M 板中点。板间距题目没有给出，记为 d。

取粒子源为原点，x 轴向右（垂直 M 板指向 N），y 轴沿板向上。两板占据 −L/2 ≤ y ≤ L/2，N 板在 x = d。

板间是水平方向的匀强电场，边界效应不计。两粒子相同，重力不计，彼此无相互作用，因此加速度 a 相同，而且只有水平分量。竖直方向分速度保持不变。

- 向右的粒子：初速度 v₀ 沿 +x。到达 N 板时速率为 √2 v₀，大于 v₀，所以水平方向一直在加速，电场力指向 N。
- 向下的粒子：初速度 v₀ 沿 −y。刚好从 N 板下端射出，意味着 x = d 时，y 正好是 −L/2。

题目只给字母。下文的演示取代表性数值 v₀ = 1 m/s、L = 4 m；字母结论与这对取值无关。质量、电荷量题目也没给，演示取 m = 1 kg、|q| = 1 C，只为把电场强度和能量显示成具体的数。加速度、轨迹和时间的比例不依赖这对具体数值。

## 二、完整解答

### 两个运动条件

向右的粒子到达 N 板时，竖直分速度仍是 0，速率就是水平分速度 √2 v₀。匀变速规律：

$$(\sqrt{2}\,v_0)^2 = v_0^2 + 2ad$$

$$ad = \frac{v_0^2}{2} \qquad (1)$$

速率增大，位移向右，所以 a > 0，电场力由 M 指向 N。

向下的粒子在竖直方向做匀速运动，中点到下端的距离是板长的一半：

$$\frac{L}{2} = v_0 t \quad\Rightarrow\quad t = \frac{L}{2v_0}$$

水平方向初速度为 0：

$$d = \frac12 at^2 = \frac{aL^2}{8v_0^2} \qquad (2)$$

### 解出加速度和板间距

由 (1) 得 d = v₀²/(2a)，代入 (2)：

$$\frac{v_0^2}{2a} = \frac{aL^2}{8v_0^2}$$

$$a^2 = \frac{4v_0^4}{L^2}$$

$$a = \frac{2v_0^2}{L}$$

正号表示加速度由 M 指向 N。板间距随之确定：

$$d = \frac{v_0^2}{2a} = \frac{L}{4}$$

向右的粒子到达 N 板的时间：

$$t_\text{右} = \frac{\sqrt{2}\,v_0 - v_0}{a} = \frac{(\sqrt{2}-1)L}{2v_0}$$

代表性数值 v₀ = 1 m/s、L = 4 m 下：

$$\boxed{a = 0.5\ \text{m/s}^2},\quad \boxed{d = 1\ \text{m}},\quad \boxed{t = 2\ \text{s}},\quad \boxed{t_\text{右} = 0.828\ \text{s}}$$

### A（错误）

电场力指向 N，说明 q 与场强的乘积指向 N，由此定不出电场本身的方向。

粒子若带正电，电场由 M 指向 N，M 板电势高。粒子若带负电，电场由 N 指向 M，N 板电势高。

题目没有给出粒子的电性，不能得出“M 板电势高于 N 板电势”。

### B（错误）

两粒子的水平位移都从 M 一侧到 N 一侧，电场力都向右做正功，电势能都减少。

向右的粒子：

$$\Delta E_k = \frac12 m\left(2v_0^2 - v_0^2\right) = \frac12 mv_0^2 > 0$$

$$\Delta E_p = -\Delta E_k < 0$$

向下的粒子射出时，水平分速度

$$v_x = at = \frac{2v_0^2}{L}\cdot\frac{L}{2v_0} = v_0$$

竖直分速度仍是 −v₀，速率同样是 √2 v₀。动能增量仍是 (1/2)mv₀²，电势能同样减少。

“两个粒子的电势能都增加”不成立。

### C（正确）

上面联立两个运动条件，得到粒子在板间的加速度

$$\boxed{\dfrac{2v_0^2}{L}}$$

方向垂直于板、由 M 指向 N。两粒子相同，加速度相同。

若把中点到下端的距离误当成整段板长 L，会得到 a = v₀²/L，与这个结果不同。中点到下端是 L/2。

### D（错误）

从 N 板下端射出的是平行 M 板向下的那个粒子。竖直方向匀速走过 L/2，时间是

$$\boxed{\dfrac{L}{2v_0}}$$

选项中的式子 ((√2 − 1)L)/(2v₀) 等于向右粒子到达 N 板的时间 t_右。二者之比是

$$\frac{1}{\sqrt{2}-1} = \sqrt{2}+1 \approx 2.41$$

并不相等。代表性数值下，下端射出时间是 2 s，该式给出 0.828 s。

四个选项里只有 C 成立。

$$\boxed{C}$$

## 四、结合图像理解关键时刻

速率图上，向右粒子的曲线在 t_右 处碰到 √2 v₀，这时它到达 N 板正中（y = 0）。向下粒子的速率曲线更晚才碰到同一条水平虚线：射出时 v_x = v₀、v_y = −v₀，速率也是 √2 v₀。选项 D 的时刻与 t_右 重合，落在向下粒子还没射出去的那一段。

竖直位置图是一条过原点的直线 y = −v₀ t。它和 y = −L/2 的交点才是下端射出的时刻，横坐标是 L/(2v₀)。在选项 D 的时刻，这条直线才走到大约 −0.414 L，离下端还差一截。代表数值下就是 y ≈ −0.828 m，下端在 y = −2 m。

能量账本对照的是同一个结论：到达 N 板时动能变大，电势能变小，二者之和不变。选项 B 说电势能增加，和账本相反。

把粒子电性改成负电荷后，速率图和 y–t 图都不变，画面上的正负号和电场箭头反向。运动学条件定得出电场力的方向，定不出电势谁高谁低，所以 A 不能选。

## 五、答案汇总

| 选项 | 判断 | 要点 |
|---|---|---|
| A | 错误 | 电场力指向 N，电性未知，电势高低不能确定 |
| B | 错误 | 电场力做正功，两个粒子的电势能都减少 |
| C | 正确 | a = 2v₀²/L，方向由 M 指向 N |
| D | 错误 | 下端射出时间是 L/(2v₀)；该式等于向右粒子到达 N 板的时间 |

代表性数值 v₀ = 1 m/s、L = 4 m 时：a = 0.5 m/s²，d = 1 m，下端射出时间 t = 2 s，向右粒子到达时间 t_右 = 0.828 s。
