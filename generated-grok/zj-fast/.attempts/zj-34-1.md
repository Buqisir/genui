## 一、题目条件分析

- 玻璃砖的截面是等腰三角形。参与折射的是侧面 A、侧面 B，两侧面的夹角是顶角 θ。底边水平，求折射率时用不到底边，也用不到两个底角相等。
- 直线 ab 贴着侧面 A。cd 过 O 且垂直于 ab，所以沿 cd 射来的光在侧面 A 上的入射角是 0°。P₁、P₂ 都插在 cd 的空气一侧，P₁ 在外、P₂ 靠近 O。
- ef 是侧面 B 在纸上的位置。光线在侧面 B 折射后进入空气，出射光线和直线 ef 的夹角记为 α。
- 图上的 O′ 在 cd 穿出侧面 B 以后，是“不发生偏折”时光线要去的位置。实际出射光线离开了 cd，所以 P₃ 不在 cd 上，图中也没有把光线画到 P₃。
- 题目只给字母 θ、α。下面取一组代表值：θ = 30°，α = 40°，对应普通玻璃能测到的结果。图中边长取 8 cm，只为把针和角度画开，角度仍按真实大小，折射率与边长无关。

## 二、完整解答

### ③ P₃ 挡住谁的虚像

P₁、P₂ 确定的入射光线就是 cd。cd 垂直于侧面 A，入射角为 0°，折射角也是 0°，光进入玻璃后方向不变，仍然沿 cd，一直到侧面 B 才折射。

从侧面 B 观察时，进入眼睛的是折射以后的光线。把出射光线反向延长，延长线并不经过 P₁、P₂ 的真实位置，所以看到的是虚像。

P₁ 和 P₂ 在同一条入射光线上，经侧面 B 折射后仍落在同一条出射视线上，两枚针的虚像重叠。P₃ 必须同时挡住这两枚虚像，视线才是出射光线。

- 只挡住 P₁：错误。视线没有被 P₂ 约束，可以是别的方向。
- 只挡住 P₂：错误。同样不能确定这就是沿 cd 进来的那条光线。
- 同时挡住 P₁ 和 P₂：正确。

$$
\boxed{P_1 \text{ 和 } P_2}
$$

### ④ 要不要第四枚大头针

出射光线是一条直线，纸上至少要两个点才能把它画出来。

P₃ 只给出一个点。还要在同一条视线上再插一枚 P₄，让 P₄ 同时挡住 P₃ 以及 P₁、P₂ 的虚像。撤去玻璃砖和大头针以后，两个针孔 P₃、P₄ 的连线才是出射光线，才能去量它和 ef 的夹角 α。

所以确定出射光线的位置，需要第四枚大头针。

$$
\boxed{\text{需要}}
$$

### ⑤ 折射率

记 cd 与 ef 的交点为 M，玻璃砖的顶点为 V。在 △VOM 中：

- ∠OVM 就是两侧面的夹角 θ；
- VO 沿着侧面 A，OM 沿着 cd，而 cd ⊥ ab，所以 ∠VOM = 90°；
- 因此玻璃内部的光线和侧面 B 的夹角 ∠VMO = 90° − θ。

法线垂直于 ef。入射角从法线量起，所以侧面 B 上的入射角

$$
i = 90^\circ - (90^\circ - \theta) = \theta
$$

出射光线与 ef 的夹角是 α，故折射角

$$
r = 90^\circ - \alpha
$$

光从玻璃射向空气，折射定律为

$$
n \sin i = \sin r
$$

$$
n \sin\theta = \sin(90^\circ - \alpha) = \cos\alpha
$$

$$
n = \boxed{\dfrac{\cos\alpha}{\sin\theta}}
$$

代表值 θ = 30°、α = 40° 代入：i = 30°，r = 50°，

$$
n = \frac{\cos 40^\circ}{\sin 30^\circ} = \frac{0.7660}{0.5} = \boxed{1.532}
$$

核对：n sin θ = 1.532 × 0.5 = 0.766 = sin 50°，与 r = 50° 一致。

两个常见的错式，用同一组数就能看出来：

- 把 α 当成折射角，写成 sin α / sin θ。代入得 sin 40° / sin 30° = 1.286，和 1.532 不同。α 恰好取 45° 时 sin 与 cos 相等，两个式子数值碰巧一样，不能靠这一个角度发现错误。
- 把入射角当成底角 (180° − θ) / 2。θ = 30° 时底角是 75°，cos 40° / sin 75° = 0.793，小于 1，不可能是玻璃，说明入射角就是顶角 θ，不是底角。

实验能做成，还要求侧面 B 不发生全反射：θ 小于临界角 arcsin(1/n)。代表值 n = 1.532 时临界角约 40.8°，θ = 30° 小于它，光线能从侧面 B 射出，才能看到虚像。

## 四、结合图像理解

拖动 α，或点上面的三个预设，对照光路和图线。

- 代表值 θ = 30°、α = 40°：侧面 B 上 i = 30°，r = 50°。出射光线比 cd 更靠近 ef，P₃、P₄ 落在 cd 的下方，O′ 留在原方向上。读数 n = 1.532，虚线给出的错误值是 1.286。
- 点「不偏折」：α 被放到 90° − θ。这时 r = i = θ，n = 1，出射光线与 cd 重合，P₃、P₄ 和 O′、d 排成一条直线。图线上这个位置标着 n = 1。α 再增大，算出的 n 会小于 1，玻璃砖不会出现这种偏折。
- 点「α = 45°」：sin α = cos α，正确式和错误式交于同一点。只拿这一个角度的数值，分不出 α 到底是和 ef 的夹角，还是和法线的夹角。要靠几何关系判断：题里的 α 靠着 ef，法线又垂直于 ef，所以进折射定律的是 90° − α。
- 顶角改大时，同一块玻璃对应的 α 变小，出射光线更贴着 ef。这就是 i = θ 变大、折射角 r 也变大的结果。α 小到使 n sin θ 超过 1 以前，侧面 B 已经全反射，插针法看不到虚像；代表值下临界角约 40.8°，30° 的顶角还在能射出的范围里。
