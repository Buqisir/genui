## 一、题目条件分析

吊篮原来静止。杯底固定着三套装置，图上的形变要分开看：

- A 是铁球，弹簧**被压缩**（圈较密），弹力向上。
- B 是木球，弹簧**被拉长**，弹力向下。
- C 是木球，下面是**细线**。细线只提供拉力，拉力可以在一瞬间变成 0。

三球都浸没。已知 $\rho_木 < \rho_水 < \rho_铁$，不计空气阻力。问的是绳子剪断的**那一瞬间**，相对**杯底**的运动趋势。

剪断后，吊篮、杯子和水一起自由下落，向下的加速度等于 $g$。这一瞬间：

- 弹簧的形变来不及改变，弹力保持剪断前的值。
- 水随杯子以 $g$ 向下加速，液体里的压强差消失，浮力变为 0。
- 细线的拉力是约束力，会立刻变成新的平衡所需要的值；完全失重时这个值是 0。

题目只给了密度的大小关系。下面取一组符合 $\rho_木 < \rho_水 < \rho_铁$ 的代表性数值，把方向算成具体加速度。加速度的正负只由「铁比水密、木比水疏」和「A 压、B 拉、C 是细线」决定，换一组数，正负号不变。

取 $g = 10\ \text{m/s}^2$，三球体积同为 $V = 1.0\times 10^{-4}\ \text{m}^3$，$\rho_水 = 1.0\times 10^3\ \text{kg/m}^3$，$\rho_铁 = 8.0\times 10^3\ \text{kg/m}^3$，$\rho_木 = 5.0\times 10^2\ \text{kg/m}^3$。动画里弹簧劲度取 $k_A = 350\ \text{N/m}$（压缩 $2\ \text{cm}$）、$k_B = 25\ \text{N/m}$（伸长 $2\ \text{cm}$），只用来演示剪断之后的一小段运动；瞬间加速度等于当时的弹力除以质量，与劲度怎样拆开无关。

## 二、完整解答

杯底参考系里，吊篮向下的加速度为 $a$ 时，有效重力加速度

$$
g_效 = g - a
$$

重力按 $mg_效$、浮力按 $\rho_水 V g_效$ 计算，弹簧弹力仍由形变决定。这和「真实重力再加一个向上的惯性力 $ma$」是同一件事。绳子剪断对应 $a = g$，于是 $g_效 = 0$。

以下加速度都**向上为正**。

### 剪断前：三球相对杯底静止

$$
F_{浮0} = \rho_水 V g = 1.0\times 10^3 \times 1.0\times 10^{-4} \times 10 = \boxed{1\ \text{N}}
$$

铁球 A：$m_A = \rho_铁 V = 0.80\ \text{kg}$。重力 $8.0\ \text{N}$ 大于浮力，弹簧被压缩，弹力向上：

$$
F_{sA} = m_A g - F_{浮0} = 0.80\times 10 - 1 = \boxed{7\ \text{N}}
$$

木球 B：$m_B = \rho_木 V = 0.050\ \text{kg}$。浮力大于重力，弹簧被拉长，弹力向下：

$$
F_{sB} = F_{浮0} - m_B g = 1 - 0.50 = \boxed{0.5\ \text{N}}
$$

木球 C 与 B 的密度、体积相同，细线拉力向下：

$$
T_0 = F_{浮0} - m_C g = \boxed{0.5\ \text{N}}
$$

体积取得相同，只是为了让 $F_{sB}$ 和 $T_0$ 都是 $0.5\ \text{N}$。体积不同时这两个力的大小会不同，方向仍然一个向下、一个向下。

### 剪断瞬间：$a = g$，$g_效 = 0$

浮力跟着 $g_效$ 变成 0：

$$
F_浮 = \rho_水 V g_效 = \boxed{0\ \text{N}}
$$

弹簧形变未变，$F_{sA}$、$F_{sB}$ 仍是 $7\ \text{N}$ 向上和 $0.5\ \text{N}$ 向下。细线要维持 C 不动，所需拉力正比于多余的浮力，也就正比于 $g_效$：

$$
T = (\rho_水 - \rho_木)\, V g_效 = \boxed{0\ \text{N}}
$$

杯底参考系里，$g_效 = 0$ 之后重力和浮力都退出。A 只剩向上的弹力，B 只剩向下的弹力，C 的合力为 0：

$$
a_A = \frac{F_{sA}}{m_A} = \frac{7}{0.80} = \boxed{8.75\ \text{m/s}^2}
$$

$$
a_B = -\frac{F_{sB}}{m_B} = -\frac{0.50}{0.050} = \boxed{-10\ \text{m/s}^2}
$$

$$
a_C = \boxed{0\ \text{m/s}^2}
$$

写成随吊篮加速度变化的式子（滑块和后面的图像用的就是它）：

$$
a_A = \left(1 - \frac{\rho_水}{\rho_铁}\right) a, \qquad a_B = \left(1 - \frac{\rho_水}{\rho_木}\right) a, \qquad a_C = 0
$$

$\rho_铁 > \rho_水$，$a_A$ 与 $a$ 同号；$a > 0$ 时 A 相对杯底向上。$\rho_木 < \rho_水$，$a_B$ 与 $a$ 异号；B 相对杯底向下。细线在 $0 \le a \le g$ 内始终能把 C 拉住，直到 $a = g$ 时拉力刚好减到 0，C 的相对加速度仍是 0。

所以剪断瞬间：A 向上运动，B 向下运动，C 不动。

对地再核对一次（向上仍为正）。杯子对地的加速度是 $-g = -10\ \text{m/s}^2$。

$$
a_{A地} = a_A - g = 8.75 - 10 = \boxed{-1.25\ \text{m/s}^2}
$$

$$
a_{B地} = a_B - g = -10 - 10 = \boxed{-20\ \text{m/s}^2}
$$

$$
a_{C地} = a_C - g = \boxed{-10\ \text{m/s}^2}
$$

A 对地仍在向下加速，但只有 $1.25\ \text{m/s}^2$，杯子以 $10\ \text{m/s}^2$ 向下加速，A 比杯子掉得慢，相对杯底向上。B 比杯子掉得快，相对杯底向下。C 的对地加速度就是 $-g$，和杯子相同，相对杯底不动。

### 选项 A

**错误。** $a_A = 8.75\ \text{m/s}^2$（向上），$a_B = -10\ \text{m/s}^2$（向下），$a_C = 0$。C 的拉力在 $g_效 = 0$ 时是 $0$，C 没有向下的加速度。

### 选项 B

**错误。** A 向上、C 不动，与 $a_A > 0$、$a_C = 0$ 一致。B 的弹簧处于拉伸，弹力向下，$a_B = -10\ \text{m/s}^2$，B 相对杯底向下。

### 选项 C

**错误。** C 不动与 $a_C = 0$ 一致。A、B 的方向反了：压缩弹簧的弹力向上，$a_A = 8.75\ \text{m/s}^2$；拉伸弹簧的弹力向下，$a_B = -10\ \text{m/s}^2$。

### 选项 D

**正确。** A 向上、B 向下、C 不动，对应 $a_A > 0$、$a_B < 0$、$a_C = 0$。

$$
\boxed{D}
$$

      v.ball(m, xB, p.xB0 + r, r, { ghost: true })
    }

    v.strobe(m, (st) => [xB, st.xB + r], { every: 0.02, kind: 'force' })
    v.strobe(m, (st) => [xC, st.xC + r], { every: 0.02, kind: 'field' })

    v.ball(m, xA, s.xA + r, r, { label: 'A' })
    v.ball(m, xB, s.xB + r, r, { label: 'B' })
    v.ball(m, xC, s.xC + r, r, { label: 'C' })

    v.label(m, xA, -0.055, '铁·原压缩', { size: 11, color: v.color.graphite })
    v.label(m, xB, -0.055, '木·原伸长', { size: 11, color: v.color.graphite })
    v.label(m, xC, -0.055, '木·细线', { size: 11, color: v.color.graphite })

    if (Math.abs(s.accA) > 0.3) {
      v.vec(m, xA + r + 0.012, s.xA + r, 0, s.accA * 0.008, { kind: 'accel', label: 'a_A' })
    }
    if (Math.abs(s.accB) > 0.3) {
      v.vec(m, xB + r + 0.012, s.xB + r, 0, s.accB * 0.008, { kind: 'accel', label: 'a_B' })
    }
    if (p.aCup > 0.2) {
      v.vec(m, 0.50, 0.20, 0, -p.aCup * 0.008, { kind: 'accel', label: 'a_篮' })
    }
    if (cut) {
      v.label(m, 0.50, 0.30, 'g_效 = 0', { color: v.color.accel, size: 12 })
      v.event(m, 0.19, 0.44, '绳子剪断', { at: 0, kind: 'force' })
    }
  },
})

## 五、答案汇总

| 选项 | 判断 |
|---|---|
| A | 错误。C 的相对加速度是 0，细线拉力已变为 0 |
| B | 错误。B 的弹簧在拉，相对杯底向下 |
| C | 错误。A 的弹簧在推，相对杯底向上；B 向下 |
| D | 正确 |

代表性数值下，剪断瞬间（向上为正）：$a_A = 8.75\ \text{m/s}^2$，$a_B = -10\ \text{m/s}^2$，$a_C = 0$，细线拉力 $T = 0$，浮力 $F_浮 = 0$。

选 D。
