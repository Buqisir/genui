## 一、题目条件分析

气体电子放大器的这一局部结构，是两片平行金属薄膜夹着一层绝缘介质，膜上有一排等间距小孔。题目图是相邻两孔的截面：电场线从上方弯进孔里，再从下方散开，左右大致对称；等势线与电场线垂直，在孔口向上下鼓出。

认线和认点可以按下面四条来：

- 金属膜是导体，每一片膜都是等势体。两膜之间有电势差，电场线从电势高的膜指向电势低的膜，在孔口汇聚，出孔后再散开。
- 与电场线垂直、在孔口鼓出的那一族是等势线。d、e、f、g 依次标在从左孔上方绕到右孔的同一条曲线上，四点电势相等。
- a 在左侧一条从下往上穿过孔区的曲线上。这条线与鼓出的等势线垂直，是电场线，沿它电势要改变。
- b 在左孔外侧、电场线较疏处；c 在左孔孔口、电场线较密处。场强大小看疏密。

题目没有给出电压和尺寸。演示把下膜电势取为 0、上膜电势取为 $U$（初始 $100\ \text{V}$），截面坐标的单位取为 $\text{m}$，于是场强读数的单位是 $\text{V/m}$。试探电荷 $q$ 用 $\mu\text{C}$，电场力做功用 $\mu\text{J}$（$1\ \mu\text{C}\times 1\ \text{V} = 1\ \mu\text{J}$）。两孔中心相距 $2.6\ \text{m}$、膜间距 $0.32\ \text{m}$、孔宽 $0.84\ \text{m}$，都只是为了把截面画清楚，不按真实器件比例。电势零点选在下膜，不改变场强、电势差和做功。

绝缘介质的介电常数没有单独设置。导体是等势体、等势线与电场线垂直、沿等势线移动做功为零，这三件事与介电常数无关，四个选项的判断也不依赖它。

## 二、完整解答

静电场里用这三条读图：电场线越密，场强越大；沿电场线方向电势降低；等势线与电场线垂直。把电荷从电势 $\varphi_{\text{初}}$ 移到 $\varphi_{\text{末}}$，电场力做功

$$
W = q(\varphi_{\text{初}} - \varphi_{\text{末}})
$$

### A

**错误。** a 所在的曲线从孔的下方穿到上方，与孔口鼓出的等势线垂直，是电场线。上膜电势高、下膜电势低时，顺着这条线向下电势降低，线上各点电势并不相等，所以它不是等势线。曲线是弯的，不能用来区分这两族线。

### B

**错误。** c 在左孔孔口，电场线挤进孔里，分布比孔外密；b 在左孔外侧，电场线稀疏。场强大小看疏密，因此

$$
E_c > E_b
$$

b 点的电场强度并不比 c 点大。

### C

**错误。** 这里的「电势差的值」指电势差的大小。电势差由两点的电势决定，不由其中一点的场强决定，也不能只看直线距离。

等势线在孔口向外鼓出，孔口的电势会沿着鼓出的等势线延伸到外侧弱场。b 标在通过 c 的等势线落到左孔外、场强已经变小的位置，所以

$$
|\varphi_b - \varphi_c| \approx 0
$$

a 与 c 在穿过左孔的同一条电场线上：c 在上孔口，a 在孔的下侧。沿电场线电势下降，$|\varphi_a - \varphi_c|$ 是两膜电势差里相当大的一部分，比 $|\varphi_b - \varphi_c|$ 大。b、c 间电势差的值并不比 a、c 间的大。

### D

**正确。** d、e、f、g 在同一条等势线上，

$$
\varphi_d = \varphi_e = \varphi_f = \varphi_g
$$

沿这条线从 d 移到 g，电势差为 0。电场力做功

$$
W_{dg} = q(\varphi_d - \varphi_g) = \boxed{0}
$$

静电力做功只看始末电势，与路径弯不弯无关，也与 $q$ 的正负、大小以及两膜电势差 $U$ 无关。$q$ 改为负值时，电场力反向，做功仍然是 0。

四个说法里只有 D 成立。

$$
\boxed{D}
$$

> 易错：看见弯线就当成等势线；看见场强大或两点离得远，就当成电势差大。b 到 c 可以沿着鼓出的等势线走很远，电势几乎不变；a 到 c 顺着电场线穿过孔，电势降了一大截。

## 四、结合图像理解

这是一幅静电场截面，没有时间过程。对照四个选项时看下面几件事。

a 所在的实线穿过虚线等势线，两者垂直。沿实线从孔的上侧走到下侧，电势下降，所以它是电场线，A 不成立。

孔口的电场线比左孔外密。读数给出 $E_c > E_b$。把 $U$ 从 $100\ \text{V}$ 加大，两个场强同比增大，谁大谁小不变，B 不成立。

点「比较电势差」后，通过 c 并伸到 b 的等势线会更清楚。b 在这条鼓出的等势线上，$|U_{bc}|$ 接近 0；a 在电场线的下侧，$|U_{ac}|$ 是两膜电势差里的一大段。C 不成立。$U$ 改变时，这两段电势差里接近 0 的那一段仍然接近 0，另一段随 $U$ 成比例变化。

拖动「从 d 到 g」，电荷依次经过 d、e、f、g，所在虚线上的电势不变，$W$ 保持为 0。把 $q$ 改成负值，$\mathbf F$ 反向，仍然垂直于路径，做功还是 0。作为对照，电荷若从电势高的膜跨到电势低的膜，做功的量级是 $qU$（初始为 $1\ \mu\text{C}\times 100\ \text{V} = 100\ \mu\text{J}$），和图中沿等势线的 $W$ 不是一回事。D 成立，而且不依赖于 $U$ 和 $q$ 取题目里的初始值。
