## 一、题目条件分析

瓶子导热良好，后续过程都进行得很慢，并且瓶子放进恒温水之后没有再取出。因此：

- 状态 1：瓶仍在原来的环境中，$T_1 = 300\ \text{K}$，$V_1 = 1\times 10^3\ \text{cm}^3$。吸管与瓶身相通、上端通大气，管内水面比瓶内水面高 $h$。在瓶内水面这一高度上，管中水柱比大气多压下一段 $\rho g h$，所以气体压强
  $$p_1 = p_0 + \rho g h.$$
- 状态 1 → 状态 2：放进 $T_2 = 303\ \text{K}$ 的恒温水，瓶塞无摩擦地升到瓶口。$h$ 不变，压强就不变，这是等压升温，温度升到 $T_2$。
- 状态 2 → 状态 3：瓶塞锁定，仍浸在同一盆恒温水里，再缓慢吸走一部分水，直到两处水面等高。温度保持 $T_3 = T_2$，压强变为 $p_3 = p_0$。体积变大是因为瓶内水面下降，不是瓶塞再上升。

汇编题干没有写出重力加速度。取高中常用值 $g = 10\ \text{m/s}^2$。这时 $\rho g h = 1.0\times 10^3\ \text{Pa}$，只比大气压高 $1\%$，和温度比 $303/300 = 1.01$ 是同一个因子。按这个压强算出的等温膨胀功约为 $1.015\ \text{J}$，题目给出 $1.02\ \text{J}$，两者一致；下面的功和热量都用题目给出的 $1.02\ \text{J}$、$4.56\ \text{J}$。

表面张力和水蒸气都不计，液柱产生的压强只有 $\rho g h$。

## 二、完整解答

### （1）平均速率和碰壁次数

分子平均速率只由温度决定，$\bar{v}\propto\sqrt{T}$。状态 2 和状态 3 的温度都是 $T_2 = 303\ \text{K}$，所以平均速率

$$\boxed{\text{不变}}$$

单位时间打到单位面积瓶壁上的分子数

$$Z = \frac{1}{4}n\bar{v},$$

$n = N/V$ 是分子数密度。气体没有漏走，$N$ 不变；瓶塞锁定后吸走水，体积变大，$n$ 变小。$\bar{v}$ 又不变，因此

$$\boxed{\text{减小}}$$

用压强看同一件事：$p = nkT$。这段过程 $T$ 不变，$p$ 从 $p_0+\rho g h$ 降到 $p_0$，$n$ 按同样的比例减小，$Z$ 减小。减小的比例就是 $p_3/p_2 = 1/1.01 \approx 0.990$。

### （2）状态 3 的体积

$h = 10\ \text{cm} = 0.10\ \text{m}$，

$$\rho g h = 1.0\times 10^3\times 10\times 0.10 = 1.0\times 10^3\ \text{Pa},$$

$$p_1 = p_2 = p_0 + \rho g h = 1.01\times 10^5\ \text{Pa},\qquad p_3 = p_0 = 1.00\times 10^5\ \text{Pa}.$$

状态 1 → 2 等压：

$$V_2 = V_1\frac{T_2}{T_1} = 1.00\times 10^3\times\frac{303}{300} = 1010\ \text{cm}^3.$$

状态 2 → 3 等温，$p_2 V_2 = p_3 V_3$：

$$V_3 = \frac{p_2}{p_3}V_2 = 1.01\times 1010 = \boxed{1020.1\ \text{cm}^3}.$$

也就是 $1.0201\times 10^{-3}\ \text{m}^3$。

### （3）内能的改变量

中学常用 $\Delta U = Q + W$，其中 $W$ 是外界对气体做的功，气体对外做功时 $W$ 为负。

状态 1 → 2 是等压膨胀。体积增加

$$V_2 - V_1 = 10\ \text{cm}^3 = 10\times 10^{-6}\ \text{m}^3 = 1.0\times 10^{-5}\ \text{m}^3,$$

气体对外做功

$$W_{12,\text{外}} = p_1(V_2-V_1) = 1.01\times 10^5\times 1.0\times 10^{-5} = 1.01\ \text{J}.$$

状态 2 → 3 气体对外做功 $1.02\ \text{J}$（题目给出）。整个过程气体对外做功

$$W_{\text{外}} = 1.01 + 1.02 = 2.03\ \text{J},$$

外界对气体做功 $W = -2.03\ \text{J}$。吸收的热量 $Q = 4.56\ \text{J}$，

$$\Delta U = Q + W = 4.56 + (-2.03) = \boxed{2.53\ \text{J}}.$$

内能增加 $2.53\ \text{J}$。若把 $W$ 记成气体对外做的功，则写成 $\Delta U = Q - W_{\text{外}}$，数值相同。

理想气体的内能只由温度决定。状态 2 → 3 等温，$\Delta U_{23} = 0$，所以这 $2.53\ \text{J}$ 全部发生在状态 1 → 2。由此可以核对热量：

$$Q_{12} = \Delta U + W_{12,\text{外}} = 2.53 + 1.01 = 3.54\ \text{J},$$

$$Q_{23} = W_{23,\text{外}} = 1.02\ \text{J},$$

$$Q_{12}+Q_{23} = 4.56\ \text{J},$$

与题目给的总吸热一致。

> 压强的高低可以用做功核对：状态 2 → 3 气体对外做正功，体积一定变大；等温下体积变大，压强一定变小，所以状态 2 的压强高于 $p_0$，管内水面更高是对的。算功时体积必须先换成立方米，$10\ \text{cm}^3 = 1.0\times 10^{-5}\ \text{m}^3$。

## 四、结合图像理解关键时刻

拖动进度，对照瓶子、$p$–$V$ 图和能量账本。

- **状态 1**（$s=0$）：管内水面更高，标注的 $h=10\ \text{cm}$。气体压强是 $1.0100\times 10^5\ \text{Pa}$，比大气压多出的 $1000\ \text{Pa}$ 就是这段水柱。瓶塞还在瓶颈里。能量三项都是 0。
- **$s$ 从 0 到 1**：温度从 $300\ \text{K}$ 升到 $303\ \text{K}$，压强读数不动，体积从 $1000\ \text{cm}^3$ 增到 $1010\ \text{cm}^3$。图上是一小段水平线，瓶塞升到瓶口；虚线瓶塞是出发位置。平均速率比从 $\sqrt{300/303}\approx 0.995$ 升到 1。账本上内能和对外做功一起增加，到状态 2 时 $\Delta U=2.53\ \text{J}$，$W=1.01\ \text{J}$，吸热 $3.54\ \text{J}$。
- **状态 2**（$s=1$）：瓶塞被瓶口挡住，此后锁定。$h$ 仍是 $10\ \text{cm}$，所以压强仍是 $p_1$。
- **$s$ 从 1 到 2**：温度读数停在 $303\ \text{K}$，平均速率比保持 1。吸水后两处水面靠拢，$h$ 降到 0，压强降到 $1.0000\times 10^5\ \text{Pa}$，体积增到 $1020.1\ \text{cm}^3$。碰壁分子数比从 1 降到约 $0.990$。$p$–$V$ 图沿等温线略向下。账本里代表内能的那一段长度不再变，新增的 $1.02\ \text{J}$ 全部进了对外做功，总吸热成为 $4.56\ \text{J}$。
- 图上两块色分别对应 $W_{12}=1.01\ \text{J}$ 和 $W_{23}=1.02\ \text{J}$。纵横轴都做了放大，色块的几何面积不能直接当成焦耳。
