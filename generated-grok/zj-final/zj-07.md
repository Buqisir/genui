## 一、题目条件分析

图中没有给出电压和长度，判断只靠电场线的方向、疏密和各点所在的导体。

- 电场线从长导体板 b 出发，向上进入上极板，左右两侧弯曲，最外侧绕到手指上。沿电场线方向电势降低，所以 b 的电势高于上极板和手指。
- 下极板贴着 b，和 b 是同一块导体。上极板是单独的一块有厚度的导体。手指也是导体。
- A 在电容器左外侧的弯曲电场线上，那里电场线疏。B 在两极板之间靠下的位置，电场线密。
- C 在上极板上表面左端，D 在同一块上极板的下表面右端。
- 右侧一条电场线从 b 弯到手指，靠手指的一端标 a。E 在这条线上，靠近 a。ab 是曲线。

四个说法里只有一个正确。

## 二、完整解答

### A

**错误。** 电场线越密，场强越大。B 在两极板之间，电场线密；A 在左外侧，电场线疏。因此

$$
E_B > E_A
$$

选项把大小说反了。板间电场线又密又接近平行，可看成匀强电场，场强大约是两板电势差除以间距；外侧电场线散开，场强小得多。

### B

**错误。** B 靠下，紧挨发出电场线的导体板 b，电势高。A 在弯曲电场线已经离开 b、朝低电势的手指或上极板走去的那一段上，电势比 B 低：

$$
\varphi_B > \varphi_A
$$

电子的电势能是 $E_p = -e\varphi$。从 A 移到 B，

$$
\Delta E_p = -e(\varphi_B - \varphi_A) \lt 0
$$

电势能减小。选项说增大，不成立。

正电荷移到电势高的地方，电势能才增大。电子带负电，高低正好相反。比较电势能只看电势，不看 A、B 两处场强谁大。

### C

**正确。** 静电平衡的导体是等势体，表面和内部电势处处相同。C、D 在同一块上极板上，所以

$$
\varphi_C = \varphi_D
$$

$$
\boxed{C}
$$

下表面对着板间密的电场线，上表面附近电场线少，两侧场强可以差很多。场强不同，不改变这块导体上的电势相等。

### D

**错误。** 静电力沿该点电场的切线，没有指向弯曲内侧的分力。电子从 E 点由静止释放后，速度沿切线增加，弯曲的 ab 会把它甩出去。轨迹与电场线重合，要同时满足：电场线是直线，初速度为零或已经沿着这条直线。ab 是曲线，不满足。

E 点的场强沿 ab 指向手指一端 a。电子带负电，受力与场强相反，起动方向朝电势高的 b 一侧，不会顺着箭头走向 a。

    function polyHit(x, y, poly) {
      let inside = false
      let j = poly.length - 1
      for (let i = 0; poly.length > i; i++) {
        const xi = poly[i][0]
        const yi = poly[i][1]
        const xj = poly[j][0]
        const yj = poly[j][1]
        const cross = (yi > y) !== (yj > y)
        if (cross) {
          const xHit = (xj - xi) * (y - yi) / (yj - yi + 1e-12) + xi
          if (xHit > x) inside = !inside
        }
        j = i
      }
      return inside
    }

    function segDist(px, py, ax, ay, bx, by) {
      const dx = bx - ax
      const dy = by - ay
      const L2 = dx * dx + dy * dy || 1e-12
      let u = ((px - ax) * dx + (py - ay) * dy) / L2
      if (0 > u) u = 0
      if (u > 1) u = 1
      return Math.hypot(px - (ax + u * dx), py - (ay + u * dy))
    }

    function edgeDist(x, y, poly) {
      let best = 1e9
      let j = poly.length - 1
      for (let i = 0; poly.length > i; i++) {
        const d0 = segDist(x, y, poly[j][0], poly[j][1], poly[i][0], poly[i][1])
        if (best > d0) best = d0
        j = i
      }
      return best
    }

    function nearSolid(x, y) {
      if (polyHit(x, y, bPts) || polyHit(x, y, uPts) || polyHit(x, y, fPts)) return true

## 四、结合图像理解关键时刻

题图位置下，板间电场线密而接近竖直，左右两侧变疏并弯向手指。b 是高电势，上极板和手指是低电势。

- 选项 A：B 的电场箭头比 A 长，读数满足 $E_B > E_A$。
- 选项 B：等势线越靠近 b，电势越高。B 在板间靠下，A 在左侧弯曲电场线的后段，画面上 $\varphi_B > \varphi_A$。虚线只表示「从 A 移到 B」，不是电场线。电子电势能按 $-e\varphi$ 比较，这次移动电势能减小。
- 选项 C：C、D 读到同一个数，就是这块上极板的电势。下表面板外的场强通常比上表面大，电势仍然相同。
- 选项 D：时刻 0，电子速度为 0，F 已经和电场箭头反向。拖到约 0.75 s，速度沿切线积累，轨迹和弯曲的 ab 分开。进度条上的「偏离」是大约时刻；画面里「已偏离 ab」出现的时刻，是沿着算出的电场积分得到的。
