## 一、题目条件分析

截面上有两族互相交叉的曲线。

- 从上方汇入小孔、孔内最密、到下方又散开的一族是**电场线**。金属膜把电场线挡住，通量只能从孔里挤过去，所以孔内密、孔外疏。箭头指向电势降低的方向，本题图里是自上而下。
- 与它们交叉、大体横向、在孔口附近向上下鼓出的一族是**等势线**。等势线与电场线垂直，彼此也不相交。金属膜是导体，膜表面是等势面。

各点就按题目图的相对位置来读：

- a 在左上方，落在汇入左孔的那条电场线上，不在最上面那条横向等势线上。
- b 在 a 的右上方，落在最上面一条等势线上，那里竖向电场线间距大。
- c 在 b 的下方、贴近左孔孔口，落在更靠近孔的一条等势线上，那里电场线明显变密。b 到 c 之间还隔着别的等势线；a 已经比 b 更靠近孔。
- 左孔下方的 d 和右孔下方的 e 在同一条横向等势线上；g 在 d 的正下方，f 在 e 的正下方，f 与 g 在更下面的同一条等势线上。d 与 g、e 与 f 各沿一条电场线。四点不在同一条曲线上。

原题没有给电势的数值。下面的演示取一组代表性电势，只为了把「哪边大」读成数字：画面外上端电极 $\varphi_H = 100\ \text{V}$，下端 $\varphi_L = 0$，两层金属膜都取 $\varphi_M = 50\ \text{V}$。两层取同一电势，空白缝里几乎没有电场，电场线主要穿过小孔，和题目的图一致。孔上方、孔下方的虚线等势线都按相同间隔

$$
\Delta\varphi = 0.10\,\varphi_H
$$

画出。膜的厚度、孔距和画面外电极的距离**不按比例**。把 $\varphi_H$ 或试探电荷 $q$ 拖离上述取值，读数会按比例变，或功的正负反过来，四个选项的对错不变。

## 二、完整解答

### 选项 A：错误

a 所在的那一族从上方进入左孔，再向孔的另一侧散开，并且和横向曲线交叉。沿电场线方向电势降低，这一族还在孔口变密，用来表示场强变大，所以它是电场线。

等势线彼此不能交叉，也不会连成「钻进小孔、从另一侧散开」的这一族。a 并不在最上面那条横向等势线上。因此 a 点所在的线不是等势线。

### 选项 B：错误

电场线越密，场强越大。b 在最上面一条等势线上，周围竖向电场线间距大；c 贴近左孔孔口，竖向电场线明显变密。所以

$$
E_b < E_c
$$

选项写成「b 比 c 大」，方向反了。

等势线若按相等的电势间隔画出，等势线越密的地方场强也越大。c 比 b 更靠近孔口，等势线也更密，结论相同。

### 选项 C：正确

顺着电场线，电势从上方降到下方。b 在最上面一条等势线上，c 在靠近孔口的一条等势线上，两条之间还隔着别的等势线，因此 $|\varphi_b - \varphi_c|$ 等于这几格间隔之和。

a 不在 b 的那条等势线上，而且已经比 b 更靠近孔：它的电势比 $\varphi_b$ 低，又还没有低到 $\varphi_c$（c 贴在孔口，比 a 更靠前）。a 落在 b、c 之间，从 a 再到 c 跨过的等势线更少：

$$
|U_{bc}| = |\varphi_b - \varphi_c| > |\varphi_a - \varphi_c| = |U_{ac}|
$$

所以 b、c 两点间电势差的值比 a、c 两点间的大。

### 选项 D：错误

d 与 e 在同一条等势线上，$\varphi_d = \varphi_e$；f 与 g 在另一条等势线上，$\varphi_f = \varphi_g$。e 与 f、d 与 g 是电场线，电势沿电场线要变，所以 $\varphi_d \neq \varphi_g$。

静电场做功只看初末位置的电势。取电荷从 d 走到 g：

$$
W_{d \to g} = q(\varphi_d - \varphi_g)
$$

$q \neq 0$ 且 $\varphi_d \neq \varphi_g$，做功不为零。正电荷顺着向下的电场从 d 走到 g 时，做的是正功。

分段看也一样：d→e 沿等势线，位移与电场力垂直，这一段做功为零；e→f 沿电场线，电势下降，做功不为零；f→g 再沿等势线，电势不再变，前面已经做出的功还在。三段加起来不是零。

d→e→f→g 没有回到 d。把 g→d 也走完，才是闭合回路，静电场沿闭合回路的功才一定为零。少掉的那段正好跨着两条等势线。

> **易错点**：把汇入小孔的曲线当成等势线；看见 b 离孔远，却说 b 的场强更大；把 d→e→f→g 看成已经闭合。回路还差 g→d，而 d 和 g 不在同一条等势线上。

### 结论

$$
\boxed{C}
$$

      for (let i = 0; i < raw.length; i++) {
        if (Math.abs(raw[i][0] - cL) < hw * 0.8 && raw[i][1] < yU1 && raw[i][1] > yL0) inHole = true
        if (raw[i][1] > 2.05 && raw[i][0] < cL + 0.4) fromAbove = true
      }
      if (!inHole || !fromAbove) continue
      const hit = onPhi(raw, phiA, function (x, y) {
        return y > yU1 + 0.25 && y < 2.35 && x < cL
      })
      if (hit) {
        aLine = raw
        aPt = hit
        break
      }
    }
    if (!aPt) {
      aLine = getLine(cL - 0.8, 1.65)
      aPt = onPhi(aLine, phiA, function () { return true })
      if (!aPt) aPt = projectPhi(cL - 0.9, 1.6, phiA)
    }

    let bPt = null
    let bBest = 1e9
    const xStart = aPt[0] + 0.25
    const yMinB = aPt[1] + 0.22
    for (let x = xStart; x <= xStart + 2.6; x += 0.25) {
      const hit = projectPhi(x, 2.35, phiB)
      if (hit[1] < yMinB || hit[1] > 2.58) continue
      if (hit[0] < aPt[0] + 0.1) continue
      const em = eMag(hit[0], hit[1])
      if (!isFinite(em) || em <= 0) continue
      if (em < bBest) {
        bBest = em
        bPt = hit
      }
    }
    if (!bPt) bPt = projectPhi(aPt[0] + 0.8, 2.3, phiB)

    let cPt = projectPhi(cL + 0.25 * hw, yU1 + 0.32, phiC)
    if (!(cPt[1] > yU1 - 0.02 && cPt[1] < 1.55 && Math.abs(cPt[0] - cL) < hw)) {
      cPt = projectPhi(cL, yU1 + 0.36, phiC)
    }

    const leftLine = getLine(cL, 0)
    const rightLine = getLine(cR, 0)
    const dPt = onLine(leftLine, cL, phiD, -1.15)
    const gPt = onLine(leftLine, cL, phiG, -2.25)
    const ePt = onLine(rightLine, cR, phiD, -1.15)
    const fPt = onLine(rightLine, cR, phiG, -2.25)

    const dePath = walkPhi(dPt, ePt, phiD, -2.7, yL0 - 0.02)
    const fgPath = walkPhi(fPt, gPt, phiG, -2.7, yL0 - 0.02)
    const efPath = sliceLine(rightLine, ePt, fPt)

    let ss = p.s
    if (ss < 0) ss = 0
    if (ss > 3) ss = 3
    let pos = dPt
    if (ss <= 1) pos = pointAlong(dePath, ss)
    else if (ss <= 2) pos = pointAlong(efPath, ss - 1)
    else pos = pointAlong(fgPath, ss - 2)

    v.label(m, -3.7, yU1 + 0.16, "上膜", { place: "above", size: 12, color: v.color.ink })
    v.label(m, -3.7, yL0 - 0.08, "下膜", { place: "below", size: 12, color: v.color.ink })
    v.label(m, cL, 0, "左孔", { place: "above", size: 11, color: v.color.graphite })
    v.label(m, cR, 0, "右孔", { place: "above", size: 11, color: v.color.graphite })
    v.text(m, -4.85, -2.58, "不按比例", { align: "left", size: 11, color: v.color.graphite })

    if (p.mode === 2 || p.mode === 4) {
      const shown = clipLine(aLine, -0.15, 2.58, -4.8, 0.9)
      if (shown.length > 2) {
        v.path(m, shown, { color: v.color.field, width: p.mode === 2 ? 2.6 : 1.8 })
      }
      if (p.mode === 2) {
        v.label(m, aPt[0], Math.min(aPt[1] + 0.42, 2.3), "电场线", {
          place: "above",
          size: 12,
          color: v.color.field,
        })
      }
    }

    if (p.mode === 3) {
      const eb = eAt(bPt[0], bPt[1])
      const ec = eAt(cPt[0], cPt[1])
      const Eb = Math.hypot(eb[0], eb[1])
      const Ec = Math.hypot(ec[0], ec[1])
      const sc = 0.62 / Math.max(Eb, Ec, 1e-6)
      v.vec(m, bPt[0], bPt[1], eb[0] * sc, eb[1] * sc, { kind: "field" })
      v.vec(m, cPt[0], cPt[1], ec[0] * sc, ec[1] * sc, { kind: "field" })
      let cmpE = "E_b 小于 E_c"
      if (Eb > Ec * 1.02) cmpE = "E_b 大于 E_c"
      else if (Eb > Ec * 0.98) cmpE = "两点场强接近"
      hud(["E_b=" + fmt(Eb) + "   E_c=" + fmt(Ec), cmpE, "单位 V/格，只比大小"], [v.color.field, v.color.ink, v.color.graphite])
    }

    if (p.mode === 5 || p.s > 0.02) {
      if (dePath.length > 1) v.path(m, dePath, { color: v.color.field, width: 2.4, dash: true })
      if (efPath.length > 1) v.path(m, efPath, { color: v.color.field, width: 2.4 })
      if (fgPath.length > 1) v.path(m, fgPath, { color: v.color.field, width: 2.4, dash: true })
      v.line(m, gPt[0], gPt[1], dPt[0], dPt[1], { color: v.color.steel, dash: true, width: 1.2 })
      v.label(m, dPt[0] - 0.08, (dPt[1] + gPt[1]) / 2, "不闭合", {
        place: "left",
        size: 11,
        color: v.color.graphite,
      })
      if (isFinite(pos[0]) && isFinite(pos[1])) {
        v.ball(m, pos[0], pos[1], 0.13, { charge: true, label: p.q >= 0 ? "+q" : "−q" })
      }
    }

    mark(aPt, "a", "left", p.mode === 2 || p.mode === 4)
    mark(bPt, "b", "above", p.mode === 3 || p.mode === 4)
    mark(cPt, "c", "right", p.mode === 3 || p.mode === 4)
    mark(dPt, "d", "left", p.mode === 5)
    mark(ePt, "e", "right", p.mode === 5)
    mark(fPt, "f", "right", p.mode === 5)
    mark(gPt, "g", "left", p.mode === 5)

    if (p.mode === 1) {
      hud(["箭头：电场线", "虚线：等势线", "孔内最密"], [v.color.field, v.color.graphite, v.color.ink])
    } else if (p.mode === 2) {
      hud(["a 的线穿进左孔", "与虚线交叉，是电场线"])
    } else if (p.mode === 4) {
      const pb = safePhi(bPt[0], bPt[1])
      const pa = safePhi(aPt[0], aPt[1])
      const pc = safePhi(cPt[0], cPt[1])
      const Ubc = Math.abs(pb - pc)
      const Uac = Math.abs(pa - pc)
      const cmpU = Ubc > Uac + 0.2 ? "|U_bc| 更大" : "比较这两段电势差"
      hud([
        "φ_b=" + fmt(pb) + "  φ_a=" + fmt(pa) + "  φ_c=" + fmt(pc),
        "|U_bc|=" + fmt(Ubc) + " V   |U_ac|=" + fmt(Uac) + " V",
        cmpU,
      ], [v.color.field, v.color.ink, v.color.field])
    } else if (p.mode === 5) {
      const phiDnow = safePhi(dPt[0], dPt[1])
      const phiGnow = safePhi(gPt[0], gPt[1])
      let phiNow = safePhi(pos[0], pos[1])
      if (ss <= 1) phiNow = phiDnow
      if (ss >= 2) phiNow = phiGnow
      const dPhi = phiDnow - phiNow
      const W = p.q * dPhi
      let segName = "d→e 等势线"
      if (ss > 1 && ss <= 2) segName = "e→f 电场线"
      if (ss > 2) segName = "f→g 等势线"
      let judge = "Δφ ≠ 0，做功不为零"
      if (Math.abs(p.q) < 1e-9) judge = "q = 0，电场力为零"
      else if (Math.abs(dPhi) < 0.4) judge = "Δφ = 0，做功为零"
      hud([segName, "φ=" + fmt(phiNow) + " V", "W=" + fmt(W) + " J", judge], [v.color.ink, v.color.field, v.color.charge, v.color.ink])
    }
  },
})

## 四、结合图像理解关键状态

全图里先分清两族线：箭头向下、汇入两个孔并且孔里最密的是电场线；和它们交叉的虚线是等势线。上方虚线疏、孔口虚线密，和电场线的疏密一致。

- 选项 A：加粗的是过 a 的那条线。它从上方下来，向右下弯进左孔，中途穿过好几条虚线。能和虚线交叉、又能钻过小孔的是电场线。
- 选项 B：b 的箭头短，c 的箭头长，右上角 $E_b < E_c$。c 旁边的电场线也更密。把 $\varphi_H$ 拖开，两个场强一起放大或缩小，大小关系不变。
- 选项 C：右上角 $\varphi_b > \varphi_a > \varphi_c$，所以 $|U_{bc}| > |U_{ac}|$。b 到 c 之间能看见两格虚线间隔，a 到 c 不到这么多。这就是 C 正确的原因。
- 选项 D：进度停在 e 时，电荷还贴着 d、e 那条虚线，功是 0。一过 e，电荷沿实线电场线下行，功离开 0。f→g 再回到虚线上，功保持这个不为零的值，直到 g。左侧虚线标着「不闭合」：差的那一段 g→d 没有走。把 $q$ 改成负号，功的正负反过来，但停在 e 时仍是 0，到达 g 时仍不是 0。

## 五、答案汇总

| 选项 | 判断 |
| --- | --- |
| A | 错误。a 所在的线是电场线 |
| B | 错误。c 处电场线更密，$E_b < E_c$ |
| C | 正确。a 的电势介于 b、c 之间，$\lvert U_{bc}\rvert > \lvert U_{ac}\rvert$ |
| D | 错误。路径停在 g，初末电势不同，做功不为零 |

本题为单选，选 C。
