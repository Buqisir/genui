## 一、题目条件分析

机器人可视为质点，船和机器人都保持静止，所以机器人加速度为零，所受合力为零。它只受四个力：

- 重力 $G$：竖直向下。
- 磁力 $F$：垂直壁面，指向壁面（磁铁把机器人吸在外壁上）。
- 支持力 $F_N$：垂直壁面，指向船体外侧，离开壁面。
- 摩擦力 $F_f$：沿壁面指向斜上方。壁面是斜的，机器人有沿壁面滑向水面的趋势，静摩擦力沿壁面向上。

$\theta$ 是壁面与**竖直**方向的夹角，不是与水平方向的夹角。磁力垂直壁面，沿壁面方向没有分力。

题目只给字母、不给数值。下面的读数取一组代表性数值：$G = 20\ \text{N}$，$\theta = 30^\circ$。支持力的大小题目没有给出，平衡只能确定 $F - F_N$，这里另取 $F_N = 15\ \text{N}$（大于零，表示机器人确实压在壁面上）用来对照 B、D。滑块回到初值时，界面上的「题目原值」指的就是这组代表性初值。

## 二、完整解答

### 正交分解

壁面与竖直方向成 $\theta$，与水平方向的夹角就是 $90^\circ - \theta$。

取沿壁面向上为 $x$ 轴正方向，垂直壁面指向外侧（与 $F_N$ 同向）为 $y$ 轴正方向。重力竖直向下，它和「沿壁面向下」之间的夹角就是 $\theta$，因此

$$
G_x = -G\cos\theta, \qquad G_y = G\sin\theta.
$$

$\theta = 0$ 时壁面竖直，$G$ 全部沿壁面向下，$y$ 方向分力为零；$\theta$ 增大后，壁面向外侧倒，沿壁面的分力变小，指向外侧、想把机器人从壁面上揭下来的分力变大。

$F$ 与 $F_N$ 都垂直壁面，只有 $y$ 分量；$F_f$ 沿壁面，只有 $x$ 分量。静止时

$$
\sum F_x = F_f - G\cos\theta = 0
$$

$$
\sum F_y = F_N + G\sin\theta - F = 0
$$

$$
F_f = \boxed{G\cos\theta}, \qquad F - F_N = \boxed{G\sin\theta}.
$$

用「与水平方向夹角」复核：令 $\alpha = 90^\circ - \theta$，沿壁面的分力为 $G\sin\alpha = G\cos\theta$，垂直壁面的分力大小为 $G\cos\alpha = G\sin\theta$。机器人和放在斜面顶上的物块不同：它贴在外壁外侧，这个垂直分力指向离开壁面的一侧，所以是 $F = F_N + G\sin\theta$，而不是 $F_N = G\sin\theta$。

代表性数值 $\theta = 30^\circ$、$G = 20\ \text{N}$：

$$
F_f = 20\cos 30^\circ = 20\times\frac{\sqrt{3}}{2} = 10\sqrt{3} \approx \boxed{17.32\ \text{N}}
$$

$$
F - F_N = 20\sin 30^\circ = \boxed{10\ \text{N}}
$$

再取题目未给出的 $F_N = 15\ \text{N}$，则 $F = 25\ \text{N}$。下面四个选项都用这组数判断；换成别的 $\theta$ 和别的正的 $F_N$，对错不变。

### A. $F_f = G$

错误。沿壁面平衡给出的是 $F_f = G\cos\theta$。$\theta = 30^\circ$ 时 $F_f = 17.32\ \text{N}$，$G = 20\ \text{N}$，两者不相等。只有壁面竖直（$\theta = 0$）时 $\cos\theta = 1$，A 才成立，它不是一般关系。

### B. $F = F_N$

错误。垂直壁面方向还有指向外侧的 $G\sin\theta$，平衡式是 $F = F_N + G\sin\theta$。$\theta = 30^\circ$、$F_N = 15\ \text{N}$ 时 $F = 25\ \text{N}$，$F_N = 15\ \text{N}$。只有 $\theta = 0$ 时这个分力为零，B 才成立。

### C. $F_f = G\cos\theta$

正确。这就是沿壁面方向的平衡方程。$F$ 和 $F_N$ 都垂直壁面，磁力多大（只要机器人仍停在壁面上）都不进入这个方程，摩擦力只由 $G$ 和 $\theta$ 决定。$\theta = 30^\circ$、$G = 20\ \text{N}$ 时两边都是 $17.32\ \text{N}$。

### D. $F = G\sin\theta$

错误。$G\sin\theta$ 等于的是 $F$ 与 $F_N$ 的差，不是 $F$。$\theta = 30^\circ$ 时 $G\sin\theta = 10\ \text{N}$，而 $F = 25\ \text{N}$。只有再把 $F_N$ 调成 $0$ 时等号才碰巧成立；题目已经列出支持力，而且没有给出它的大小，所以 D 不是必然成立的关系。

$$
\boxed{\text{C}}
$$

易错点：把 $\theta$ 当成壁面与水平方向的夹角，套「沿斜面分力 $= G\sin\theta$」，会算出 $F_f = 10\ \text{N}$。$10\ \text{N}$ 其实是 $G\sin\theta$，也就是 $F - F_N$，和摩擦力不是同一个量。

## 四、结合图像理解

看 $\theta = 30^\circ$ 这一条竖线：$F_f$ 在 $17.32\ \text{N}$，水平虚线 $G$ 在 $20\ \text{N}$，所以 A 不成立；$G\sin\theta$ 在 $10\ \text{N}$。$F_N = 15\ \text{N}$ 时磁力曲线在 $25\ \text{N}$，既不等于 $F_N$，也不等于 $10\ \text{N}$，B 和 D 都不成立。$F_f$ 的实线写的就是 $G\cos\theta$，C 成立。

把夹角收到 $\theta = 0$：壁面竖直，$F_f$ 与 $G$ 交在一起，$G\sin\theta = 0$，于是 $F = F_N$。A、B、C 同时成立，D 仍把 $F$ 说成 $0$。这只是竖直壁面的特殊情形。

把支持力收到 $0$、夹角仍留在 $30^\circ$：$F$ 的曲线落到 $G\sin\theta$ 上，D 在数值上碰巧成立，但题目中的机器人受支持力，不能把这个极限当成选项。无论 $F_N$ 取多少，$F_f$ 的实线都不动——沿壁面的方程里没有磁力和支持力。

$\theta$ 从 $0^\circ$ 增到 $60^\circ$ 时，$F_f = G\cos\theta$ 下降，$G\sin\theta$ 上升，磁力必须比支持力多出越来越大的一截，机器人越靠磁力贴在向外倒的壁面上。

## 五、答案汇总

| 项目 | 结果 |
|---|---|
| 选项 | C |
| 沿壁面 | $F_f = G\cos\theta$ |
| 垂直壁面 | $F - F_N = G\sin\theta$ |
| 代表性数值下的 $F_f$（$G = 20\ \text{N}$，$\theta = 30^\circ$） | $17.32\ \text{N}$ |
| 代表性数值下的 $F - F_N$ | $10\ \text{N}$ |
