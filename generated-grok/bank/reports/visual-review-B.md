- gd21-17 弹簧振子：t = 0 从 y = −A 释放；T/8 的点在 y = −A/2 下方，T/6 到达 −A/2，T/4 过平衡位置动能最大。最低点弹力 2.20 N 向上、重力 2.00 N 向下，合力向上，a ≈ 0.99 m/s²，与 A = 0.10 m、T = 2.0 s、m = 0.20 kg 相符。

- gd22-01 石磨：∠AOB = 60° 画在两绳之间，F 向上 17.32 N，F_1 = F_2 = 10 N 沿绳斜向下，水平分力相消，表盘停在 √3 ≈ 1.73（选项 D）。

## 共性

1. 游标读数用固定小数、不用科学计数。gd21-15 把 6×10^{-21} J 打成 0.00 J，gd22-04 把 0.004 Wb 打成 0.00 Wb。曲线位置往往是对的，图例数字是错的，而且正好打在学生会抄的那个数上。
2. 场区标签按「多边形最高点」自动上抛，扇形区域的 Ⅰ、Ⅱ、Ⅲ 和 E 会离开色块，再和手写标签叠成两套。gd21-14 最明显。
3. 坐标图不设上限时，厘米级位移会被收成 0–1 m，线贴在轴上。gd21-13 的位置图就是这样；速度图因为数值到 0.4，还能看。
4. Sim 一加载就播放，时间轴上 t = 0 的标记文案会留在画面上。标记如果写成物理结论（gd22-04 的「e_1 = 0」），播过之后就和读数打架。标记如果只是事件名（「拨出甲」「积木释放」），问题不大。
5. 套受力图组件时，导杆上的算珠被画成地面上的球。这道题里力的方向和 μmg 是对的，装置不像，学生要靠旁边的文字才知道摩擦来自导杆。
