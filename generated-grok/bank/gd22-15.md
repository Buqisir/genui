## 一、题目条件分析

- 空调把热量从室内送到室外，而且室内温度低于室外。
- 自发过程是不靠外界做功、系统自己就能进行的过程。热量自发流动的方向是从高温物体到低温物体。
- 题目写明这个过程消耗了电能，电能就是外界对空调做的功。
- 两个空都填文字。原卷没有温度和热量的数值。下文用一组符合题意的代表性数值把数量关系算清楚，滑块初值就是这组数：室内 \(T_c = 300\ \text{K}\)（27 ℃），室外 \(T_h = 310\ \text{K}\)（37 ℃），从室内吸收 \(Q_c = 3000\ \text{J}\)，消耗电能 \(W = 500\ \text{J}\)。滑块轨道上的「题目原值」指的是这组演示初值。

## 二、完整解答

### （1）是不是自发过程

热力学第二定律的克劳修斯表述：热量不能自发地从低温物体传到高温物体而不引起其他变化。

这里热量从较低的室内温度传到较高的室外温度，同时空调消耗电能。消耗电能就是伴随的其他变化，过程要靠外界做功才能进行。第一空填

$$\boxed{\text{不是}}$$

### （2）排放的热量和吸收的热量

取空调为系统。它完成一个工作循环后回到原来的状态，内能不变。一个循环里有三笔能量：

- 从室内吸收热量 \(Q_c\)；
- 消耗电能 \(W\)，即外界对空调做功 \(W\)；
- 向室外放出热量 \(Q_h\)。

能量守恒写成

$$Q_c + W = Q_h$$

电能若留在空调内部，内能会越积越高，系统回不到初状态。一个完整循环里，这份电能也要变成热，和从室内吸收的热量一起排到室外。题目已经说明消耗了电能，\(W > 0\)，所以

$$Q_h - Q_c = W > 0$$

第二空填

$$\boxed{\text{大于}}$$

### （3）用代表性数值核对

$$Q_h = Q_c + W = 3000 + 500 = \boxed{3500\ \text{J}}$$

$$Q_h - Q_c = \boxed{500\ \text{J}}$$

把室内、室外看成两个恒温热源，再核算总熵变。空调循环回到初态，自身熵变为 0。热源熵变按吸热为正：

$$\Delta S = -\frac{Q_c}{T_c} + \frac{Q_h}{T_h} = -\frac{3000}{300} + \frac{3500}{310} = \frac{40}{31} = \boxed{1.29032\ \text{J/K}}$$

\(\Delta S > 0\)，过程可以进行。温度必须用开尔文。

若 \(W = 0\)，则 \(Q_h = Q_c\)，

$$\Delta S = Q_c\left(\frac{1}{T_h} - \frac{1}{T_c}\right) < 0$$

总熵减少，第二定律不允许。这就是第一空「不是」的定量含义：不消耗电能时，热量不能从室内传到室外。

总熵变刚好为零的可逆极限，对应最少电能

$$W_{\min} = Q_c\frac{T_h - T_c}{T_c} = 3000 \times \frac{10}{300} = \boxed{100\ \text{J}}$$

这时 \(Q_h = 3100\ \text{J}\)，仍然大于 \(Q_c\)。实际空调还有摩擦等不可逆因素，消耗的电能多于 \(W_{\min}\)，总熵增加更多，排到室外的热量也更大。

这组演示值的制冷系数 \(\varepsilon = Q_c / W = 6\)，同温度的卡诺制冷系数 \(\varepsilon_C = T_c / (T_h - T_c) = 30\)。实际制冷系数低于卡诺制冷系数，与第二定律相符。

第二空只由能量守恒决定：只要 \(W > 0\)，就有 \(Q_h > Q_c\)。第二定律另外要求电能至少达到 \(W_{\min}\)，过程才真能发生。题目说空调已经把热量送到了室外，消耗的电能一定覆盖了这个下限，室外收到的热量只会更大。

易错提醒：第二空若填「等于」，就是漏掉了最终也要排走的电能。空调是制冷机，电能从外界输入，\(Q_h = Q_c + W\)。热机是对外做功，放热小于吸热，那套大小关系不能套到空调上。

三条竖线对应三个关键状态。

- \(W = 0\)：两条热量线重合，\(Q_h = Q_c\)。总熵变为负，热量不能自发地从室内传到室外。第一空因此填「不是」。
- \(W = W_{\min}\)（演示初值下是 \(100\ \text{J}\)）：总熵变为 0，过程处在可逆极限。排放热量已经比吸收热量多出 \(W_{\min}\)。
- \(W = 500\ \text{J}\)：演示中的正常制冷。总熵变约为 \(1.29\ \text{J/K}\)，过程可以发生。\(Q_h = 3500\ \text{J}\)，比 \(Q_c = 3000\ \text{J}\) 多 \(500\ \text{J}\)，多出的就是消耗的电能。第二空因此填「大于」。

拖动电能时，吸收热量那条虚线不动，排放热量的实线以斜率 1 上升，高度差始终等于 \(W\)。只要电能大于 0，排放热量就大于吸收热量；电能还要越过 \(W_{\min}\)，熵变曲线才到横轴上方，过程才被允许。

## 五、答案汇总

| 空 | 答案 |
|---|---|
| 这个过程是不是自发过程 | 不是 |
| 排放到室外的热量与从室内吸收的热量相比 | 大于 |

演示初值 \(T_c = 300\ \text{K}\)、\(T_h = 310\ \text{K}\)、\(Q_c = 3000\ \text{J}\)、\(W = 500\ \text{J}\) 下的核算：\(Q_h = 3500\ \text{J}\)，\(Q_h - Q_c = 500\ \text{J}\)，\(W_{\min} = 100\ \text{J}\)，\(\Delta S = 1.29032\ \text{J/K}\)。
