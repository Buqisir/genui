## 一、题目条件分析

- 高压电源画在装置上方：长线在左，是正极，接到发射极；短线在右，是负极，接到吸极。两极之间是强电场，虚线是等差等势面。
- 一带电液滴从发射极加速飞向吸极。a、b 是路径上的两点，a 在左、b 在右。液滴重力不计。
- 通过 a 的等势面更靠近发射极，弯曲得更厉害；通过 b 的更靠近吸极，弯曲较缓。a 附近的虚线比 b 附近更密。
- 题目只给极性、路径和等势面的疏密，没有电压、距离、电荷和质量。选项的对错由这些事实决定。下面交互里的数字是另行取的代表性数值，用来把大小关系显示出来。

## 二、完整解答

液滴只受电场力。先由电源确定电场方向和电荷正负，再逐项判断。

长线为正极、短线为负极，所以发射极电势高、吸极电势低。电场由高电势指向低电势，沿路径向右。液滴向右加速，电场力必向右，与电场同向，因此液滴带正电。

### 选项 A

**错误。** a 点的电势比 b 点高。

顺着电场方向电势降低。a 在 b 左侧，更靠近正极，所以

$$\boxed{\varphi_a > \varphi_b}$$

选项写成“a 点的电势比 b 点的低”，判断反了。

### 选项 B

**错误。** a 点的电场强度比 b 点大。

图中虚线按等差等势面来读：相邻两条之间电势差相同，画得越密，电势降落越快，场强越大。题图写明 a 附近比 b 附近更密，所以

$$\boxed{E_a > E_b}$$

选项说 a 点场强更小，判断反了。

### 选项 C

**错误。** 液滴在 a 点的加速度比在 b 点大。

重力不计，合力就是电场力，q 与 m 在飞行中不变：

$$a = \frac{qE}{m}$$

$E_a > E_b$ 且 $q > 0$，加速度都向右，大小满足

$$\boxed{a_a > a_b}$$

选项说 a 点加速度更小，判断反了。

### 选项 D

**正确。** 液滴在 a 点的电势能比在 b 点大。

液滴带正电，电势能 $E_p = q\varphi$。由 $\varphi_a > \varphi_b$ 得

$$\boxed{E_{p,a} > E_{p,b}}$$

功能关系给出同一结论，而且不再依赖把 $\varphi$ 的数值算出来：从 a 到 b，电场方向不变，电场力一直向右，做正功，速率增大，动能增大。只有电场力做功，电势能的减少等于动能的增加，所以 a 点电势能更大。

若把液滴误当成负电荷，$E_p = q\varphi$ 的不等号会反过来；但负电荷在这个电场里会被拉回发射极，不可能向吸极加速。电源极性排除了这种画法。

四个选项里只有 D 成立：

$$\boxed{D}$$

容易看反的三处：等势面的疏密表示场强，不表示电势高低；比较电势能之前要先确定电荷正负；正极在发射极一侧，电场指向吸极，a 的电势高于 b。

## 三、交互演示

题目没有数值。下面取一组代表性数据，只为把不等号画成读数；真实液滴的电荷和质量远小于这里的取值，外形也不按比例。

把发射极尖端等效成位于喷口左侧 $d = 0.10\ \text{m}$ 处的正点电荷，记 $K = kQ = 80\ \text{V}\cdot\text{m}$。喷口在 $x = 0$，吸极缝在 $x = L = 0.50\ \text{m}$，a 固定在 $x_a = 0.10\ \text{m}$，b 的初始位置 $x_b = 0.30\ \text{m}$。轴上到等效电荷的距离 $r = x + d$，则

$$\varphi = \frac{K}{r},\qquad E = \frac{K}{r^2}$$

$E$ 沿轴指向右，与“背离正电荷”以及“由高电势指向低电势”一致。液滴取 $q = 2\times 10^{-6}\ \text{C}$、$m = 0.02\ \text{kg}$，从喷口由静止释放。加速度由 $a = qE/m$ 积分得到，不把重力算进去。

初始参数下：

$$\varphi_a = \frac{80}{0.20} = 400\ \text{V},\qquad \varphi_b = \frac{80}{0.40} = 200\ \text{V}$$

$$E_a = \frac{80}{0.04} = 2000\ \text{V/m},\qquad E_b = \frac{80}{0.16} = 500\ \text{V/m}$$

$$a_a = \frac{qE_a}{m} = 0.20\ \text{m/s}^2,\qquad a_b = \frac{qE_b}{m} = 0.05\ \text{m/s}^2$$

$$E_{p,a} = q\varphi_a = 8.0\times 10^{-4}\ \text{J} = 800\ \mu\text{J},\qquad E_{p,b} = 400\ \mu\text{J}$$

比例是 $\varphi_a:\varphi_b = 2:1$，$E_a:E_b = a_a:a_b = 4:1$，电势能之比也是 $2:1$。喷口处 $\varphi_0 = K/d = 800\ \text{V}$。由动能定理

$$v = \sqrt{\frac{2q(\varphi_0 - \varphi)}{m}}$$

经过 a、b 时速率分别约为 $0.28\ \text{m/s}$ 和 $0.35\ \text{m/s}$。动画里的速度由电场力积分，应与这两个值相同。

等势面画成以等效电荷为圆心的圆弧，用来复现题图里“越靠近发射极越密、弯曲越厉害”。吸极极板会改变真实等势面的形状，这里没有把极板上的感应电荷算进去；轴上仍然是电势向右降低、场强向右变小。b 的滑块限制在 a 的右侧，四个不等号不会颠倒。

## 四、结合图像理解关键时刻

进度条上有四个时刻。初始参数下可以这样看：

- **出发：** 速率为 0，电势 800 V，电势能 1600 μJ。能量账本第一行只有电势能。受力图上的电场力最大，为 $1.6\times 10^{-2}\ \text{N}$，方向向右。
- **经过 a：** 电势 400 V，场强 2000 V/m，加速度 0.20 m/s²，电势能降到 800 μJ。v–t 图在这里仍比较陡。画面上 E_a 的箭头是后面 E_b 的 4 倍。
- **经过 b：** 电势 200 V，场强 500 V/m，加速度 0.05 m/s²，电势能 400 μJ。速率约为 0.35 m/s，大于经过 a 时的约 0.28 m/s。多出来的动能等于减少的 400 μJ，总机械能仍是 1600 μJ。v–t 图这里更平，所以加速度更小，选项 C 不成立。
- **到达吸极缝：** 动画停在缝口，只表示题目路径看到这里为止，不是液滴被极板撞停。此时电势降到约 133 V，速率比 b 点还大一点。

四张图和受力图分别对着四个选项：电势曲线否定 A，场强曲线否定 B，v–t 图的斜率加上受力图否定 C，能量账本肯定 D。点「核对选项 D」可回到 a 点，并在账本里直接看 a、b 两行的电势能。

## 五、答案汇总

| 选项 | 判断 | 要点 |
| --- | --- | --- |
| A | 错误 | 沿电场方向电势降低，$\varphi_a > \varphi_b$ |
| B | 错误 | a 附近等差等势面更密，$E_a > E_b$ |
| C | 错误 | $a = qE/m$，所以 $a_a > a_b$ |
| D | 正确 | 液滴带正电，$E_{p,a} > E_{p,b}$；从 a 到 b 动能增加 |

答案：D。
