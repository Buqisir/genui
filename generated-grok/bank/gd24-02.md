## 一、题目条件分析

核反应方程是

$$
\mathrm{Y} + {}^{243}_{95}\mathrm{Am} \rightarrow {}^{A}_{119}\mathrm{X} + 2\,{}^{1}_{0}\mathrm{n}
$$

高中阶段核反应方程用两条守恒：

- **电荷数守恒**：电荷数等于质子数。中子 ${}^{1}_{0}\mathrm{n}$ 的电荷数是 0。
- **质量数守恒**：质量数等于核子数。每个中子的质量数是 1。质量数守恒说的是核子个数，不是静止质量分毫不差。

方程里已经写明的数：

| 核 | 质量数 | 电荷数 |
|---|---|---|
| 镅 ${}^{243}_{95}\mathrm{Am}$ | 243 | 95 |
| 生成核 ${}^{A}_{119}\mathrm{X}$ | $A$（待定） | 119 |
| 两个中子 | 每个 1 | 每个 0 |
| 入射核 Y | 待定 | 待定 |

四个选项是四组候选 $(Y,\ A)$，不是四次不同的实验。选项已经给出元素符号：电荷数 26 是铁 Fe，电荷数 24 是铬 Cr。计算只用电荷数和质量数，元素名称不另代入数。

加速器的束流能量、靶的厚度题目都没有给，求的是反应方程里的 $Y$ 和 $A$，与这些装置参数无关。

## 二、完整解答

### 电荷数守恒

中子电荷数为 0，所以

$$
Z_Y + 95 = 119 + 2 \times 0
$$

$$
Z_Y = 119 - 95 = \boxed{24}
$$

电荷数必须是 24。选项里只有 ${}^{54}_{24}\mathrm{Cr}$ 的电荷数是 24，铁的电荷数是 26，A、B 两项因此不能成立。对应的质量数是选项所写的

$$
A_Y = \boxed{54}
$$

### 质量数守恒

两个中子一共带走质量数 2：

$$
A_Y + 243 = A + 2 \times 1
$$

$$
A = A_Y + 243 - 2 = A_Y + 241
$$

把 $A_Y = 54$ 代入：

$$
A = 54 + 243 - 2 = \boxed{295}
$$

两侧再对一次总账：反应前质量数 $54 + 243 = 297$，反应后 $295 + 2 = 297$。电荷数两侧都是 $24 + 95 = 119$。

正确选项是 $\boxed{\text{C}}$。

### 逐项判断

**A. 错误。** $Y$ 为 ${}^{58}_{26}\mathrm{Fe}$，$A = 299$。

电荷数：左侧 $26 + 95 = 121$，右侧 $119 + 2 \times 0 = 119$。$121 \neq 119$，电荷数不守恒。

质量数：左侧 $58 + 243 = 301$，右侧 $299 + 2 = 301$。质量数守恒。

只满足质量数，这一项不成立。$121$ 与 $119$ 正好差 2：若把每个中子的电荷数误写成 1，就会得到 $Z_Y + 95 = 119 + 2$，从而 $Z_Y = 26$，质量数却仍是 299。这就是把中子写成 ${}^{1}_{1}\mathrm{n}$ 时会落到的选项。

**B. 错误。** $Y$ 为 ${}^{58}_{26}\mathrm{Fe}$，$A = 301$。

电荷数同样是 $121 \neq 119$，不守恒。

质量数：左侧 $58 + 243 = 301$，右侧 $301 + 2 = 303$。$301 \neq 303$，质量数也不守恒。

电荷数、质量数都不成立。它在 A 的错误之外，又把两个中子的质量数留在了生成核上。

**C. 正确。** $Y$ 为 ${}^{54}_{24}\mathrm{Cr}$，$A = 295$。

电荷数：左侧 $24 + 95 = 119$，右侧 $119$。相等。

质量数：左侧 $54 + 243 = 297$，右侧 $295 + 2 = 297$。相等。

两条守恒同时成立。

**D. 错误。** $Y$ 为 ${}^{54}_{24}\mathrm{Cr}$，$A = 297$。

电荷数：$24 + 95 = 119$，守恒。

质量数：左侧 $54 + 243 = 297$，右侧 $297 + 2 = 299$。$297 \neq 299$，质量数不守恒。

右边多出来的 2 就是两个中子的质量数。若直接把 $A$ 写成 $54 + 243 = 297$，等于没有减去中子带走的核子。

> 两条守恒要分开算。中子是 ${}^{1}_{0}\mathrm{n}$：下面的 0 才进电荷数，上面的 1 才进质量数。把 1 当成电荷数会得到铁、$A = 299$（选项 A）；电荷数算对、却漏减两个中子，会得到铬、$A = 297$（选项 D）。

## 四、结合图像理解关键时刻

这道题没有运动过程，图上要看的不是某一时刻，而是两个候选质量数处，质量数直线和选项所填的 $A$ 是否重合，以及电荷数是否同时等于 119。

质量数守恒把生成核的质量数锁在直线上：

$$
A = A_Y + 241
$$

$A_Y = 54$（铬）时，直线给出 $A = 295$；$A_Y = 58$（铁）时，直线给出 $A = 299$。选项 A 的 $299$ 正好落在铁的那一点上，所以只看质量数会觉得 A 对；再看电荷数 $26 + 95 = 121 \neq 119$，这一点就被排除。选项 D 的入射核质量数也是 54，但填写的 $297$ 比直线高出 2，高出的就是两个中子。
