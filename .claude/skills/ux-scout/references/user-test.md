# 真人测试单

我们自己（主会话和用户）看不出的问题，要靠真人测试。下面的测试单直接交给用户去安排。

## 学生出声思考（5 人，每人约 25 分钟）

**找谁**：高一、高二学生，没学过或刚学过这节课的内容。5 个人能发现大部分可用性问题（Nielsen 和 Landauer，1993）。

**准备**：
- 一台电脑、一部手机；
- 录屏，带声音；
- 方案的页面链接，页内切换按钮先藏起来，每人随机先用其中一个方案。

**说给学生听**："我们在测这个页面，不是测你。做的时候把想到的都说出来，卡住了也说。"

**任务**（按这次调研的题目改）：
1. 从头上到第 3 幕结束，中间不提示。
2. 遇到要选的题，先说你会去哪里找答案。
3. 上完问："刚才学到的结论，你在页面上哪里能再找到？"

**记录**（每人一张表）：

| 记什么 | 怎么记 |
|---|---|
| 每个停点从出现到作答用了多少秒 | 看录屏 |
| 找不到该点哪里的次数 | 学生说"在哪"、鼠标乱晃超过 3 秒，都算一次 |
| 看错画面或读错数的次数 | 听学生说的 |
| 结论能不能复述，能不能在页面上找到 | 课后问 |
| 原话 | 抄下来，好的坏的都抄 |

**结果怎么用**：两个方案逐项对比；有 2 人以上卡在同一处的，就是要改的问题。

## 老师投影试课（1 人）

- 教室投影，学生坐最后一排，看最小的字和画面里的读数能不能看清。
- 老师用遥控笔或键盘推进，看推进方式顺不顺手。
- 问老师：哪一步想停下来讲，界面有没有给留出地方。

## 上线后能看的数据（以后接上统计再用）

- 每个停点第一次就答对的比例，和错两次后才给答案的比例；
- 每步停留的时间；
- 小测（第 7 幕）的得分，两种方案对比。
