# 真人测试单

盲评和模拟走查都是模型输出，只能算弱证据。规格里标"待真人测试"的决定，要靠下面三份测试单。直接交给用户去安排；做完把结果交给主会话，回填证据表（做完后怎么标，由用户定，见 `templates.md`）。

三份各管一类问题：

| 测试 | 回答什么 | 人数 |
|---|---|---|
| 学生出声思考 | 学生在每一步想什么？错误想法是不是规格写的那样？ | 5 |
| 老师审读 | 物理和教学上有没有错？第七节清单老师同意吗？课堂上会怎样？ | 2～3 |
| 前后测加延迟测 | 学完真的会了吗？错误想法被推翻了吗？一周后还在吗？ | 一个班或更多 |

## 一、学生出声思考（5 人，每人约 25 分钟）

**找谁**：高一、高二学生，没学过或刚学过这节课的内容；水平有高有低，不要全找尖子。5 个人能发现大部分问题（Nielsen 和 Landauer，1993，只读摘要）。

**准备**：
- 一台电脑，课件的页面链接；
- 录屏，带声音；
- 规格里的错误想法清单和题目表，打印出来，**主持人带着，不给学生看**；
- 一张记录表（下面）。

**主持人话术**（照念，不要即兴发挥）：

> 今天我们在测这节课，不是测你。没有对错，你答错了对我们反而有用。
> 做的时候，把你想到的都说出来，包括"我不确定""我猜是……"。卡住了也说。
> 每遇到一个要选的题，选之前先说你想选哪个、为什么。
> 我会安静地看，大部分时候不会回答你的问题。这不是不礼貌，是因为我们要看没有人帮忙的时候会怎样。
> 你可以随时说"不想做了"。

**任务**（按这节课改）：
1. 从头上到规格里指定的那一幕（通常是建构段结束），中间不提示。
2. 每个停点，先说想选什么、理由，再提交。
3. 做完问（结束访谈）：
   - 这节课的核心问题，用你自己的话说，答案是什么？
   - 刚学到的结论，你在页面上哪里能再找到？
   - 哪一步你觉得最难、最没听懂？哪一步觉得在浪费时间？
   - 有没有哪个问题你觉得"这不是在问我"？
   - 在不看页面的情况下，把这节课的结论说三条。

**不许提示的规矩**：
- 学生问"对吗？"：答"你怎么看？"。
- 学生沉默超过 10 秒：只问"你现在在想什么？"。不要问"是不是在想……"。
- 学生选了错误选项：不点头、不皱眉、不说"再想想"。课件自己的反馈和提示按钮不算提示，由学生自己点。
- 只有技术故障（页面打不开、按钮没反应）可以出手帮，并在表里记一笔。
- 不解释题目；学生问"这个词什么意思"：答"你的理解是什么"，记下这个词。
- 不在学生做完前讲规格里的意图。

**记录表**（每人一张）：

| 步 | 停点 | 第一次选了什么 | 理由（原话） | 对应规格哪条错误想法（C#，没有就写"无"） | 改答了吗、改成什么 | 用了几级提示 | 用时（秒） |
|---|---|---|---|---|---|---|---|

另记：

| 记什么 | 怎么记 |
|---|---|
| 找不到该点哪里的次数 | 学生说"在哪"、鼠标乱晃超过 3 秒，算一次 |
| 读错画面或读错数的次数 | 听学生说的 |
| 原话 | 抄下来，好的坏的都抄 |
| 技术故障 | 记步号和主持人是否出手 |

**结果怎么用**：
- 有 2 人以上卡在同一处的，就是要改的问题。
- 把"理由（原话）"对到错误想法清单：学生选某个错误选项时说的理由，是不是规格写的那条想法？是，就把那条的依据从"教学经验，待核"改成"出声思考 n=5：k 人"；不是，说明规格没猜对，写出新的想法。
- 学生在每步之后是否改了答案，对照规格"在哪一步推翻"，看想法是不是在那一步被推翻。
- 结束访谈里"结论能不能复述"，对照结论区条目。

## 二、老师审读（2～3 人）

**找谁**：教过这一章的高中物理老师；最好有一位新手老师、一位有经验的老师。

**给老师什么**：规格全文（去掉证据表和自检两节，先不说我们的结论）和课件链接。审读时间约 40 分钟。

**主持人话术**：

> 请你按自己上这节课的想法来看：哪里对、哪里不对、哪里你的学生会不一样。不用客气，挑错最有用。

**审读表一：第七节清单**（标准 `plans/lesson-design-standard.md` 第七节）。老师每条答"是 / 否 / 不确定"，"否"和"不确定"写原因。

| 条目 | 是/否/不确定 | 备注 |
|---|---|---|
| 写明对应的课标条目 | | |
| 核心问题是一句学生能感到好奇的话 | | |
| 目标 2～3 条，动词句，每条指明检验它的题；重点、难点分别标出 | | |
| 先修写清楚，开头有确认 | | |
| 错误想法清单每条都填了四格 | | |
| 写明接住上一课的什么、留给下一课的钩子 | | |
| 每一步都能填出"上一步留下的问题……这一步回答……留下……" | | |
| 每个埋下的问题都写明在哪一步回答 | | |
| 四段都有，每段有步数预算，写明超出时先砍什么 | | |
| 开头的现象，在收束段回到了它 | | |
| 每一步写了"这一步要达成什么" | | |
| 每个结论出现前，学生都表过态，且揭晓后不能改 | | |
| 每条错误想法都按"引出 → 冲突 → 化解"处理 | | |
| 概念在事实之后才命名 | | |
| 一步只推进一个想法；每个数字都有画面上的出处 | | |
| 画板上没有只是过渡用的话 | | |
| 学生做实验时给的是挑战，不是步骤 | | |
| 每个结论都进了结论区 | | |
| 每条目标至少两道题，其中至少一道迁移题 | | |
| 每个错误选项对应一条错误想法，反馈说清为什么错 | | |
| 随堂检查插在建构段中间，答错能指回对应的步 | | |
| 第一次用新规律之前，有一道四段式示范例题 | | |
| 至少用了两种单选以外的题型 | | |
| 每道题标了预估首答正确率，都在 35%～70% | | |
| 收束靠学生回忆；作业分两层，逐题写了意图 | | |
| 每张图都通过删除检验 | | |
| 预测前不泄底 | | |

**审读表二：课堂上会怎样**（每步一行，或只填有话说的步）：

| 步 | 你会这样讲吗（会 / 会但要改 / 不会） | 你的学生这一步会怎样（卡在哪、会选哪个错误选项、会不会觉得无聊） | 规格里的错误想法你的学生真有吗（有 / 没有 / 没见过） | 备注 |
|---|---|---|---|---|

再回答：

1. 你见过、但规格没列的错误想法有哪些？学生通常怎么说、怎么错？
2. 哪个数字、哪句物理表述你觉得不严谨或不对？
3. 如果课时紧张，你会先砍哪几步？和规格写的"超出时先砍"一致吗？
4. 预估首答正确率，哪几题你觉得差得多？为什么？
5. 哪个题的选项，你的学生不会选，或者选项里该有而没有的？

**结果怎么用**：
- 物理表述有错的，立即改并重跑 `check_numbers.py`。
- 2 人以上"否"的条目，是要改的缺口。
- 老师说"没见过"的错误想法，不删，在依据列追加"老师审读 n=k：没见过"，等学生数据。
- 老师补的新错误想法，加进清单，标"老师审读"。

## 三、前后测加延迟测

**目的**：看学完有没有进步、错误想法有没有被推翻、一周后还在不在。

**题目从哪来**：从规格的检验题抽。

1. 题库 = 规格 `## 题目` 里的小测题和随堂检查题。
2. 每条目标至少抽 2 道：一道近题、一道迁移题（标准 §五.1）。迁移题占比不少于一半；目标是难点的，迁移题多抽一道。
3. 课上小测的原题**不能**直接用作前测、后测：学生在课里做过。把它们改成平行题：保持选项结构和每个干扰项对应的错误想法不变，换情境、换数据；数值进 `check` 块重算。
4. 做三套平行卷 A、B、C，每套题量相同（建议每条目标 2～3 题，全卷 6～9 题，15 分钟内做完）。
5. 每题记录所选选项，不只记对错，这样才能看每条错误想法的选择率。

**怎么安排**：

| 时间 | 做什么 |
|---|---|
| 上课前 | 前测。一半学生做 A 卷，一半做 B 卷（轮换，抵消两套题难度的差别） |
| 上完课，当天或次日 | 后测。做前测没做的那一套（做 A 的做 B，做 B 的做 A） |
| 一周后 | 延迟测。做 C 卷。**事先不通知，不让回看课件，不在这周内再讲这个内容** |

三次测试都不给答案，也不讲评，讲评放到延迟测之后。

**算归一化增益**：

> g = (后测 − 前测) / (100 − 前测)

成绩是百分制。班级的 g 用**班级平均分**算（先对全班取平均，再代入公式）；前测满分的学生不能算个人 g，剔除并注明人数。延迟测同样算：g_延迟 = (延迟测 − 前测) / (100 − 前测)，和 g_后测 比，看一周后掉了多少。

**参照**：Hake (1998)，*Am. J. Phys.* 66, 64（只读摘要）：用 FCI 等测验统计了六千多名学生，传统授课班级的平均 g 约 0.23，互动式教学班级约 0.48。常用分级：g < 0.3 低，0.3～0.7 中，> 0.7 高。**注意**：这些数来自美国大学和高中、用的是力学概念测验、整门课的数据；我们是一节小课、中国高一高二学生，所以只当量级参照，不当达标线。没有对照班时，只能说"前后有多大变化"，不能说"比别的教法好"。样本小时只看方向，不下显著性结论。

**逐条错误想法看**：这是最有用的一张表。

| 错误想法 | 对应选项 | 前测选择率 | 后测选择率 | 延迟测选择率 |
|---|---|---|---|---|

前测高、后测低、延迟测又回升，说明想法被暂时压住但没有化解，规格里"在哪一步推翻"那一步要加强；前测就很低，说明这条想法本来不常见，依据要改。

**结果怎么用**：
- 每题的前测、后测首答正确率，对照规格的预估首答正确率，校正预估。
- 迁移题的增益明显低于近题，说明学生学到了表面做法，要在巩固段加对比案例。
- 结果交给主会话回填证据表；对不上规格的地方，列入"请用户定的问题"。
